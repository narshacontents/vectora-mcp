# D4_Diagram — 제작 공통

## 모든 도식의 공통 원칙

요청한 대상·관계·순서·집합·공간 구조를 먼저 확정하고 미지수·빈 질문을 풀지 않는다. 같은 역할의 표기와 크기 기준을 일관되게 유지하되, 글 길이·비교 행·관계 구조에 필요한 크기 차이는 해당 배치 원칙에 따른다. 원문의 관계를 임의로 추가하거나 지우지 않는다. 이동·조판 후 라벨과 실제 대상의 대응, 문자와 경계의 겹침·잘림을 검수한다.

논증에서 두 전제를 묶는 독립 `+`처럼 **구조를 나타내는 기호**는 본문 글자 크기에 묶지 않는다. 굵은 추론 화살표와 함께 쓰이면 편집 가능한 십자 채움 경로/도형을 우선하고, 화살표 몸통과 시각적 무게를 맞춘다. 기호 크기는 약3–4mm, 획 두께는 크기의 약1/5–1/4부터 간격에 맞게 정하며 두 전제 사이 중앙에 둔다. 문장·수식 안의 `+`는 문자와 연산자 공백 규칙을 유지한다.
