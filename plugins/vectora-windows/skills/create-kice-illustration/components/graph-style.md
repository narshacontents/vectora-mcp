## 차트·연속 그래프의 축·개형 표현 — chart/graph에만

독립된 생산가능곡선 등 개념 좌표도는 다른 자료·긴 라벨이 비례를 제한하지 않으면 **플롯의 X·Y축 길이가 비슷한 정사각형**을 출발점으로 한다. 바깥 글자까지 포함한 그림 전체를 정사각형으로 만드는 규칙이 아니며, 두 축의 수치 척도를 같게 바꾸라는 뜻도 아니다. 시계열·관측 차트, 병렬 패널·화면 속 그래프에는 해당 내용의 가용 영역을 우선한다.

짧은 Y단위가 숫자 눈금 위에 놓이면 글상자 왼쪽 좌표가 아니라 **눈금 숫자 열의 실제 잉크 정렬선**에 맞춘다. 개념 좌표도의 X축 끝 가로 제목은 축 아래의 인접 여백부터 배치하고, 아래 빈칸을 줄이려고 자료 영역 안쪽·축 위로 올리지 않는다. Y축 끝 제목도 축의 왼쪽/위에서 가까이 붙이고 실제 획과 화살촉 사이를 확인한다. 단위·제목과 눈금을 같은 역할의 정렬 묶음으로 검수한다.

정량 chart와 축/개형을 가진 graph에 적용한다. 수량 눈금은 **실제 수량 척도가 있는 경우만**; 정성 이론 그래프에 새 숫자 눈금·전면 격자를 자동 추가하지 않는다. **수치를 생략하더라도 요청된 시점·범주명과 자료의 대응은 표시한다.** 숫자 눈금 숨김 설정이 의미 있는 축 라벨까지 없애지 않는지 계획과 실제 출력에서 확인한다. 눈금 비교용 보조선 적용 조건은 해당 유형에서 정한다.

- 축은 **0.4pt**(대략0.3–0.4), 독립된 자료선·개형은 **0.8pt**(대략0.6–1.1), 보조선은 **0.2pt**(대략0.15–0.3)를 출발값으로 쓴다. 선그래프·큰 독립 방사형에서는 자료선이 축보다 보통 약2배, 보조선보다 더 뚜렷하게 읽히게 한다. 계열이 조밀하거나 작은 패널이면 범위 아래쪽, 한두 선의 추세·이동을 강조하면 위쪽을 선택한다. 몇 가지 숫자 중 하나만 고를 의무는 없고 최종 인쇄 크기로 판정한다. **누적면적·구성비처럼 면 자체가 자료인 경계는0.2–0.3pt**부터 사용하며 굵은 독립 곡선 규격을 적용하지 않는다. 범례 견본에도 본체의 실제 굵기를 반영하고 채운 화살촉에 외곽선을 덧대지 않는다.
- 파선의 선/간격도 역할별 출발값이다. 보조선은 **1.5/1pt**, 자료선의 긴 파선은 **3/1.5pt**(작고 조밀하면2/1pt), 일점쇄선은 **6/1.5/1.5/1.5pt**부터 검토한다. 제공된 선종류·계열 구별을 유지하고 굵기·곡선 길이에 맞춰 주기를 조정한다. 같은 계열의 본체·범례·비교 패널에는 같은 설정을 쓴다. 엔진이 범위 안의 다른 주기를 사용했다는 이유만으로 불필요하게 다시 그리지 않는다.
- 선종류가 미지정인 여러 계열은 실선·파선·일점쇄선 또는 표식으로 **최종 인쇄 크기에서도 구별되는 조합**을 선택한다. 서로 다른 계열에 같은 검정 파선과 같은 표식을 주고 범례 문자만 다르게 적지 않는다. 네이티브 범례는 실제 계열 스타일에서 생성하며, 여러 패널의 공통 범례는 같은 계열 ID·명칭·선종류·표식을 대조한다. 한 패널 소유 범례를 공통으로 사용했다면 다른 패널의 편집까지 자동 연동된다고 가정하지 않는다.
- Y지표명은 정량 차트에서는 축 왼쪽 직립 세로쓰기를 출발점으로 하며, 긴 제목은 의미 단위 **2–3열**, 짧은 단위는 따로 둔다. 정성 이론 그래프의 짧은 제목(물가·Y재(개) 등)은 **Y축 상단 왼쪽의 가로쓰기**를 기본으로 한다. 짧은 단어와 단위를 여러 세로열로 쪼개지 않으며 사용자 지정 방향을 우선한다. X제목은 눈금 아래 별도 줄/축 끝 바깥. 단위는 수량을 나타내는 축에 붙인다. 가로 막대·100% 띠의 단위는 가로 값 축 끝 부근에 두며, 범주축 위 왼쪽에 홀로 띄우지 않는다.
- 제목·눈금·단위·범례·외부 라벨 공간을 먼저 제외하여 자료 영역 계산. 긴 범주명은 의미 단위 줄바꿈과 실제 폭 측정, 한 음절 고립·이웃 라벨 접촉 금지. 비수량 범주 간격만 라벨 폭에 맞춰 변경할 수 있다.
- 두 축이 같은 원점을 공유하면 `0`은 한 번만 표시한다. 투영·기간 보조선이 개형을 가로지르는 것은 의미상 필요한 교차일 수 있으므로 무조건 피하지 않는다. 기간 화살촉·글자가 개형에 붙어 한 기호처럼 보이는 충돌은 피하되, 이를 위해 자료 좌표나 기간 끝점을 바꾸지 않는다.
- 점·곡선의 이름과 수치 라벨은 보조선에 획이 관통하지 않게 두고, 곡선명은 가까운 투영 보조선이나 다른 곡선이 아니라 자기 곡선에 분명히 연결되게 배치한다. 의미가 지정된 A 등 점과 곡선·자료 좌표는 그대로 두고 라벨의 가로·세로 위치만 검토하며, 같은 역할의 간격을 맞춘다. 보조선 위에 놓여야 하는 라벨은 공통 규칙의 작은 흰 배경으로 판독성을 확보하고 정렬을 유지한다. 선을 문자 뒤로 보냈다는 사실이나 글자 외곽에 가는 흰 선을 두른 것만으로 충돌이 해결됐다고 판단하지 않는다.
- 축 제목은 바로 인접한 눈금 글자 또는 축 끝의 **실제 획에서 약 1–2mm** 떨어진 위치부터 배치한다. 수치 눈금이 없는 개형에 눈금용 빈 줄을 남겨 제목이 축에서 고립되지 않게 한다. 기울어진 선 옆 라벨도 글상자 사각형이 아닌 글 획↔선의 빈틈을 검사하고, 교점·자료 위치는 유지한다.
- 수량 축은 일정 간격의 읽기 쉬운 눈금이며 관측값을 불규칙 눈금으로 대신하지 않는다. 생략 뒤에도 척도/눈금 간격 유지. 같은 의미의 비교 패널은 척도·크기 공유, 패널 사이 틈은 내부 틈보다 크게.
- 범례는 각 표식과 해당 문자를 한 쌍으로 가까이 놓고, 다른 범례 항목 사이에는 더 넓은 틈을 둔다. 표식/선 중심은 실제 표시되는 글 획 묶음의 세로 중심에 맞추고, 범례 전체도 적용 자료 영역을 기준으로 정렬한다. 기준선·행간 상자의 중앙만 맞추어 기호가 위아래로 뜨지 않게 한다.
