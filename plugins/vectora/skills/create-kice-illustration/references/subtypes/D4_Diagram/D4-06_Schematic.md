# D4-06_Schematic — 모식도

단면·공간 구조·특성 좌표 배치·3D 속성 큐브(정량 값 없는 축)

단면·공간 구조·정성 특성 좌표·수량 없는 3D 속성 큐브다. 영역·층·접합·안팎·투영과 상대 위치를 보존하고 물리적 관계를 연결 편의를 위해 바꾸지 않는다. 절단면과 외관 면을 구별한다. 3D 구조의 보이는 앞 모서리는 실선, 가려진 뒤 모서리는 파선으로 구별하며 실제 투영·가림에 맞춘다. 기호는 축·모서리와 떨어뜨려 배치하고 인출선이 필요하면 원래 대응 위치를 유지한다.

정성 좌표는 축 양끝 의미와 상대 위치만 보존하며 숫자 눈금/전면 격자를 추가하지 않는다. 축 0.4pt, 인출선 0.3pt; 세로축 제목은 축 왼쪽에 직립 세로쓰기, 긴 제목은 의미 단위로 2–3열, 단위는 분리하고 X제목은 축 끝 바깥 또는 아래에 둔다. 세로 지표명을 패널 상단 중앙 제목으로 떼지 않는다. 제공된 기준선·이동 방향만 쓴다. 수치 없는 radar 외곽은 실제 `chartStyle:"radar",type:"line",chartOptions:{scaffoldOnly:true,radarAxisLabels},categories,series`에서 values를 범주 수만큼 null, 계열 labels를 제공 기호로 둘 수 있다. 내부 위치를 실제 값처럼 표시하지 않는다.
