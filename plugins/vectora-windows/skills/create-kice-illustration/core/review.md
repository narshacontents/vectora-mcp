# 이미지 검수와 원인별 수정

**첫 완성본과 저장된 실제 JPEG를 직접 본다.** 사용 크기와 확대에서 원 요청·제작 계획과 대조한다. 계획에 빠진 요구도 원 요청으로 확인하며 자동 audit·렌더 성공을 시각 합격으로 대신하지 않는다. 원문을 임의로 늘리는 시험은 하지 않는다.

## 원인을 구별해 고치기

| 실패 원인 | 확인·수정할 부분 | 보존할 부분 |
| --- | --- | --- |
| 내용 | 원문·값·기호·단위·자료 대응과 누락을 확인하고 해당 입력/연결을 수정한다. 원자료가 불명확하면 추측하지 않는다. | 요청의 의미와 수정 대상 밖의 데이터·자산 |
| 배치·표현 | 제목 중심, 비교 자료의 시각적 크기/정렬선, 묶음 안팎 간격, 꼬리·지시선 대상, 인물 화풍, 선택 pt/선폭을 본다. 폭 배분·배열·범례·역할별 위치 등 원인에 맞는 조판/자산을 수정한다. | 원문·값·척도·기호 대응·문자 규격·편집 연결 |
| 편집 구조 | 실제 ID/서식·소유 관계와 자료 연결을 확인한다. 텍스트 덩어리당 한 글상자, 같은 글상자의 밑줄/부분 서식으로 고치며 기존 네이티브 소유자를 유지한다. | 표시 내용·사용자 서식·문단 박스 mm·수정하지 않은 자산 |

원인이 겹치면 내용·연결부터 바로잡고 다시 조판한다. 수정 전에 내부 기록에 **위치·관찰한 문제/원인·수정 대상·보존 대상**을 한 줄씩 남기고 실행 결과를 덧붙인다. 단순 위치 오류로 전체를 재생성하지 않는다. 큰 구도 변경이 필요하면 계획을 고쳐 영향받는 묶음을 재조판한다. 도구 오류/미지원은 재현 입력과 기대·실제를 구분해 보고하며, 반복 실패를 영구 화풍 규칙이나 임의 데이터 변경으로 우회하지 않는다.

## 여백·표시 외곽·최종 보존

- 의미 없는 빈 띠·한쪽에 몰린 틈·고립된 라벨·지나친 밀착·배경을 피하느라 벌어진 배치는 고친다. 지정 빈칸·읽기 여유·원화 장면의 의도된 공간은 유지한다. 범례는 글상자가 아닌 실제 문자 획과 표식의 가로·세로 중심을 맞추고, 여러 줄 라벨은 표시 획 전체를 본다.
- 목록의 위계·본문 시작 열·후속 행을 확인한다. 모두 왼쪽 정렬하거나 줄별 글상자·별도 밑줄 선으로 대신하지 않는다. 실제 수정 의뢰에서는 변경 내용과 연결 재조판도 확인한다.
- 보이는 glyph ink·획·clip 결과와 명시한 유효 reserve bounds로 대지를 맞춘다. 지원되는 composition child/text root/text-frame blocks의 예약만 보존하며 빈 프레임·숨긴 임시 문자·가짜 placeholder를 예약으로 삼지 않는다. clip 밖 기하는 제외한다. 실제 잘림·내부 밀착과 외부 여백을 구별하고 작은 픽셀 반올림 차이로 반복 확대하지 않는다.

수정 대상과 영향받은 주변 배치를 확인한 뒤 **완성본 전체를 다시 본다**. 저장·재열기에서도 내용·서식·구조가 유지되는지 확인한다. 수정 결과가 합격하기 전에는 실패한 첫 결과를 통과 기록으로 바꾸지 않는다. 사용자 원본의 명시적 재현·대조 때만 `core/reference-review.md`를 추가로 읽는다. 수정 예산은 SKILL을 따르고 남은 결함/도구 한계는 알린다. 축소·흐림·클리핑·진단 면제로 숨기지 않는다.
