- 내용 예약은 `{widthMm?,heightMm}` 또는 `{widthMm?,lines,text?,lineHeight?}` 중 하나다. heightMm와 lines를 함께 보내지 않는다. 줄 수는 실제 선택한 UND 계열 8pt와 역할별 자간의 측정 결과와 일치해야 한다. 임시 측정 문구는 그림에 표시하지 않는다. 연결된 live schema에서 지원을 확인한 뒤 newspaper/scroll/browser와 worksheet의 reserve/component blocks, worksheet response 블록을 쓴다. Response의 widthMm는 상자 폭, heightMm는 전체 상자 높이, lines는 필기 줄 수를 지정하며, 세 값이 없으면 supplied placeholder는 기본 얕은 한 줄 상자에 둔다. noticeboard blocks는 계속 지원 범위에 포함하지 않는다. 예약은 조판 공간이며 실제 원문/빈칸 의미를 대체하지 않는다.
