# 외부 출제 의뢰의 실행과 응답

외부 출제 에이전트 의뢰에만 적용한다. 입력 도움말은 [의뢰 가이드](../references/caller/exam-agent-guide.md)이며 일반 제작자의 필수 읽기는 아니다.

- **접수:** 자연어·표·첨부를 받고 신규/수정, 표시 원문·자료·대응과 숨길 정답·출제 맥락을 분리한다. 실제 제공/조사/가상/정성, 출처·이용 조건, 보존·금지, 전체 외곽 크기와 내부 예약, 저장·덮어쓰기 범위를 확인한다. 호출자에게 recipe ID·좌표·도구 스키마·스타일 설계를 요구하지 않는다.
- **내부 계획:** 내용 묶음·읽는 관계, 자료/기호 대응, 편집 소유 범위, 보존 조건과 확인 항목만 짧게 정리한다. 조판은 제작자가 결정하고 의미를 바꾸는 누락·모순만 확인한다. 일반 생성에 기출 이미지 열람을 추가하지 않는다.
- **실행·보정:** 원본 접근과 실제 지원 기능을 확인한다. 원문·값·단위를 보존하고 조사는 원자료·표시 가공을 구별한다. 충돌은 배치·라벨·가용 영역을, 잘못된 대응은 해당 원자료 연결을 고친다. 미지원·접근 실패는 필요한 파일/기능과 한계를 알리며 반복 보정으로 숨기지 않는다.
- **편집 연결:** 값→도형·지리 범위→위치·척도→범례를 각각 검증한다. 연결된 본문/값을 갱신하고 소유 범위 밖 보충 개체는 제작자가 재배치한다. 일반 도형으로 해체해 연동을 잃거나 자동 연동을 과장하지 않는다. 인간의 반복 위치·폭 보정을 전제로 납품하지 않는다.
- **응답:** [납품 계약](delivery.md)에 따라 같은 이름의 `.vectora`·`.jpeg`를 제공한다(사용자 지정 우선). 식별자(있을 때), 상태·실제 경로·실측 외곽 치수·저장/재열기/JPEG 직접 검수 결과·남은 문제를 전한다. 해당 출처·가공·편집 한계를 포함하고 미실행·실패를 통과로 쓰지 않는다. 내부 분류·상세 기록은 요청 또는 문제 설명에 필요할 때만, 별도 보고 파일은 요청 시만 제공한다.
