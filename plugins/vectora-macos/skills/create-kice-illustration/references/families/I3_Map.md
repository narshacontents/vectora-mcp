# I3_Map — 제작 공통

## 모든 지도의 공통 원칙

지리 기준 위의 위치·범위·방향·경계·자료 시점을 유지한다. 원자료의 투영·범위·시점과 실제 지원을 구별하고, 근거 없는 지물·수치·경계를 만들지 않는다. 문자/범례는 지리 도형과 독립 편집하며 내용 좌표를 움직여 겹침을 해결하지 않는다. 최종 크기와 확대에서 위치·주제 의미·인출선 끝·섬·잘림·선명도를 확인한다.

기존 지도 사진/스캔은 `I3-13_OldMap`을 우선한다. 새 바탕이 필요한 지도만 실제 프리셋에서 시작한다. 같은 회색 면도 후보 위치이면 Locator, 범주 영역이면 Area, 값 구간이면 Choropleth다. 기온/강수 등치선은 Isoline, 고도 등고선은 Topographic이다. 범례가 정량/정성/위치 중 무엇을 뜻하는지 먼저 확인한다.

## 새 지도에서 선택할 기본형

아래는 미지정 시 판단 기준이다. 지도에서 읽을 정보로 경계·바다색을 고르고, 명시된 재현 요청이나 기존 문서 편집에서는 지정된 설정을 보존한다.

| 지도가 전달할 정보 | 기본 경계 선택 | 바다색 판단 |
| --- | --- | --- |
| 자연환경·기후 지점·국경과 무관한 분포/권역 | 해안 실선 중심. 불필요한 국경은 생략하고 권역 판독에 필요한 경계만 남긴다. | 회색 분포·해양 주제가 있으면 흰 바다 우선. 흰 육지의 위치만 읽는 지역 지도는 연회색 바다도 가능. |
| 국가 식별·국가별 수치/비교 | 해안 실선 + 필요한 국경 점선. 단순 국가 강조 때문에 모든 경계를 실선으로 바꾸지 않는다. | 국가 음영·등급과 구별하기 쉬운 흰 바다 우선. 연회색 바다를 쓰면 가장 옅은 자료 등급과도 구별한다. |
| 섬·해협·항구·연안 경로/지역 확대 | 해안 형태와 주요 섬을 우선하고, 국가·행정 경계는 설명에 필요할 때만 추가한다. | 흰 육지를 분명히 보여주는 연회색 바다를 검토한다. 확대라는 이유만으로 회색을 강제하지 않는다. |
| 한 국가의 행정 통계·연속 자연 분포 | 국가 외곽과 실제 집계 경계를 구별한다. 주변국이 무관하면 해당 국가의 부속 섬까지 선택해 제시한다. | 흰 배경 우선. 수역색과 가장 밝은 자료 구간을 혼동하지 않게 한다. |

연회색 바다는 `#E7E7E7` 부근을 출발값으로 삼되 출력 대비에 맞춰 약 `#D9D9D9`–`#EEEEEE`에서 조절한다. 회색 주제 면과 회색 바다의 공존 자체는 금지가 아니다. 범례의 자료색·흰 육지·수역이 명확히 구별되는지가 기준이다. 흰 육지 위 작은 범주 표식을 돋보이게 하는 무획 해안 지도는 더 진한 회색 바다도 허용한다. 바다를 하나의 연회색으로 고정하지 않는다. 해양 분포를 나타내는 채색은 배경 바다색이 아니라 주제 자료다.

행정구역 통계는 실제 집계 경계를, 등치선·지형도는 연속 선과 지형을, 유선·이동 지도는 방향과 굵기를 우선한다. 이를 모두 국경 점선으로 통일하지 않는다. 행정 경계는 해안·국경보다 가늘게 구분할 수 있고, 주제선과 혼동되는 불필요한 바탕선은 생략한다. 경위선·방위표·축척은 위치/거리/방향 판독에 필요하거나 요청된 경우에만 추가한다.

## 실제 지물·주제 자료의 조사

실제 시설·역사 사건·문화권·환경 분포를 요청하면 짧은 의뢰만 받았어도 제작자가 신뢰할 수 있는 참조 지도와 시점·위치를 조사한다. 사용자가 좌표·도법·경유점을 전부 제공해야 하는 작업으로 돌리지 않는다. 준비 요청의 `dataSource:"research"`로 실제 자료 지침을 포함하고, 사용자가 준 가상/개략 자료는 그 성격을 유지한다. 지도 위의 참조 자료를 찾았다는 사실과 정확한 위치 변환을 검증했다는 사실은 구별한다. 실제 좌표·경계와 임의 문서 경로를 혼합한 뒤 자동 재투영이 된다고 보고하지 않는다.

## 범위·상세도·단순화

**문제에서 읽을 지물 → 표시 범위·최종 폭 → 원자료 상세도 → 단순화 → 선·배경** 순서로 선택한다. Natural Earth의 110m/50m/10m는 축척 등급(1:1억1천만/5천만/1천만)이지 미터 단위 위치 정확도가 아니다. 아래 보존율은 단순화 가능한 꼭짓점 중 남기는 비율이며 낮을수록 강하게 단순화한다. 원자료가 바뀌면 같은 비율에서 같은 모양이 된다고 보장하지 않는다.

| 최종 지도에서 읽을 내용 | 원자료·보존율의 출발점 | 확인할 부분 |
| --- | --- | --- |
| 작은 세계 위치도·대륙의 대략적인 위치 | 110m 원형 또는 약한 단순화 | 섬·해협 식별을 요구하는 주지도에는 그대로 확대하지 않는다. |
| 한 단 폭(약90–108mm)의 세계 기후 지점·대륙 분포 | 50m, 20–30%; 미지정이면 20% + 작은 섬 최소면적 0.025mm²부터 | 해안은 배경이다. 비핵심 섬의 점무늬를 덜고 북극 군도·칠레 남부의 검은 뭉침을 확인한다. |
| 국가 식별·국가별 비교가 핵심인 세계지도 | 50m, 20–40%; 미지정이면 30%부터 | 필요한 작은 국가·섬을 보호한 뒤 출력 면적에 맞춰 비핵심 섬만 생략한다. |
| 동아시아–동남아–호주 등 광역 부분도 | 50m, 30–60%; 좁은 부분도는 30%부터 | 한반도·일본·필리핀·인도네시아의 식별, 작은 곶의 각짐. |
| 국가·연안의 세부 형태, 큰 지역 확대 | 10m를 검토하고 필요한 형태가 남는 강도 선택 | 더 세밀한 원형을 그대로 쓰는 대신 실제 출력 크기에서 잔굴곡을 조절. |
| 통로 자체의 형태·교량/터널·항구의 세부 위치 관계 | 10m, 60–100%부터 | 실제 통로·양안·주요 섬 유지. 식별이 부족하면 강한 단순화로 숨기지 않는다. |

**해안의 꼭짓점 단순화와 작은 섬 표시 생략은 독립 설정**이다. 보존율만 낮춰도 작은 섬은 그대로 남을 수 있다. 새 세계 개관도에서는 두 값을 함께 명시하고, 앱 프리셋의 원형 보존값(100%·섬 면적 0)을 평가원 제작 기본으로 받아들이지 않는다. `islandPolicy:"all"`은 주요 섬을 포함할 수 있는 선택 정책이며, 비핵심 미세 섬의 면적 생략을 금지하는 뜻이 아니다.

이는 **제작 시작값**이며 평가원의 원자료 축척·도법·가공값을 역산한 수치가 아니다. 구도와 최종 크기로 조정하고, 비교 패널은 비슷한 범위에 같은 계열의 상세도를 적용한다. 원형 100%로 되돌릴 수 있는 공통 원본에서 매번 파생하며 이전 단순화 결과에 누적 적용하지 않는다. 해안·국경·국가 채움은 같은 공유 경계에서 생성한다.

같은 10m라도 국가 경계에서 추출한 해안과 전용 육지·연안 자료는 담긴 지물이 다를 수 있다. 세부 확대에서 각진 모양이 남으면 보존율 100%와 비교해 추가 단순화인지 원형의 일반화인지 먼저 구분한다. 원형 자체가 목적에 부족할 때는 등록된 더 적합한 연안 자료를 사용하며, 가짜 굴곡을 그려 보충하지 않는다.

세부 연안에서 선분 단순화가 뾰족한 모서리를 만들면 생략 강도만 계속 높이지 않는다. 지원되는 파생 표시 경로에서 원자료 가까이의 **국소 곡선 일반화**를 검토할 수 있다. 최종 인쇄에서 약0.05–0.1mm 이내의 작은 오차를 출발 범위로 삼되 실제 오차·유효한 면·필요한 섬과 해협을 확인하고, 동일한 곡선에서 육지 채움과 해안을 만든다. 지도 틀은 곡선화하지 않으며 원자료·지점·경로의 지리 앵커는 보존한다.

비핵심 작은 호수도 지표 판독을 방해하는 점무늬가 되면 표시를 줄이되 오대호처럼 주제·위치 식별에 필요한 수역은 유지한다. 육지 안의 호수를 흰 섬으로 오인해 처리하지 않는다.

세계 개관도의 비핵심 작은 섬은 출력 면적 약 **0.015–0.03mm² 미만**의 표시 생략을 기본으로 검토하며, 위 표의 일반 세계 분포도는 0.025mm²에서 시작한다. 지역 확대·섬 자체가 주제이면 더 낮추거나 0으로 두고 필요한 섬을 보호한다. 보존율을 낮췄더니 섬이 삼각형·다각형처럼 각지면 더 낮추지 말고 보존율을 되돌린 뒤 섬 표시 기준과 원자료 상세도를 조정한다. 원자료 삭제와 구별하고, 선택·지명·지시점·해협을 구성하는 섬 등 문제에 필요한 지물은 크기에 관계없이 유지한다. 이 기능을 지원하지 않으면 있는 것으로 가정하지 않는다. 빈틈을 메우려고 해협을 합치거나 임의 곡선으로 지형을 다시 그리지 않는다.

**울릉도·독도는 표시 범위 안에 있으면 지리 도형을 항상 보존한다.** 원자료 상세도·단순화율·작은 섬 생략 설정으로 지우지 않지만, 생략 방지는 외곽선 강제를 뜻하지 않는다. 두 섬도 다른 육지와 같은 채움·외곽선 유무·선폭 설정을 따르며, 선 없는 지도에 두 섬만 검정 테두리나 점으로 강조하지 않는다. 원자료에 빠져 있으면 검증된 등록 지리 자료로 보완하고 실제 위치를 옮기지 않는다.

지역 프리셋은 범위·도법·표시 옵션의 출발점이다. 공통 세계 원본이 실제로 연결되면 그 원본에서 지역을 잘라 쓰며, 동일 지리를 별도 파일로 중복 보관할 필요는 없다. 다만 하천·호수·국내 행정·중국 성·지형·판 경계·빙상·옛 지도는 해당 정보가 든 전용 자료를 유지한다. 일반 국가 경계 자료가 이 층들을 대신하지 않는다.

**전체 세계지도는 별도 지시나 주제상 이유가 없으면 태평양 중심을 우선한다.** 대서양을 잇는 이동·교류나 참조 원본의 구도 등 대서양 중심이 더 적합한 이유가 있으면 달리 선택한다. 중심 경도는 도법과 별개이며, 변경 후 지점·주제층을 함께 재투영하고 절단선이 필요한 지물·표기를 가르지 않는지 확인한다.

도법·중심 경도·잘라낸 범위·종횡비는 별도로 결정한다. ‘평가원은 항상 메르카토르’ 또는 ‘세계·동아시아는 항상 밀러’로 고정하지 않는다. 원본/출처의 도법이 확인되면 우선하고, 미지정일 때는 아래 후보에서 시작한다.

| 지도 구도·판독 조건 | 도법 선택의 출발점 |
| --- | --- |
| 직사각형 세계 분포·문화권 | Miller/Patterson 계열에서 시작하되 고위도 확대를 강조할 때는 Mercator를 비교한다. 주제·남북 비율·절단선에 맞는 후보를 선택하며 유형명만으로 도법을 고정하지 않는다. |
| 해협·항구·한반도–일본 등의 좁은 지역 | Mercator를 우선 검토한다. 위도가 넓어지면 위선 간격·남북 비율을 다시 확인한다. |
| 동아시아–호주 등 남북으로 긴 광역 부분도 | Mercator/Miller를 비교한다. ‘지역 지도’라는 이유만으로 세계지도의 기본 투영이나 Equirectangular를 그대로 쓰지 않는다. |
| 미국 본토 등 중위도의 동서로 넓은 지도 | 원추도법 후보에서 표준위선·중앙경선을 확인한다. 위선/국경의 굽음과 방향을 대조한다. |
| 극 중심 | 경선의 방사형만으로 확정하지 않는다. 위선의 반지름 간격이 일정하면 AzimuthalEquidistant, 극에서 멀수록 확대되면 Stereographic을 비교하며 구체를 보는 Orthographic과 구별한다. |

원본 대조에서는 서로 떨어진 해안 기준점과 위선 간격을 함께 본다. 적도 근처 몇 점만 맞추거나 가로·세로를 따로 늘려 도법 차이를 숨기지 않는다. 판별 근거가 부족하면 ‘정확한 도법 확인’이 아니라 적합한 후보를 선택한 것으로 기록한다. 실제 지리 위치의 기준과 지도 자체의 인쇄 종횡비를 구별한다.

재투영이 지원되는 새 지도는 선택한 도법을 spec에 명시하고 저장본에서 확인한다. 프리셋 이름이나 생략된 `projection`을 의도한 도법으로 간주하지 않는다. 비교 시 먼저 같은 지리 범위를 맞춘 뒤 대륙의 비례를 확인하여, crop 차이를 도법 차이로 오인하지 않는다.

정축 원통도법의 세계지도 절단 경도는 중앙경도 ±180°다. 필요한 그린란드·대륙·주제 영역을 가르면 crop만 넓혀 해결되지 않는다. 중심을 조정하거나 검증된 경도 연속 표시를 쓰고 바탕과 주제층을 함께 다시 투영한다. 명시 중심·원자료는 보존하며, 지형 조각만 수동으로 옮겨 붙이지 않는다. 투영 절단선과 문서 crop/clip 각각에서 네 변의 잘림을 확인한다.

범위는 대상과 위치 판독에 필요한 주변만 포함한다. 세계 기후 분포는 불필요한 극지·남극을 덜어내고, 문화권·극지 자료는 필요한 북극권·그린란드를 유지한다. 동아시아와 호주를 함께 보는 세로형은 대략 동경75–170°, 남위45°–북위65° 부근에서 필요한 나라가 온전히 남도록 조정한다. 고정 crop이 아니며 인도·뉴질랜드 등 요청 대상이 있으면 넓힌다. 좁은 해협 주지도는 양안·출발/도착지를 충분히 보이고 넓은 맥락은 작은 위치도로 분리한다. 국가 단독 분포는 의미 없는 주변국을 덜어낸다.

작은 **위치 식별용 부분도**는 해협·반도라는 소재만 보고 통로를 화면 가득 확대하지 않는다. 주변 반도·큰 섬의 특징적인 윤곽이 남아 어느 지역인지 알아볼 수 있는 범위를 먼저 잡고, 그 범위에서 50m와 필요한 10m를 비교한다. 교통 시설·항만의 세부 관계를 읽는 확대도와 구별한다. 가장자리 경위도 숫자는 짧은 눈금과 묶어 가까이 배치하고, 큰 바깥 띠 때문에 실제 지도 창이 지나치게 작아지지 않게 한다.

## 선의 위계

선이 거칠면 **단순화와 물리 선폭을 따로 비교**한다. 역할별 출발값을 먼저 선택해 제작하며, 전체 지도 폭에 따라 모든 선을 똑같이 가늘게 만들지 않는다. 아래는 역할별 제작 시작값이며 고정 검수 임계값이 아니다. 명시값과 원자료 의미를 보존하고 실제 JPEG에서 조정한다.

| 역할 | 시작값과 구별 |
| --- | --- |
| 보통 해안 실선 | **0.3pt**. 조밀한 세계도는 약0.25pt, 지역 확대는0.3–0.35pt에서 검토한다. 작은 지역도라고 자동으로0.15pt까지 낮추지 않는다. |
| 넓은 범위의 배경 국경 점선 | 검정 **0.25pt**, 대시 길이 약**1.05pt / 간격0.65pt**. 미세 점무늬가 되거나 확대해도 연속 실선처럼 붙으면 조정한다. |
| 식별해야 하는 국경·행정 경계 | 약**0.3pt**, 더 길게 읽혀야 하면 **2pt / 1pt** 점선. 해안·주제 경계와 구별하되 모든 내부 경계에 굵은 패턴을 강제하지 않는다. |
| 외곽선 자체를 강조하는 국가·영역 | 뚜렷한 외곽 강조가 필요한 국가는 약**0.8–0.9pt**. 회색 면만으로 구별하는 지도는 보통 해안·국경 굵기를 유지한다. 문화권처럼 바탕과 별개인 넓은 폐영역은 약0.7pt, 클릭 선택 상태처럼 강한 강조는 약2pt도 가능하다. |
| 작은 위치 범위를 둘러싼 주제 점선 | 약**0.5–0.7pt**, 짧은 대시로 바탕 경계보다 또렷하게. 표식은 판독할 해안·만·내륙 범위에 맞는 작은 타원/폐곡선으로 만들고 무조건 같은 큰 원을 씌우지 않는다. |
| 지도 창·배경 경위선 | 직사각형 창은 약**0.5pt**, 경위선은 약0.25–0.3pt. 창은 구도를 구분할 때 쓰며, 모든 떠 있는 지도에 자동으로 덧붙이지 않는다. |

점선 표의 길이와 간격은 **실제로 칠해진 길이/빈 간격**이다. butt cap은 그대로, round/square cap은 획 폭 w를 고려해 `dasharray=[대시-w, 간격+w]`로 설정한다(짧은 국경 .25pt는 [.80,.90]pt). 최종 렌더의 끝 모양을 확인한다.

대시 길이·간격은 모두 최종 출력의 **pt**다. 선폭만 바꾸고 기존 점선 패턴을 방치하지 않는다. 연결 구간마다 점선이 재시작해 작은 점무늬가 생기지 않는지도 본다. 해안은 실선, 배경 경계는 점선이라는 위계를 목적에 맞게 선택하며, 주제선·하천·항로에는 별도 굵기를 쓴다.

## 위치점과 지도 기호

위치 식별점, 도시 표식, 범주 기호, 비례원은 서로 다르다. 입력 지명을 전부 인쇄하거나 의미 없는 원 크기 차이를 만들지 않는다. 다음 크기는 **테두리까지 포함한 바깥 크기**이며 같은 지도 안의 같은 역할과 범례에 일관되게 적용한다.

- 일반 검은 위치점은 지름 약1.3mm에서 시작한다. 빽빽하면 서로 구별되는 범위에서 줄이되 같은 역할의 점을 위치마다 임의로 다르게 만들지 않는다.
- 흰 중심이 작은 **두꺼운 고리 위치점**은 바깥 지름 약1.6mm, 흰 중심 약0.55mm가 기준이다. 가는 빈 원과 구별한다.
- 도시용 빈 원은 바깥 지름 약1.2–1.5mm, 외곽 약0.3–0.7pt에서 정보 밀도에 맞춘다. 두꺼운 고리 위치점의 비율을 모든 도시점에 적용하지 않는다.
- 범주 표식은 채움·모양을, 비례원은 제공된 수량 척도를 보존한다. 일반 위치점의 크기 규칙으로 비례원을 정규화하지 않는다.

Fabric 원의 `radiusMm`/`sizeMm`는 획 중심의 기하 크기이므로 실제 바깥 크기에 획 두께가 더해진다. 예를 들어 두꺼운 고리는 기하 지름 약1.07mm + 외곽선1.5pt로 만들면 바깥 지름이 약1.6mm다. 최종 JPEG에서 흰 중심이 실제로 남는지 확인한다.

최종 출력에서 선 접합·배경 대비·정보 밀도를 함께 확인하며 숫자 일치만으로 판독성을 판단하지 않는다. 비슷한 공개 지도도 출처가 확인되지 않으면 ‘평가원이 사용한 동일 원본’으로 부르지 않는다.
