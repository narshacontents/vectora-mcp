# 독립 자료의 결합



**복합형:** 독립적으로 완결된 자료 단위를 나누고 각 단위를 작업 명세의 units에 넣고 필요한 제작·구성요소 규칙을 조립한다. 공통 규칙과 같은 구성요소 규칙은 한 번만 읽는다. 같은 장면의 교사 발표와 학생 가로 발언처럼 배치 규칙이 다른 발언군은 지침 선택용 unit을 나눌 수 있으나, 같은 외피·인물·발언을 중복 제작하지 않는다. 매체 테두리·교사·짧은 발화처럼 종속된 요소 자체를 별도 완성 그림으로 만들지 않는다. 같은 기호·시점·값을 단위 간 대조하고 하나의 완성 그림으로 저장하되 내부 자료·글·연결은 편집 가능하게 유지한다. 작업 준비 도구가 composition 지침을 함께 포함한다.

끼워 넣는 자료는 전체 컴포넌트 상자와 실제 제목·라벨·도형의 외곽을 구별한다. 비어 있는 캡션 행이나 흰 무선 바탕의 여백에 외피의 안쪽 여백을 또 더해 빈 띠가 생기지 않게, 보이는 자료 외곽으로 간격과 중심을 정한다. 미사용 예약 공간만 지원되는 레이아웃 설정/편집으로 줄이며, 실제 글·인출선·범례·지리 영역을 잘라 숨기거나 자료의 가로세로 비율을 바꾸지 않는다.

나란히 대조하는 자료는 **배치 전에** 제목·범례까지 포함한 표시 외곽의 폭과 높이를 비교한다. 같은 비중의 두 자료는 비슷한 시각적 크기로 배분하고 제목 행·자료 상단 또는 중심 등 읽기 순서에 맞는 공통 정렬선을 정한다. 제목·단위·범례 높이가 다르면 전체 패널 상자의 중앙만 맞추지 말고, 실제 표 테두리와 그래프의 자료 영역을 기준으로 상단/중심을 맞춘 뒤 머리말·범례를 각 자료 가까이에 붙인다. 같은 폭의 빈 컨테이너만 배정해 내부 크기 차이를 방치하지 않는다. 원·방사형 그래프처럼 폭을 늘리면 높이도 커지는 자료 옆에 짧은 표가 있으면, 표를 최소 폭으로 줄이고 남은 폭을 전부 그래프에 주지 않는다. 트랙 폭·그래프의 자료 영역 높이·합리적인 표 안쪽 여백·범례 위치를 함께 조판한다. 한쪽만 절반 높이로 끝나 큰 빈 면이 생기면 그 배분을 그대로 제작하지 않는다. 주자료/보조자료의 의도된 비중 차이는 허용하고, 동일 크기를 강제하려고 표 행을 과도하게 늘리거나 무의미한 행·빈 문구를 추가하지 않는다. 지도는 승인된 도법·범위의 비율을 유지하며 문자·원·지도 자체를 가로세로로 따로 늘리지 않는다. 요청이 가로 배치를 고정하지 않았다면 내용이 자연스러운 세로 배치도 검토한다.

지도에 연결한 자료창은 판독에 필요하지 않은 지도 바탕 위에 겹쳐 놓을 수 있다. 강조 지역·지명·경계의 판독 부분과 지시선 끝은 보존하되, 모든 자료창을 지도의 사각 외곽 밖으로 밀어 큰 빈 띠를 만들지 않는다. 지도 범위는 요청한 주제를 담도록 정하고 무관한 지역을 포함한 채 배치 여백으로 취급하지 않는다.

자료를 갱신·재생성하면 외곽 크기와 주변 자료의 위치가 달라질 수 있다. 생성기 밖에서 보충한 외피·테두리·공통 범례·주석·지시선도 새 외곽에 맞춰 크기와 위치를 다시 맞추고, 독립된 테두리끼리 붙거나 겹쳐 하나의 구조처럼 보이지 않는지 확인한다. 이전 좌표를 그대로 재사용하지 않는다.

외피를 여러 면으로 보충할 때는 뒤에서부터 바깥 테두리·회색 장식 → 흰 내용 면 → 글·표·그래프 순서로 쌓고, 완성 순서를 유지한 채 그룹화한다. 여러 배경을 각각 맨 뒤로 보내면서 흰 면이 회색 외피 아래로 뒤집히지 않게 한다. 전체 그림뿐 아니라 내용 면이 실제로 흰색을 유지하는지도 확인한다.
