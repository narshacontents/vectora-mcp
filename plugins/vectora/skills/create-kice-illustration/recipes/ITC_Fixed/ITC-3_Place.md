# ITC-3_Place — 특정 장소·장면

고정형. 특정 건축물·광장·유적·사건 현장이 배경이자 단서

특정 건물·유적·장소·사건 현장이 배경이자 단서다. 배경을 일반 교실/풍경으로 교체하지 않는다. 원본 사진/작품 재현인지 새 장면 작화인지 요청대로 구별한다.

실재 장소는 신뢰할 수 있는 출처의 참조 이미지를 직접 확인해 지붕·문·층수·주요 배치 같은 식별 구조를 보존한다. 새 작화에서는 식별에 불필요한 표면 얼룩·바닥 질감까지 복제하지 않는다. 상단의 독립 발언은 장면 전체의 가용 폭을 쓰며, 아래쪽 인물·이름 자리를 같은 행의 예약 칸처럼 빼지 않는다.

사진을 확정하기 전에 **식별 구조의 완결성·장면 종횡비·발화자 자리**를 함께 본다. 탑·지붕 등의 중요한 끝부분이 원사진부터 잘린 후보는 필요한 구조가 온전히 보이는 후보로 바꾼다. 말풍선 높이와 사진의 표시 범위를 먼저 잡고, 비단서 하늘·바닥·외곽을 활용해 인물과 꼬리를 연결한다. 짧은 꼬리를 사진 위에 두고 인물만 먼 아래쪽에 놓지 않는다. 긴 곡선 꼬리가 필요하면 핵심 구조를 피해서 실제 화자 방향으로 이어지게 한다. 전체 장소를 알아볼 만큼의 범위는 유지하되 빈 바닥 때문에 장면을 불필요하게 길게 만들지 않는다.

말풍선이 본문과 독립된 보충 도형이면 문장 추가·삭제 뒤 실제 글 높이를 다시 측정해 외피·꼬리·인물과 사진의 겹침을 함께 재조판한다. 글상자만 늘어났다는 이유로 수정 완료로 판단하지 않는다.
