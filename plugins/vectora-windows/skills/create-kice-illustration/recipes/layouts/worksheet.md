### 학습 응답·과제 양식

지시·학습 자료·응답/작성 공간을 과제 순서대로 구성한다. 질문과 응답 영역의 대응을 유지하고 제공하지 않은 정답·예시 답안·과제를 채우지 않는다. 빈 응답란은 완료된 빈 양식이며 제공된 밑줄·빈칸·번호는 보존한다.

현재 연결된 live schema에서 일반 응답 양식은 `kind:"text", variant:"worksheet"`로 시작한다. **'학습지'는 내용의 역할이며 생성기의 외피 이름을 고정하는 말이 아니다.** 작은 말림·접힘이 있는 종이가 명시되면 이를 지원하는 `variant:"paper"`의 순서 있는 `blocks`에 성명·지시문·설명·답안표를 함께 넣고 `background.cornerTreatments`로 요청한 모서리와 모양만 지정한다. 크기는 안쪽 여백에 들어가게 정한다. worksheet 전용 fields/response를 paper에 보내거나, 지원되는 장식을 누락하거나 분리된 경로로 덧붙이지 않는다. 미지원 외피만 직접 보충하고 수정 때 함께 재배치한다.

문서명(활동지·계획서 등)과 구체적인 과제 제목이 함께 있으면 과제 제목을 주제목으로 삼고, 문서명은 성명 같은 보조 정보와 한 머리행에 묶을 수 있다. 보조 문서명까지 별도의 큰 제목 행으로 만들어 상단 여백을 중복하지 않는다. 요청한 종이 고정부가 철사형 클립인지 넓적한 누름 집게인지 구별하며, 생성기의 클립 옵션이 다른 구조라면 해당 부속만 내용에 연결된 편집 가능한 외피로 보충한다.

상단 필드는 요청된 항목만 넣고 각 필드에 고유한 ASCII ID를 유지한다. 제공된 응답 자리표시자는 기본적으로 얕은 한 줄 상자에 둔다. worksheet 응답의 `widthMm`는 상자 폭, `heightMm`는 전체 상자 높이, `lines`는 필기 줄 수를 지정한다. 내부 자료의 내용·폭은 외피 소스를 통해 수정하여 종이와 함께 재배치하고 실제 JPEG를 확인한다.

평가 설명·결론·과제 문단처럼 문장으로 읽는 내용은 하단에 있더라도 footer로 분류하지 않고, 관련 본문 문단과 같은 왼쪽 기준선에 둔다. footer는 요청에 제공된 역할에 따라 페이지 번호·성명·출처 같은 보조 메타데이터에 사용한다. native worksheet의 footer 정렬이 요청과 맞지 않으면 긴 평가 문단은 native 본문 텍스트 블록으로 배치한다. 특정 템플릿이나 모든 footer의 왼쪽 정렬을 강제하지 않는다.

사용자가 필드 정렬이나 종이 장식(예: 오른쪽 성명란, 작은 하단 물결)을 명시하면 연결된 native worksheet 경로의 실제 지원 범위를 확인하고, 지원되는 경우 첫 레이아웃부터 함께 구성한다. 내부 API 필드나 후처리 수단을 추정하지 않는다.

일반 응답 과제 양식의 제목은 상단의 중심, 점수·성명 같은 보조 필드는 가쪽의 작은 묶음으로 계획한다. **사료 인용·해설형에서는 표제의 역할과 종이 외피에 따라 모서리 정렬도 선택**한다. 같은 native worksheet 생성기라는 이유로 모두 중앙이나 우상단에 고정하지 않는다. 각 필드명과 값/입력 칸을 가까이 붙여 한 쌍으로 읽히게 하고, 다른 필드명과 값 사이에 끼워 넣지 않는다. 상단이 좁으면 보조 묶음을 다음 행으로 내려 제목·과제 영역과 구분한다.

성명 기호·점수처럼 한 줄 필드는 실제 값 전체를 안쪽 글상자 폭에서 측정해 한 줄임을 확인한 뒤 외곽 칸을 정한다. `○○○`를 한 글자 폭으로 취급하거나 칸 바깥으로 줄바꿈하게 두지 않는다. 외곽 칸과 글 프레임을 각각 고정한 경우에도 둘의 실제 높이·여백을 함께 대조한다.

`(가)` 같은 내용 자리표시자만 요청한 칸은 한 줄 기호와 안쪽 여백에 맞는 얕은 상자로 만들고 기호를 가운데 둔다. 여러 줄을 직접 쓸 응답 공간이나 지정 치수/줄 수가 명시된 경우에만 그 크기를 예약한다. '답안'이라는 이름만으로 큰 빈 필기 공간을 추가하지 않는다. 문장 사이의 작은 기호 박스와 독립된 답안 행을 구별한다. 독립된 답안 박스가 같은 본문 열 안에 있으면 주변 항목의 시작선·오른쪽 여백을 따라 폭을 정해 한쪽에만 큰 빈 띠를 남기지 않는다. 지정된 폭은 우선한다. 내부 표·그래프는 셀과 도해 라벨 각각의 선택 프로필 판독성과 데이터 관계를 유지하는 필요한 크기로 두며, 주변 글 영역의 전체 폭을 채우려고 모든 자료를 크게 늘이지 않는다. 전체 높이는 이 내용들과 최소 간격을 합쳐 정한다.

종이 양식의 외피는 필요한 가장자리·겹침/접힘 정도만 직접 구성한다. 표시용 보드의 핀·받침·조작부를 응답 양식에 자동 추가하지 않는다. 전용 게시판 helper로 응답 양식을 억지로 대체하지 않는다.

#### 검사

활동 순서·지시와 응답란 연결, 실제 사용 가능한 작성 영역 치수, 하단/접힘과 마지막 줄의 충돌을 확인한다.

빈 응답 영역은 실제 예약 치수로 유지하며 측정 문구를 표시하지 않는다.
