## 세로 발언 행

발언 순서와 반복 화자의 식별을 유지한다. 실제 사람 그림이 없는 메신저는 이름표·아이콘으로 화자를 대응시키며 새 인물을 추가하지 않는다.

좌우 교대는 의무가 아니며 같은 화자의 반복 위치와 발언 순서를 유지한다.

이름표를 말풍선 옆에 두면 **이름의 실제 글자 폭·꼬리가 몸통 밖으로 나온 길이·그 사이의 빈 간격**을 모두 행 폭에 예약한다. 이름과 몸통 사이의 숫자만 정해 꼬리가 이름 위에 겹치지 않게 한다. 직접 만든 외피 경로는 자식의 배치 폭을 자동으로 늘리지 않으므로, 첫 생성 전에 완성 꼬리 외곽과 이름 잉크 사이에 약 0.8–1.5mm를 출발 여유로 확보하고 각 화자 열에 같은 기준을 적용한다.
