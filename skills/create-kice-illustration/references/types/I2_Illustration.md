# I2_Illustration — 삽화

세부유형 폴더가 없으므로 SKILL.md와 이 문서 두 개만 읽고, 아래에서 요청 대상에 해당하는 조건만 적용한다.

원래 I2 계열의 신규 작화다. 유물·주화·국기·문장의 선화 재작화도 포함한다. 실제 사진/스캔/기존 작품 자체의 복제는 Photo다. 형태·재질·행동을 전달하는 자연 장면은 Illustration, 연결·단면·공간 구조·속성 좌표 등의 관계가 핵심인 모식은 Diagram이다. ‘모식도’라는 명칭이나 정량값 유무만으로 자연 장면을 일괄 분류하지 않는다. 공간 기준 위의 위치·영역·분포·이동은 Map이다.

장면 속 사람은 별도 하위 문서를 읽지 않는다. 여러 대상이 있어도 하나의 장면이면 한 단위다. 발화가 핵심이면 ITA·ITB·ITC의 분류 경계를 적용하되 장면을 정형 가로대화로 강제 변환하지 않는다. 독립된 완결 자료가 있는 복합형만 요소를 분리한다.

지정 대상의 참조 검색과 벡터화 여부·공통 변환·검수는 SKILL.md의 조건을 적용한다. 핵심 대상이 가장 큰 비중이며 배경·소품은 의미를 보완한다. 실루엣→겹침→명암→세부 순으로 제작한다. 문자·식별 기호·인출선·자료 도형은 별도 개체다. 라벨마다 뜻하는 실제 대상/부위를 먼저 지정하고 인출선 끝이 그 영역에 닿는지 확인한다. 가까운 사람·기계 외곽이나 모호한 경계로 대신하지 않는다.

소품의 윤곽·망·세부 밀도는 주대상과 맞춘다. 소형 출력에서는 공통 회색조 화풍의 큰 면과 명료한 선화를 우선하고 사진 같은 표면 질감·촘촘한 털선·음영을 줄여 식별 구조를 남긴다. 작은 테두리/격자가 검정 덩어리로 뭉치면 배율과 최종 물리 굵기를 확인하고 세부를 단순화한다. 미세 획 개수를 완성도로 대신하지 않는다. 대상 수·식별 특징·구조·일관된 화풍을 확인하고 임시 도식만 만든 것을 완성 삽화로 보고하지 않는다.

## 대상·기능이 있을 때만 적용

아래 조건은 사물/장면의 해당 대상·기능에 적용한다. 독립 인간 초상에 생물 묘사나 확대·추적을 조건 없이 요구하지 않는다.

- 비인간 생물이 있으면 식별되는 구조를 유지하고 이모지·아이콘·기하 도형 몇 개로 대신하지 않는다. 생물은 유기적 부피 변화와 가늘어지는 관절/다리 끝을 잇는다. 원 머리+캡슐 몸통 같은 기계 조립 형태를 피하고 날개·털·잎맥은 큰 구조의 방향에 맞춘다.
- 부분 확대를 요청한 경우에만 적용한다. 확대는 같은 원화의 해당 부위이며 형태·방향·연결선이 본체와 대응해야 한다. 필요한 상세가 읽히는 틀을 옆 빈 공간에 놓고 확대 내용은 실제 틀 경계 안에 클리핑한다. 연결선은 본체의 해당 부위와 확대 틀을 잇고, 본체와 확대의 방향·식별 특징을 대조하며 확대 후 해상도도 확인한다. 배율·종명·기관 기능이나 불확실한 해부 구조를 지어내지 않는다. 톱니·털·가시를 동일한 큰 삼각형 반복으로 대신하지 않는다.
- 생물의 가는 구조를 선택적으로 추적하는 경우: 생물의 가는 더듬이·털·잎맥·가시 끝이 최소 경로 제거로 사라지거나 서로 뭉치지 않게 해상도·`--min-path`·세밀도를 조절한다. 본체와의 연결·방향·가늘어지는 끝을 보존한다.

해당 조건이 있으면 생물 본체와 가는 구조의 연결, 확대의 부위/방향 대응도 검사한다.

## 독립 인간 머리·흉상

독립된 인간 얼굴·머리·흉상을 신규 작화한다. 공통 인물 화풍·정체성·절단 범위·비례·승인 검사를 적용한다. 단독 초상 요청을 장면이나 발화 배치로 확대하지 않는다. 화자용 인물을 단독으로 요청했으면 그 사용 맥락의 절단 범위를 보존한다.

## 유물·사물·생물

개별 대상의 형태·재질·구조가 중심이다. 작은 물체를 빈 영역을 채우려고 키우지 않는다.

국기·문장은 해당 국가/기관의 공식 도안과 요청한 시기·판본을 확인하고 가로세로 비율·분할·문양·문장 구성 요소와 배치를 보존한다. 회색조 재작화에서도 도안의 식별 요소를 생략하거나 다른 판본의 요소를 섞지 않는다. 유물 자체가 조각품이면 사물의 형태와 재질을 유지한다.

### 선택 추적 helper

로컬 helper를 사용할 때 스킬 루트에서 `node scripts/trace_artwork.mjs <원화.png> <출력.svg> --width-mm <그림폭>`으로 실행한다. canvas/imagetracerjs가 있는 프로젝트에서만 사용한다.

기본 6단계 회색이며 `--colors 3..12`, `--detail 0초과..5`(작을수록 세밀), `--max-px 300..1800`, `--min-path 0..100`을 조절한다. `--ink 85`는 검정 윤곽 기준, 0이면 별도 추출을 끈다. 연한 회화나 검정 번짐은 기준을 낮춘다. 기존 출력은 덮어쓰지 않고 `.trace.json`은 처리 기록이지 품질 판정이 아니다.

### 검사

물체의 식별 부위·문양·재질과 공식 도안의 판본·비율·구성 요소를 확인한다.

## 장면·풍경·동작·복원도

여러 대상의 관계와 행동 또는 공간을 하나의 장면으로 표현한다. 만화적 비유는 명확한 표정, 운동 인물은 자연스러운 관절·무게중심, 풍경은 넓은 면으로 구별하고 질감 밀도는 최종 인쇄 크기의 판독성에 맞춘다. 자유 장면의 전신 동작·풍경·회화 질감에 작은 초상 화풍/흉상 비례를 강제하지 않는다. 회화풍은 연한/끊긴 선과 명암 면을 허용하며 픽셀에 검정 외곽을 강제하지 않는다.

- 자연 지형은 불규칙한 능선·비탈·암벽을 잇는다. 반복 삼각뿔 산·다면체 바위로 만들지 않는다. 반듯한 블록 절단면 안에서도 표면은 자연스러워야 한다. 강·호수·바다는 낮은 수면과 연결 관계가 읽히고 해안·암반·수면이 구별돼야 한다.
- 전신 동작은 움직임 방향의 여백까지 확보한다. 손과 물건의 접촉·시선 목표·화면 안/밖·앞/뒤를 보존하고 핵심 손동작·얼굴·확대 부위를 가리지 않는다.
- 물·실내·화면 등 장면 배경을 유지할 수 있다. 원근에 따른 크기 차이를 머리 크기 불일치로 일괄 교정하지 않는다. 완결 장면은 한 이미지 개체로, 독립 이동할 인물/소품은 분리 가능한 원화로 둔다.
- 잔상은 같은 물체의 위치·회전·농담 반복이다. 형태/크기를 유지해 실제 여러 개체와 시간상 반복을 구별하고 궤적 여백을 자르지 않는다. 속도·시간·힘·번호·화살표는 자동 추가하지 않는다.
- 화면 속 장면과 바깥 관찰자, 기계 입력/출력, 물건과 받는 손은 별도 역할이다. 복원도도 확인되지 않은 대상의 구조나 기능을 지어내지 않는다.

### 검사

접촉·시선·원근·앞뒤·잔상 동일성과 동작 방향의 여백을 확인한다.
