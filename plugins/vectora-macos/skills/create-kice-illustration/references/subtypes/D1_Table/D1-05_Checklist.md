# D1-05_Checklist — 응답체크표

셀이 ○×·✓·빈칸·점수. 조건 대응용

응답 조건에 대응하는 ○×·✓·빈칸·점수를 셀별로 보존한다. 체크 여부, 입력할 빈칸, 점수 0은 별개다. 선택 가능/불가능·단일/복수 응답이 제공되면 그 관계만 반영하고 정답이나 체크를 추측하지 않는다. 반복 기호의 크기와 중심을 정렬한다.

지원 연결본에서는 유형 공통의 현재 제작 계약을 사용한다. state의 blank/zero/notApplicable/unknown을 구별하고 응답을 추측하지 않는다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
