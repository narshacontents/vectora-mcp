# I3-34_Isoline — 등치선도

양적 주제도. 기온·강수량 등 통계값의 같은 값을 이은 선. 지형 등고선은 I3-12

좌표 노드의 통계값 지도는 `isoline-map`으로 분류한다. 연결 앱의 `TemplateMapSpec.scalar`에서 선만 표시할지, 구간 채색과 선을 함께 표시할지 선택한다. `scalar.contours`가 live schema에 있으면 원 격자에 연결된 선·수치 라벨을 우선 사용한다. 미지원 앱에서만 필요한 부분을 보충하고 편집 연동의 한계를 밝힌다.

원 격자의 좌표 순서, `rowOrder`, 값과 null, 척도·단위, 시점 표기와 출처를 유지한다. 제공된 임계값·구간·라벨을 그대로 쓰고 자동으로 척도를 추정하거나 값을 고도/DEM으로 바꾸지 않는다. DEM 기반 등고선은 I3-12다.

국가 안의 분포면 해당 영역에서 선을 자르고, 해양까지 관측한 분포면 해안에서 끊지 않는다. 얇은 해안·보조 경계와 읽어야 할 등치선의 굵기를 구별한다. 선 위 수치는 작은 흰 받침으로 읽히게 하며, 숫자 위치 때문에 값이나 선 자체를 옮기지 않는다.

가상 분포를 설계할 때는 요구된 각 등치값이 출력 영역 안에서 숫자를 붙일 만큼의 가시 선을 갖는지 확인한다. 최솟값·최댓값을 작은 섬 끝에만 놓아 필수 숫자를 잃지 않는다. 실제 제공 자료의 값·등치값은 이를 위해 바꾸지 않는다. 계획이 ready여도 실제 생성의 라벨 공간 부족 경고와 숫자 누락을 다시 확인하며, 해안과 다른 선을 보존하는 위치를 찾지 못하면 미완료로 남긴다.

단독 지도와 여러 지도 비교 모두 이 recipe를 유지한다. native scalar와 공통 비교 범례의 입력·측정·편집 계약은 선택된 `execution/modules/map-scalar-native.md`를 따른다.
