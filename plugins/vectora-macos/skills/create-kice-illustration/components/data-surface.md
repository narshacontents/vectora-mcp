## 자료 도형의 회색조·범례

채움은 **#FFFFFF,#EEEEEE,#CCCCCC,#AAAAAA,#666666,#000000**이며 그라디언트·그림자·입체 장식은 쓰지 않는다. 범례 테두리·인출선은 0.3pt다. 필요한 범례는 흰 사각 상자에 본체와 같은 물리 크기의 견본/표식·문구를 정렬하며 직접 이름으로 충분하면 생략한다. **범례 안의 자료 견본선은 해당 자료선과 같은 굵기·선종류**를 쓰고 테두리 규격으로 가늘게 바꾸지 않는다. 내부 범례는 자료점·자료선을 가리지 않는 영역에 놓고, 안전한 공간이 없으면 범례 자리까지 포함해 자료 영역을 다시 배분한다. 무늬는 불투명 바탕의 실제 원/선으로 만들고 경계에서 클리핑하며 외곽/공유 경계는 한 번만 그린다. 라벨 충돌은 배치로 풀고 자료 좌표를 옮기지 않는다.
