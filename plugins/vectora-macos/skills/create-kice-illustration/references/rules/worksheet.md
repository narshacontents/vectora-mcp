### 학습 응답·과제 양식

지시·학습 자료·응답/작성 공간을 과제 순서대로 구성한다. 질문과 응답 영역의 대응을 유지하고 제공하지 않은 정답·예시 답안·과제를 채우지 않는다. 빈 응답란은 완료된 빈 양식이며 제공된 밑줄·빈칸·번호는 보존한다.

종이 양식의 외피는 필요한 가장자리·겹침/접힘 정도만 직접 구성한다. 표시용 보드의 핀·받침·조작부를 응답 양식에 자동 추가하지 않는다. 전용 게시판 helper로 응답 양식을 억지로 대체하지 않는다.

#### 검사

활동 순서·지시와 응답란 연결, 실제 사용 가능한 작성 영역 치수, 하단/접힘과 마지막 줄의 충돌을 확인한다.

빈 응답 영역은 실제 예약 치수로 유지하며 측정 문구를 표시하지 않는다.
