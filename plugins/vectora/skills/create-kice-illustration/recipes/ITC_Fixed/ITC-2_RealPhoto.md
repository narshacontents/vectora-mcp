# ITC-2_RealPhoto — 실존 인물 사진

고정형. 실제 인물의 초상·보도 사진이 단서

실존 인물의 원본 초상·보도 사진이 의미 단서다. 새로 생성한 초상으로 바꾸지 않는다. 일반 신문 사진 슬롯만으로 이 유형을 고르지 않는다.

## 실제 인물 사진의 발표 배치

원본 사진의 인물·자세·신체 범위와 종횡비를 보존한다. 새 자세나 부족한 몸 부분을 생성하지 않는다. 기준 자료 면과 가용 폭을 먼저 계산하고 사진의 허용된 비례 크기·배치와 글 영역 조판으로 맞춘다. 원본 보존과 지정 치수가 충돌하면 충돌을 밝히며 사진을 재생성해 해결하지 않는다.
