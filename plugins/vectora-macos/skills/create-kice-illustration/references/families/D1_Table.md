# D1_Table — 제작 공통

## 모든 표의 규칙

- 행/열 제목·셀 값·병합 범위·빈칸 의미를 먼저 확정한다. 2028 예시문항의 수치 비교표처럼 **본문과 머리행 모두 흰 면·직각 격자**를 기본으로 한다. 머리행이라는 이유만으로 자동 회색을 넣지 않고, 명시된 강조·구획·비해당 상태를 구별할 때만 회색 면을 사용한다. 공유 경계는 한 번만 그린다.
- 짧은 항목·기호·헤더는 중앙, 긴 설명은 왼쪽이다. 세로 정렬은 짧은 한 줄 항목을 가운데, 여러 문장·목록을 담은 비교 셀은 위쪽부터 맞춘다. 생성기가 이 조건을 자동 처리하면 모든 셀에 `verticalAlign:"middle"`을 명시해 덮어쓰지 않는다. 숫자 열은 비교에 맞춰 중앙 또는 오른쪽 하나를 유지한다. 실제 문구·수치 측정으로 열 폭을 정하고 행 높이는 그 행의 최대 글상자 높이+위아래 여백이다. 같은 역할의 값 열은 가능한 한 같은 폭이다.
- **열 폭 확정 전** 짧은 항목명·머리글·숫자·단위의 선택한 표 문자 프로필의 실제 혼합 서식을 측정하고 좌우 셀 여백을 더한다. 병합 머리글은 소속 열들의 합계 폭으로 검사한다. 짧은 이름이나 제목 한 글자만 다음 줄에 남거나 수치의 자릿수가 갈라지는 배분을 그대로 첫 그림에 쓰지 않는다. 제한된 전체 폭에서 짧은 열의 필요한 폭을 먼저 확보하고 긴 설명 열에 나머지를 배분한 뒤 모든 행을 다시 측정한다. 임의 엔터·숫자 축소·특수 공백으로 숨기지 않는다.
- 행 높이는 각 행 내용에 필요한 만큼만 둔다. **한 줄의 짧은 항목·수치만 있는 셀은 선택한 셀의 문자 스타일을 측정하고 위아래 약 0.8–1.0mm를 출발 여백**으로 실제 획·테두리 간격을 확인한다. 문서 외피의 넓은 패딩을 내부 표에 그대로 적용하지 않는다. 사용자 지정 높이·답안 작성란·여러 줄 설명·그림이 있으면 그 내용에 맞게 늘리며, 한 행 때문에 모든 행을 같은 큰 높이로 늘이지 않는다. 그림은 병합 영역 안에서 비율을 유지하며 여백·캡션까지 실측한다. 행·열 편집 뒤 그림/캡션의 영역 중심과 셀 경계를 함께 확인한다.
- 미지수·미입력·0·해당 없음·불가능한 조합은 서로 다르다. 빈칸을 추측해 채우거나 회색으로 막지 않는다. 제공된 합계·소계는 위치·구분선으로 식별한다. 단위는 표 우상단 바깥 또는 적용 헤더 가까이에 둔다.
- 매체 안에서도 셀은 직각을 유지하고 장식은 셀 영역을 침범하지 않는다. 매체 외피를 별도로 요청한 경우에만 복합형으로 분리한다.

## 검수

모든 셀은 사방에 최소한의 판독 여백을 확보한다. 미지정이면 좌우 약1–1.5mm, 위아래 약0.8–1.0mm에서 시작하며 실제 획과 선 사이가 좌우1mm·위아래0.7mm보다 좁아 보이면 열 폭·행 높이를 늘린다. 이 값은 원본의 명시 규격을 덮는 강제 하한이 아니라 첫 제작의 검수 기준이다. 왼쪽 정렬한 질문·설명도 같은 기준으로 확인한다. 위아래의 작은 출발 여백을 좌우에도 그대로 적용해 첫 글자가 테두리에 붙게 하지 않는다. 도구가 독립 여백을 지원하면 좌우와 위아래를 원본 설정으로 각각 지정해 이후 셀 편집에도 유지한다. 사방 공통 여백만 지원하는 연결본은 읽기 편한 공통값과 열 폭을 함께 선택하며, 여백을 줄여 문장을 억지로 한 줄에 넣지 않는다.

제작 후 셀별 값·헤더 소속·빈칸·공유 경계와 실제 글 획 여백을 대조한다.

저장 성공과 시각 검수는 별개다. 재열기 후 셀 값·세로 정렬·실제 획 여백을 다시 확인하고 실제 JPEG를 원본 해상도와 최종 인쇄 크기에서 검수한다.
