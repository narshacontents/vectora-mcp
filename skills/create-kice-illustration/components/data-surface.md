## 자료 도형의 회색조·범례

일반 통계 자료의 평면 채움은 **#FFFFFF,#EEEEEE,#CCCCCC,#AAAAAA,#666666,#000000**부터 구별하고 불필요한 입체 그림자를 넣지 않는다. 연속량·원본이 요구하는 그라디언트는 해당 지도/자료 규칙을 따른다. 범례 견본은 본체와 같은 채움·무늬·표식·선 굵기·선종류로 만든다. 자료 좌표를 옮겨 충돌을 해결하지 않는다.

### 위치와 배열 선택

- 직접 계열명으로 충분하면 별도 범례를 만들지 않는다. 필요한 범례는 **내부의 빈 영역과 가장자리의 가까운 외부 공간을 함께 비교**한다. 막대 면적, 곡선·표식, 점→축 인출선, 수치·이름까지 대조하고 플롯 안/밖과 종이·칠판 외피 안/밖을 구별한다. 흰 범례 상자로 자료를 덮어 자리를 만들지 않는다. 반복되는 배경 격자는 흰 바탕으로 가릴 수 있지만 특정 값의 투영선·기준선은 보존한다.
- 위치와 배열을 함께 고른다. 오른쪽에 좁고 높은 여백이 있으면 **작은 세로 묶음을 오른쪽 가장자리에 맞춰 붙이는 배치**, 상단에 넓고 얕은 빈 띠가 있으면 **가로 배열**을 검토한다. 항목이 두 개라는 이유만으로 가로를 택하지 않는다. 긴 항목·다수 계열은 의미를 유지한 여러 행으로 묶고 역할이 다르면 행을 구별한다. 가장자리 정렬과 간격은 자료·문자·외곽선의 실제 여백으로 정하며, 내부·세로·특정 모서리를 항상 강제하지 않는다.
- **자동 충돌 회피는 초안**이다. 충돌이 없어도 범례가 가운데 떠 있거나 상단을 불필요하게 가로지르면 AI가 가장자리와의 관계·여백·시각적 무게를 보고 위치와 배열을 다시 선택한다. 내부에 판독 가능한 자리가 없으면 가까운 외부 공간을 쓰고, 범례 때문에 플롯을 과도하게 줄이거나 큰 빈 띠를 만들지 않는다. 지원 설정·편집으로 반영한 뒤 실제 JPEG를 확인하며, 자료 좌표나 글자 크기를 희생하지 않는다.
- 같은 부호가 같은 의미일 때만 여러 패널의 공통 범례로 묶는다. 공통 범례는 전체 자료 묶음에 속함이 분명한 가까운 공간에 둔다. 같은 회색이라도 뜻이 다른 패널의 범례를 합치지 않는다. 지정 순서·시점·누적 순서를 유지하고 선이 교차했다고 높이순으로 재정렬하지 않는다.
- 견본↔문구는 가깝게, 항목↔항목은 그보다 넓게 둔다. 실제 문자 획과 표식의 중심을 맞추고 범례 전체의 폭·행 높이를 내용으로 계산한다. 흰 사각 틀 또는 간결한 무테 묶음을 선택하며 작은 자료보다 큰 범례를 만들지 않는다.

범례 제목이 제공되었거나 식별 표제가 필요하면 흰 사각 틀의 윗선 가운데에 `<범례>`를 걸치고 작은 흰 배경으로 선을 끊을 수 있다. 특정 틀을 강제하거나 요청에서 제외한 제목을 추가하지 않는다. 무늬는 실제 원/선과 바탕색으로 만들고 경계에서 클리핑하며 외곽/공유 경계는 한 번만 그린다. 선 위 글·회색 면의 글/지시선은 공통 판독성 규칙을 따른다.
