# D4-07_Others — 기타 도식



다른 하위유형에 속하지 않는 비정량 도식이다. 관계를 정의하는 배치·선·면·기호와 단순 장식을 구별하고 요청 관계를 최소한의 구조로 표현한다. 수량/비례를 암시하는 면적·축 눈금을 임의로 더하지 않는다. supported schematic 기본 관계를 먼저 생성하고 미지원 구조만 벡터로 보충한다.

## comparison — 전후·좌우 비교판

- 두 대상의 전후 상태나 여러 특성을 대응시키는 판이다. 좌우 대상, 중앙 항목 타원, 위아래 전후 패널, 수평 대응선처럼 요청한 배치와 대응 관계를 보존한다. 관계선이 있다는 이유로 flowchart로 재분류하지 않으며, 판정 질문·예/아니오·절차 화살표를 추가하지 않는다. 실제 판정/절차 분기가 있는 요청은 flowchart다.
- node-diagram의 실측·대응 행·연결 축 원칙을 적용한다. 같은 역할의 항목/패널을 정렬하고 대응선은 무방향으로 둔다. 요청한 타원·외피·구분선은 실제 지원되는 schematic 요소를 사용하고, 지원되지 않는 부분만 편집 가능한 일반 벡터로 보충한다. 비교판 전용 layout이나 타원 노드의 앱 지원을 추측하지 않는다.
