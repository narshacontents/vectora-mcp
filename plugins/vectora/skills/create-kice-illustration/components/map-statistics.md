## 통계 자료가 있을 때

- 공간 단위·자료 시점·값·단위·결측을 맞춘다. 국가/행정구역을 혼용하지 않고 하위 경계가 없는데 국가 경로로 소지역 값을 대신하지 않는다. 표 행 ID와 검증 feature ID를 명시적으로 대조하고 미매칭/중복을 남긴다. 자동 join/단계구분/기호 생성/통계 갱신은 실제 지원 전 주장하지 않는다.
- 래스터 명암은 지표별 방향을 확인한다(인구밀도 검정=높음과 야간 빛 흰색=많음 등). 원자료·농도 방향·단위·범례를 보존한다.
- 단순 범례/수치 라벨/통계 기호는 선택한 지도 하위유형 안에서 처리한다. 지도 둘레에 별도로 배치한 자체 축/구성비/수치 구조의 독립 차트는 전역 복합으로 라우팅하며 native 생성기로 기본 구조를 만든다. 비교 패널은 등급·원 크기·차트 축을 공통화하거나 차이를 명시한다.
- 경위선은 불투명 정량 기호 아래에 두어 원이나 막대를 관통하지 않게 한다. 범례의 배경은 범례 기호·연결선·문자보다 뒤에 둔다. 값·최댓값·폭을 바꾼 뒤에도 지도와 범례의 대응, 기호 중첩 순서, 모든 연결선의 가시성을 함께 확인한다.
- 등치면처럼 육지·바다에 연속되는 수치 면은 불투명 바탕 위, 판독에 필요한 해안선·경계·문자 아래에 둔다. 값을 낮은 순서로 덮는 경우 각 등급의 면과 구멍을 보존하고, 지도와 범례의 농도 방향이 같은지 확인한다. 비교 패널의 범례 제목·수치·경위도 문자를 8pt로 먼저 측정해 지도 창의 공통 크기를 정한다. 패널 간격은 문자까지 포함한 실제 외곽에서 잡고, 범례 높이를 맞추려고 패널 사이에 큰 빈 띠를 만들지 않는다.

국가/행정 단위의 값 구간은 `execution/modules/map-thematic-native.md`, 연속 격자·등치선은 `execution/modules/map-scalar-native.md`를 해당할 때만 읽는다. 비례 기호·유량을 이 두 표현으로 바꾸지 않는다.
