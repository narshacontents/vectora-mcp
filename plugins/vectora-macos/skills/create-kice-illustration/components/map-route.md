## 경로·연결·이동이 있을 때

- 무방향 지점 묶음/쌍 연결도 포함한다. 연결 관계와 이동 의미를 구별하고 제공된 출발·도착·방향·경유·시점·수량만 표시한다. 빈/채운 원이나 양끝 점의 범례가 방향을 정의하면 그대로 따르며 양방향을 일방향으로 바꾸지 않는다.
- 관계 직선·실제 경로·대권 연결을 구별한다. 임의 곡선을 실제 항로/최단거리로 설명하지 않는다. 이동량은 정의된 굵기 단계/비례 굵기와 범례로 표시하며 문체상의 선폭을 수량으로 추정하지 않는다. 수량 없는 위치 연결은 가는 선과 작은 촉에서 시작한다. 촉을 판독 가능하게 만드는 것과 크게 만드는 것을 구별하고, 짧은 경로의 촉이 점 표식보다 과하게 커지거나 선 대부분을 차지하지 않는지 본다.
- 교차/겹침은 곡률·레이어·라벨 간격으로 해결하되 출발/도착 anchor를 보존한다. 촉의 실제 끝과 기호 중심을 대조한다.
- 도착점의 원 표식이 화살촉을 덮지 않게 한다. 실제 지리 anchor와 점 중심은 유지하며, 표시 경로의 끝만 원 외곽에 접속시키거나 마지막 구간에 촉을 두어 인쇄 크기에서 방향이 읽히게 한다. 일반 선의 작은 기본 촉을 그대로 채택하기 전에 표식 크기와 함께 확인한다.
- 일반 path의 끝별 arrowStart/arrowEnd는 방향이 주어진 끝에만 적용한다. 무방향은 촉 없는 선이다. 날짜변경선은 등록 도법으로 분할해 화면 양끝을 잘못 잇는 긴 선을 막는다.
- 같은 바탕/투영에 검증된 경로 SVG는 보완 가능하나 MCP의 대권 계산/날짜변경선 자동 분할을 실제 지원 전 가정하지 않는다.
