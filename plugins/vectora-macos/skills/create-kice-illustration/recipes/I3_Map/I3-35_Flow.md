# I3-35_Flow — 유선도

양적 주제도. 각 화살표의 이동 방향과 양을 수량 등급·선폭·범례로 연결한다. 자료의 단위와 원수량을 유지한다.

- 같은 지도의 geographic point overlay ID를 출발·도착점으로 사용한다. `flow.unit`은 authored 수량·범례 단위다. 준비 단계의 단위 환산은 사용자가 명시한 경우에 한해 수행하고 원자료 단위·자료 출처와 결과 단위를 밝힌다. flow에 수량·등급·선폭을 작성한 뒤에는 편집이나 자료 갱신 때 값을 다시 환산하거나 스타일을 재조정하지 말고, 원수량(0 포함)과 authored 단위를 보존한다. 임시 지점 이름·값을 넣지 않는다.
- 현재 native flow 계약은 **명시적 구간 등급 선폭**이다. 1–8개 등급은 0부터 빈틈·겹침 없이 이어지고, 마지막 상한만 비운다. 각 등급에 표시 문구와 물리 선폭(pt, 0.2–3)을 지정하며 폭은 등급 순서대로 커진다. 범례에는 단위와 등급 문구를 연결한다. 세 등급으로 고정하지 않는다.
- flow map은 실제 연결 앱의 live `vectora_map_plan` 기능·스키마가 top-level `flow`를 공개하고 native 수용을 확인한 경우에만 native flow를 우선 사용한다. 저장소 코드·정적 계약이나 UI 노출만으로 설치 앱 지원을 단정하지 않는다.
- live native 지원이 확인되면 수량 자료와 등급을 일반 `routes`로 바꾸지 않는다. 일반 단순 경로는 기존 기본 선폭 0.3pt를 유지하고, 수량 흐름을 그 기본 폭으로 정규화하지 않는다.
- 현재 계약은 연속 비례 폭, 실제 항로·대권·곡선 경로를 정의하지 않는다. 요청에 필요하면 지원되는 지도·지점 연결은 유지하고 미지원 수량 경로와 대응 범례만 별도 벡터로 보충한다. 연결이 수동/비연동임을 밝히고 전체 지도의 관리 연결을 해제하지 않는다.

한 지점에 여러 화살표가 모이거나 방향이 반대로 바뀐 경우에는 실제 끝점을 유지하면서 화살촉들이 구별되도록 끝 여유·경로 배치를 정한다. 공통 출발점의 검은 덩어리에 역방향 화살촉이 묻히면 불통과다. 0인 자료는 보이는 선이 없더라도 값과 안정 ID를 유지한다.
