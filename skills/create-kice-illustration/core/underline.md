# 본문 부분 밑줄

원문자와 답란을 함께 표시할 때도 한 줄의 네이티브 문자 서식으로 만든다. `㉠` 뒤의 답란은 같은 기준선에서 반칸 뒤로 이어 붙이고, **원문자 양옆에 같은 길이의 밑줄이 필요하면 동일한 종류·개수의 공백을 양쪽에 둔 한 문자열 전체**에 밑줄을 적용한다. 원문자 다음 줄에 공백·밑줄을 따로 만들지 않는다. 공백까지 포함된 밑줄의 실제 길이·중심과 재열기 보존을 확인한다. 원문에 명시된 별도 줄의 답란은 그대로 유지한다.



**밑줄은 같은 글상자의 네이티브 서식** `textRange`의 `underline:true`/지원되는 `doubleUnderline`으로 적용한다. 재조판·재열기 뒤 저장 범위의 실제 문자열과 JPEG를 대조한다. 정확한 논리 문자 범위를 보냈는데 줄바꿈 뒤 서식이 밀리는 증상이 재현될 때만 execution/workarounds/underline-wrap.md의 임시 우회를 적용한다. 생성기/가져오기의 별도 밑줄도 문자 서식으로 고치며 line/path로 흉내 내지 않는다. 문장 빈칸의 순서·기준선을 유지한다.

원문자가 **뒤 밑줄 본문을 지칭**하면 `㉠ 본문`처럼 원문자 뒤에 Alt+Space 반칸 U+2002 하나를 넣고 원문자·반칸은 밑줄 범위에서 제외한다. 원문자 자체가 답란 중앙에 든 경우에는 양옆 동일한 공백과 원문자 전체에 밑줄을 적용한다. 최종 문자열의 논리 grapheme 인덱스로 범위를 계산하고 재조판·재열기 후 확인한다. 두 경우를 혼동하지 않는다.
