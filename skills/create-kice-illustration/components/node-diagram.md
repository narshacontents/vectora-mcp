## 도식 공통·조건부 배치

- 대상과 관계를 먼저 확정한다. 노드/영역과 연결표(출발·도착·방향·분기 문구)를 요청에서 작성하고 미지수·빈 질문을 풀지 않는다. 노드형 도식에서 질문·특성은 흰 직사각형, 짧은 대상/결과는 원 또는 직사각형이다. 같은 역할의 짧은 노드는 형태·기본 크기를 맞추되, 독립 노드를 다른 긴 설명 노드에 맞춰 모두 키우지 않는다. 여러 행을 좌우로 비교하는 판은 대응 행의 높이를 가장 긴 내용에 맞춰도 된다. 이때 그 행의 필요한 실측 높이만 쓰며 다른 행까지 키우지 않는다. 크기가 다른 대응 노드는 중심과 연결 축을 맞춘다. 명시된 동일 크기는 보존하며 모든 질문을 마름모로 바꾸지 않는다.
- 연결이 있으면 특성 대응은 무방향, 절차·판정은 방향, 상호 관계는 의미에 따라 무/단/양방향이다. 교차는 접속이 아니다. 실제 공유 줄기만 하나의 분기점으로 만들고 공통 특성 상자를 복제하지 않는다. 화살촉 끝은 도착 윤곽에 닿으며 도형 안으로 들어가지 않는다.
- 글상자를 조판한 뒤 사방 여백으로 노드 크기를 정한다. 측정 폭은 노드 외곽이 아니라 생성기의 안쪽 여백을 뺀 실제 글 프레임 폭이다. 짧은 이름을 한 줄로 둘 때도 실제 행수를 확인하고, 여러 줄이면 글 높이에 맞춰 외곽 높이를 함께 정한다. 짧은 특성은 얇고 긴 띠, 대상 원은 짧은 글만 담으며 단문 띠 높이의 약 1.2–1.6배 지름부터 검토한다. 여러 줄 문장에는 그 비율을 강제하지 않는다. 반복 띠 사이 틈은 높이 약 1/3, 분기 문구·촉을 담는 순차 통로는 약 3–7mm부터 조정한다.
- 연결은 수평·수직·간결한 사선으로 출발·꺾임·도착을 정렬한다. 같은 수준의 가지·병렬 판정·결과 높이를 맞추며 불필요한 긴 빈 선을 줄인다. 꺾임 통로를 도형 밖에 예약하고 의미와 무관하게 글을 관통하는 연결선은 경로/라벨 배치로 해결한다. 경계선 위 제목·구간명처럼 의도된 겹침에는 공통 규칙의 작은 흰 배경을 사용한다. 범례는 단계 간격을 밀어내지 않는 공간에 둔다. 단계 간격은 실제 노드 높이·분기 문구·촉에 필요한 통로로 정하고 전체 높이에 비례해 늘리지 않는다. 수평 대응만 있는 비교 행 사이에는 수직 분기 통로가 필요하지 않다. 좌표를 직접 정할 때도 각 행의 최대 실측 노드 높이와 필요한 연결 통로를 먼저 구하고, 이를 누적하여 다음 행의 위치를 정한다. 짧은 노드들을 전체 높이에 균등 분산하거나 고정된 큰 행 간격으로 배치하지 않는다. 공유 결과·부수 표식의 위치는 이 행들을 정한 뒤 맞춘다.
- 묶음 대상 원은 묶음 중심 높이, 공유 결과는 관련 질문 사이 높이로 조정할 수 있다. 과거 도형 수·좌우 위치를 틀로 고정하지 않는다. 이동 후 선·촉·라벨을 다시 맞추고 연결표와 모든 선을 대조한다. 노드의 텍스트 프레임·글 획이 내부 여백을 포함해 상자 안에 들어가고 상자와 글이 그룹/클립 경계에서 잘리지 않는지 확인한다. 범례 열은 실제 문구 폭으로 정해 짧은 낱말의 한 음절 고립을 피한다.
