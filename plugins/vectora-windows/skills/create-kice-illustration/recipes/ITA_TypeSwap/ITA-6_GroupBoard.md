# ITA-6_GroupBoard — 여러 명 + 활자 보드

활자 교체형. 여러 사람 + 활자만 있는 보드·화면

여러 화자가 하나의 활자 자료판을 읽거나 설명한다. 읽어야 할 제목·본문·문장 속 박스는 가리지 않으며, 보드의 빈 면·테두리는 말풍선이나 인물이 덮을 수 있다. 화면 속 이름을 추가 화자로 세지 않는다.

공동 장면은 보드·발언 열·인물·탁자를 따로 완성해 쌓지 말고 하나의 구도로 설계한다. 제목의 실제 높이와 최소 간격부터 발언 영역을 잡고, 문구량에 맞게 열 폭을 배분한 뒤 자연 줄바꿈 높이로 보드와 인물 위치를 정한다. 문구가 늘어난 열을 오히려 가장 좁게 남겨 세로 탑처럼 만들지 않으며, 폭·내용 수정 때도 열 배분을 다시 계산한다. 짧은 발언을 긴 발언 높이에 억지로 맞추거나 장식용 윗공간·탁자 다리 때문에 전체 높이를 늘리지 않는다. 원화에는 필요한 얼굴·상체·손·탁자 면이 보이는 구도를 지정한다. 요청하지 않은 무릎·의자 하부·탁자 받침 전체는 생략하고 탁자 앞쪽이 화면 아래로 자연스럽게 이어져도 된다. 칠판의 회색 구조 프레임·받침은 [학습 화면·게시판](../layouts/board.md)의 칠판 원칙을 따르며, 공동 장면이라는 이유로 가는 선 상자로 바꾸지 않는다.

공동 보드의 단일 제목은 별도 정렬 지시가 없으면 보드 안쪽 폭을 기준으로 가운데 정렬한다. 제목과 문단 박스를 한 편집 글상자에 넣고, 박스 적용 후 실제 글 획의 중심을 확인한다. 넓은 왼쪽 정렬 프레임 자체만 가운데 두거나 임의 x좌표로 맞추지 않으며, 폭이 바뀌면 제목의 정렬 기준도 함께 갱신한다.

제목 아래에 발언군을 배치할 때는 **제목의 실제 글 획 하단→가장 높은 말풍선 몸통 상단을 약 1–2mm**부터 잡는다. 원화 배치를 계산한 뒤 이 간격으로 발언군 전체의 시작점을 정하며, 제목용으로 고정 y좌표나 큰 빈 띠를 먼저 예약하지 않는다. 제목·문구·폭이 바뀌면 같은 관계로 다시 계산한다.

착석 장면에서는 사람마다 같은 탁자 면을 향하도록 몸통·팔·손의 접촉 위치를 맞춘다. 타원 탁자 위의 손을 모두 같은 y에 놓아 옆 사람의 손만 공중에 뜨게 하지 않는다. 폭이나 발언 길이를 바꿀 때 글상자→몸통·꼬리→인물→보드·탁자 순으로 종속 배치를 갱신하며, 지원되지 않아 수동 보충한 관계는 자동 편집으로 보고하지 않는다.

여러 인물이 같은 가구에 기대거나 물건을 함께 다루어 팔·몸통의 가림과 원근이 이어지는 장면은 **인물과 그 지지물을 한 장면 원화로** 먼저 설계한다. 원화의 사람별 두개부 위치를 확인해 말풍선과 이름을 연결하고, 실제로 읽을 글·문단 박스·표·그래프·보드 제목은 독립 편집 요소로 남긴다. 개별 인물을 자유롭게 옮겨야 하거나 단순한 접촉만 있는 경우에는 분리 원화 방식을 사용할 수 있지만, 손끝 한 점의 일치로 몸통·팔의 부자연스러운 단절을 통과시키지 않는다.

2–3명이 중심인 구도는 최종 폭에서 머리 하나의 가시 폭 **10–15mm**를 출발점으로 인원·상체·탁자 폭을 함께 계획한다. 자료판이 주자료이거나 여러 학생이 한 줄에 있는 구도에는 이 크기를 일괄 적용하지 않는다. 자료와 발언을 먼저 실측하고, 남은 영역에 식별 가능한 머리·어깨만 들어가도록 더 작게 설계한다. 원화의 실제 머리 폭과 어깨 하단을 최종 mm로 확인하며, 생성 결과가 계획보다 크다고 자료를 줄이거나 장면 높이를 자동으로 늘려 합격시키지 않는다. 뒤에 독립 보드가 있는 구도는 생성 단계부터 장면 윤곽 밖을 투명하게 요청하되 피부·옷의 흰 면은 불투명하게 유지한다. 투명 바깥 영역과 가시 폭을 검수한 뒤 배치한다.
