# I3-12_Topographic — 지형도

일반도. 지형 등고선·하천·지도 기호의 대축척 지형도, 해발 고도 등고선 모식

- DEM 등고선은 요청한 봉우리·능선·골짜기가 자료 범위와 해상도에서 실제로 판독되는지 먼저 확인한다. 기호 중심/인출선 끝을 원자료 고도와 등고선 형상에 대조하며 빈 공간이나 다른 지형을 요청 지형으로 명명하지 않는다. 해상도·범위가 부족하면 적합한 실자료를 확보하거나 미충족으로 남긴다.
- 실제 지형도의 등고선은 사각 틀 전체를 채운다. DEM은 틀보다 넓게 받아 등고선을 계산한 뒤 틀로 잘라, 모서리에 등고선 없는 흰 빈 곳이 남지 않게 한다. 표고 숫자는 등고선 방향을 따라 회전해 선 위에 얹고, 주곡선은 가늘게·계곡선(5번째 선)은 조금 굵게 둔다. 자료 가장자리에서 생긴 평행 줄무늬·끊긴 선은 틀 밖으로 잘라낸다. 등고선은 약간 매끄럽게 다듬어 잔물결을 줄이고, 강조 파선 폐곡선도 매끈한 곡선 하나로 그린다. A·B·C 문자와 지시선은 틀 안 빈 곳에 두고, 축척은 틀 안 모서리의 흰 칸에 '0'과 '1 km'를 막대 양끝 위에 떼어 쓴다. 틀 비율은 의뢰 범위에 맞추되 대상(호수와 표시 지형)이 가운데 오게 자른다.
- 시험지 지형도는 판독용으로 성기게 그린다. DEM을 먼저 평활화한 뒤, 틀의 짧은 변을 가로지르는 등고선이 대략 15–25개가 되도록 등고선 간격을 고른다(원자료의 촘촘한 간격을 그대로 쓰지 않는다). 선은 모두 검정이며 주곡선은 고른 가는 굵기, 계곡선만 약간 굵게 둔다. 회색 선, 짧은 잔선 조각, 흐릿한 보조선은 남기지 않는다. 강조 파선은 등고선보다 확실히 굵고 대시가 뚜렷해야 하며, 의뢰된 급경사·절벽 기호는 해당 위치에 짧은 빗금으로 그린다.

- **가상 지형 개략도**는 실제 DEM·세계지도 프리셋을 억지로 사용하지 않는다. 주어진 봉우리·높이·능선 관계로 편집 가능한 등고선을 구성하고 실제 측량 자료와 구별한다. 등고선은 같은 높이의 선이며 특별한 지형 조건 없이 교차하지 않는다.
- **지형도와 단면도를 함께 제시**하면 A–B의 방향·거리 대응과 등고선 교차 높이를 하나의 자료로 계산한다. 구간별 직선 단면이면 해당 구간에서 보간해 교차 위치를 정하고, 임의의 동심원을 그려 수치만 붙이지 않는다. 단면의 값을 바꾸면 대응 등고선과 봉우리 표식·숫자도 함께 다시 확인한다. 단면선 밖의 형태는 주어진 지형 관계를 해치지 않는 범위에서 설계한다.
- **등고선 값**은 어느 선의 값인지 분명하도록 해당 선에 붙여 배치하고, 선이 글 획을 관통하면 공통 흰 받침 규칙으로 그 선만 짧게 끊는다. 선에서 떨어진 등고선 값을 봉우리 높이와 나란히 두어 두 종류의 고도가 혼동되게 하지 않는다. **봉우리의 점고도**는 표식에 가까이 두되 다른 등고선을 가려서는 안 된다. 좁은 닫힌 선 안에 숫자가 들어가지 않으면 표식과 연결되는 짧은 인출선으로 바깥에 두는 등 위치를 조정한다. 숫자를 넣기 위해 봉우리·단면 교차 위치를 옮기거나 흰 받침으로 인접 등고선을 지우지 않는다. 단위는 수치에 붙이거나 해당 패널의 가까운 단위 표기로 소속을 분명히 한다.
