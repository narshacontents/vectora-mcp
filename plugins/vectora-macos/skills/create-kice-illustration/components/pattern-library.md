## 반복 무늬를 저장하고 재사용할 때

- 현재 제작 또는 사용자가 요청한 원본 검수에서 재사용할 새 무늬를 정하면 사용자 무늬 견본 목록에서 유사 항목을 먼저 찾는다. 없다면 현재 그림에서 검수한 점·선·간격·각도·채움·그라데이션을 재사용 가능한 견본으로 저장한다. 기존 문항의 지도 윤곽·라벨·배치를 견본에 포함하지 않는다.
- 이름은 ‘짧은 사선’, ‘가장자리가 흐린 점무늬’처럼 표현을 설명하고, 확인한 출처·추정 치수와 불확실성은 메모에 남긴다. 참조에서 직접 확인한 설정과 일반적인 제작 시작값을 구별한다. 같은 무늬를 이름만 바꾸어 중복 저장하지 않는다.
- 무늬의 점·선 색과 바탕색은 별도로 결정한다. 흰 바탕의 점무늬를 회색 강조 면 위에 올릴 때 원래 회색이 남지 않도록 native `background:{mode:"color",color:"#FFFFFF"}`를 지정한다. 원래 채움 유지와 투명은 각각 `source`·`transparent` 모드이며, 지도와 범례에 같은 바탕을 적용한다. 지원 필드는 현재 연결본의 스키마로 확인한다.
- 견본은 시작 설정이다. 자료의 의미와 최종 인쇄 크기에 맞춰 점 간격·선폭·각도·회색을 조절할 수 있다. 무늬를 적용할 영역의 형태나 자료값을 견본에 맞춰 바꾸지 않는다. 지도와 범례에는 같은 물리 밀도를 쓴다.
- 연결본의 `vectora://pattern-library`를 확인하고 `vectora_pattern_library`의 list/get → save → apply 경로를 쓴다. save는 검토한 native 무늬/그라데이션 도형 또는 appearance를 받아 형상과 독립된 설정을 저장한다. 같은 ID 갱신은 명시적 upsert로 하고, 저장 결과를 다시 조회한다. 지원되는 점/사선·엇갈린 점·linear/radial gradient 외 모티프를 임의 치환해 ‘저장 완료’라 하지 않는다.
- 표·그래프·지도 생성기에 속한 도형은 소유 컴포넌트의 지원 설정으로 반영한다. 개별 도형을 별도 무늬 컴포넌트로 바꾸어 값 편집·재생성 관계를 끊지 않는다. 지원되지 않으면 한계를 기록하고 원자료와 연결되는 보완 경로를 선택한다.
- 막대의 가로줄·세로줄·격자는 같은 사선에 회색만 달리해 대신하지 않는다. 연결본이 지원하면 직사각형 막대 계열의 `pattern:"hatch"`, `patternAngle`(0° 가로·90° 세로), `patternCross`(직교 격자)로 지정한다. 범례도 같은 설정을 쓰며 바탕색은 `fill`로 분리한다. 지원 여부는 현재 스키마로 확인한다.
- 적용한 무늬는 문서 자체에 남아야 한다. 저장·재열기 뒤 채움과 클리핑을 확인하고, 사용자 견본의 이름 변경·삭제 때문에 기존 그림이 변하지 않도록 한다.
