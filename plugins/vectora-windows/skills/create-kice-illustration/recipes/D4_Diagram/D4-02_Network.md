# D4-02_Network — 관계도

임의 연결·인과·화살표 관계

임의 연결·인과·상호 관계이며 각 선의 방향과 관계명을 연결표에 대조한다. 순환은 각 출발/도착을 따로 검사하고 여러 종류의 흐름은 선종류/범례로 구별한다. 우회·곡선은 순환을 읽는 데 필요한 경우에만 쓴다. 인물 노드가 요청되면 이름·소속은 가까운 바깥, 관계명·기호는 연결 통로에 두며 말풍선 대화로 바꾸지 않는다. 얼굴 원화가 필요한 경우 전역의 원화 실행 규칙으로 실제 자산을 만들고 빈 인물 자리표시자로 끝내지 않는다. 노드의 affiliation/affiliationSide:left|right는 제공된 소속만 넣는다.
