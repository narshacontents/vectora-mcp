# I3_Map — 지도

공간 기준 위 위치·분포·영역·이동을 표현한다. 비복합 제작의 지침은 `SKILL.md → 이 문서 → 선택한 하위유형 한 문서`로 끝난다. 도구의 실제 스키마·응답, 선택 자산의 manifest와 실제 자료는 확인할 수 있으나 다른 실행/규칙 문서를 추가로 읽지 않는다.


## 핵심 정보로 한 하위유형 선택

| 세부유형 | 선택 기준 |
|---|---|
| `I3-11_Locator · 위치 지시도` | 일반도. 칠한 면·그은 경계·점이 정답 후보 자리일 뿐이고 (가)·A~E로 '어디(어느 나라)인가'를 맞추게 함. 면을 칠했든 아니든, 범례가 수도·국경 기호뿐이면 여기 |
| `I3-12_Topographic · 지형도` | 일반도. 지형 등고선·하천·지도 기호의 대축척 지형도, 해발 고도 등고선 모식 |
| `I3-13_OldMap · 고지도·실물 지도` | 일반도. 기존 지도의 사진·스캔(옛 세계 지도, 대동여지도, 점토판). 표현 방식보다 우선 |
| `I3-14_Others · 기타 지도` | 일반도. 평면·배치도, 반구·지구본, 특수 투영 모식, 카토그램 |
| `I3-21_Area · 영역 구분도` | 질적 주제도. 범례·라벨·설명이 면이 무엇의 범위인지(언어권·암석·산업 지역·왕조 영역·빙하·호수 범위) 알려 주고, 그 범위·변화 자체가 정보 |
| `I3-22_Route · 경로·선 기호도` | 질적 주제도. 양 없는 선: 원정로·교역로·이동 경로·산줄기·사건 순서 |
| `I3-23_Symbol · 점 기호도` | 질적 주제도. 범례가 점 기호(●□△)에 범주를 줌 |
| `I3-31_Choropleth · 단계 구분도` | 양적 주제도. 구역·격자별 음영 등급이 값의 구간 |
| `I3-32_Dot · 점묘도` | 양적 주제도. 점 하나 = 일정량, 점 개수로 분포 |
| `I3-33_Proportional · 도형 표현도` | 양적 주제도. 지도 위 제자리의 원·막대·풍향 장미 크기·구성이 값. 지도 둘레에 따로 그린 차트를 지시선으로 이은 것은 D2 |
| `I3-34_Isoline · 등치선도` | 양적 주제도. 기온·강수량 등 통계값의 같은 값을 이은 선. 지형 등고선은 I3-12 |
| `I3-35_Flow · 유선도` | 양적 주제도. 화살표 굵기로 이동 방향과 양 |


## 모든 지도의 공통 원칙

지리 기준 위의 위치·범위·방향·경계·자료 시점을 유지한다. 원자료의 투영·범위·시점과 실제 지원을 구별하고, 근거 없는 지물·수치·경계를 만들지 않는다. 문자/범례는 지리 도형과 독립 편집하며 내용 좌표를 움직여 겹침을 해결하지 않는다. 최종 크기와 확대에서 위치·주제 의미·인출선 끝·섬·잘림·선명도를 확인한다.

기존 지도 사진/스캔은 `I3-13_OldMap`을 우선한다. 새 바탕이 필요한 지도만 실제 프리셋에서 시작한다. 같은 회색 면도 후보 위치이면 Locator, 범주 영역이면 Area, 값 구간이면 Choropleth다. 기온/강수 등치선은 Isoline, 고도 등고선은 Topographic이다. 범례가 정량/정성/위치 중 무엇을 뜻하는지 먼저 확인한다.

## 선택 세부 문서 준비

- `--features`: 한국 바탕 korea, 확대/패널 inset, 위치점 points, 면 강조 area, 경로 route, 통계 statistics, 자연층 natural, 판/빙상 tectonic-ice, 역사 historical, 도법/시차 projection, DEM dem. 해당 세부유형에 필수인 조건은 자동 포함되므로 중복 지정할 필요 없다. 고지도 원본은 프리셋을 자동 요구하지 않는다.
