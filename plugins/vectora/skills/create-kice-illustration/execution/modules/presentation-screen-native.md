# 발표 화면 위 발언 네이티브 실행

발표자 한 명의 발언이 화면 위에 있고 자료판이 아래에 오는 화면형 발표에만 적용한다. 지원되는 경우 `layout:"presentation"`, `mode` 또는 `presentationMode:"screen"`, `presentationOptions.layout:"speech-above-board"`를 사용한다. 실제 문구를 먼저 실측하고 말풍선·자료판의 폭을 정한 뒤, 검수한 발표자 원화와 자료를 포함해 컴포넌트를 생성한다. `speechWidthMm`·`boardWidthMm`과 간격 옵션은 전체 구도에 맞춰 계획하고 실시간 스키마의 허용 범위를 따른다. 이 배치에는 흉상 또는 전신과 바깥쪽 이름을 사용한다. 얼굴 단품·아래 이름·연단 병용은 다른 지원 배치를 선택한다. `screenText`와 `screenGraph`는 둘 중 하나만 사용한다.

사용 전 현재 `vectora://production/dialogue/schema`와 `vectora://production/dialogue`에서 이 필드와 화면 배치 지원을 확인한다. 추가 필드 허용이나 앱 소스만으로 지원을 판단하지 않는다. 공개되지 않은 옵션은 보내지 않고 지원되는 화면형 발표 경로를 사용하며, 지원되지 않는 구도나 편집 제약은 구별해 기록한다.

발언이나 화면 본문을 바꾸면 같은 네이티브 대화 컴포넌트를 갱신해 화면·발표자·그래프가 함께 재배치되게 한다. 개별 요소를 따로 밀어 맞추지 않는다. 갱신 뒤 실제 말풍선·자료판 폭, 이름의 글자 획, 흰 내용 면의 잘림·가림과 발표자/자료판의 정렬을 확인한다.
