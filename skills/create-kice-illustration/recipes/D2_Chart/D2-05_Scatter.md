# D2-05_Scatter — 산점·버블

두 정량 지표 좌표점. 버블 포함

인구 구조처럼 두 비율과 규모를 함께 읽는 형식의 기본은 2028 예시문항의 구성이다. 얇은 사각 자료 영역 안에 양방향 주요 파선을 두고, 밝기 등급과 원 면적은 서로 다른 변수로 유지한다. 원 바깥의 이름은 짧은 가는 인출선으로 해당 원에 연결한다. 자료가 없는 위쪽 공간이 충분할 때 규모의 겹친 원 범례와 명도 범례를 작은 흰 상자로 모으되, 실제 점·원과 겹치면 밖으로 옮긴다. 기본 배치를 맞추려고 좌표·면적을 변경하지 않는다.

각 점 중심은 실제 x·y이며 임의 연결·좌표 벌리기는 하지 않는다. 모양/채움으로 계열을 구별하고 밀집 라벨만 빈 방향/인출선으로 이동한다. 라벨의 글 획과 점 외곽·축을 함께 대조한다. 근접 표식은 중심을 유지한 채 열린/채운 모양·겹침 순서로 식별하고, 제공된 크기 변수가 없을 때만 가독성을 위한 공통 표식 크기를 조정한다. 작은 패널의 수십 개 점 구름은 지름 0.35–0.5mm부터 검토해 검은 띠로 뭉치지 않게 하며, 소수의 개별 라벨 표식에 이 값을 일괄 적용하지 않는다. 버블 크기는 별도 변수이고 면적/지름 비례를 확인한다. 면적 비례 반지름은 값 제곱근; 범례도 같은 변환이다. 큰 원의 가림/잘림을 배치로 풀되 비례를 바꾸지 않는다. 기준선·평균·회귀·이동은 각각 제공된 의미만 쓴다.

새 `chartStyle:"bubble",type:"line"`의 series.points는 `{x,y,size?,label?,fill?,labelOffsetMm?:{x,y}}`, size 비음수; 없으면 기본 크기이며 창작하지 않는다. values 배열도 필수다. `chartOptions.bubbleSizeScale,sizeLegend:[{value,label}],sizeLegendTitle,sizeLegendPosition:beneath|inside|right,sizeLegendLayout:row|nested`는 버블 전용이며 실제 크기 변환을 확인한다. 크기 범례의 겹친 원도 윤곽·수치 대응을 남긴다. 표식만이면 legacy `type:"points",series.points,xDomain,yDomain`와 실제 ticks, legend right/none을 사용할 수 있다; legacy 생략 안 점/눈금은 거부된다. 무늬/시점의 의미를 임의 부여하지 않는다.

명도/색이 구간별 범주를 뜻하고 각 점의 소속이 제공되면 **구간을 native 계열로 나누고 각 계열의 points에 해당 관측값을 넣어** 색 범례와 실제 원을 연결한다. 모든 점을 한 계열에 넣고 개별 fill만 바꾼 뒤 범례를 따로 그리는 것을 기본으로 삼지 않는다. 크기 범례와 색 범례를 함께 둘 때는 live 계약의 `legend`, `legendTitle`, `legendAnchor`와 `sizeLegendPosition`, `sizeLegendLayout`을 먼저 조합한다. 두 범례를 모두 inside로 놓을 수 있는 빈 자료 영역이 있으면 그 안에 모으며, 판독할 점·원·인출선과 충돌하는지 실제 잉크 범위로 검수한다. 범례가 있다는 이유만으로 본체 위에 별도의 큰 빈 띠를 예약하지 않는다. 값이나 소속이 바뀌면 원과 두 범례가 같은 자료 구조에서 다시 생성되는지 확인한다.
