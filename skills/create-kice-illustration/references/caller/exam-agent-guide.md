# 출제 에이전트의 일러스트 의뢰

출제자는 평가 요소·정답·자료 타당성을 정하고, `create-kice-illustration` 제작자는 그 내용을 편집 가능한 Vectora 그림과 JPEG로 만든다. 이 이름은 MCP 함수명이 아니다. 실제 작업 환경에서 스킬을 불러 제작을 맡기고, 그 환경에 원본 파일과 필요한 Vectora 도구가 연결되어 있는지 확인한다. 다른 컴퓨터의 경로만 전달해 파일이 공유됐다고 간주하지 않는다.

## 의뢰에 담을 내용

간단한 의뢰는 자연어 한두 문장으로 충분하다. 표·JSON·첨부 파일을 포함한 상세 의뢰도 그대로 받을 수 있으며, 복합 자료라는 이유로 내용을 짧게 줄일 필요는 없다. 다음 항목은 해당하는 만큼 알려준다.

- **그림의 역할과 의미**: 무엇을 보여 주거나 비교하게 할지, 풀이에 중요한 관계·순서·방향.
- **정확한 표시 내용**: 그림에 들어갈 원문·이름·기호·값·단위와 각 항목의 대응. 입력 자료 전체와 그림에 실제로 인쇄할 내용을 구분한다.
- **자료의 성격**: 제공된 실제 자료, 새로 조사할 실제 자료, 가상 자료, 정성 자료 중 무엇인지. 실제 자료라면 필요한 지역·기간·출처나 참조 파일을 준다.
- **보존·금지 조건**: 반드시 유지할 내용·관계·원본 특징과 그림에 넣지 않을 정답·해설·출제 맥락.
- **작업 범위**: 새 그림인지 수정인지. 수정은 제작자가 실제로 열 수 있는 기존 `.vectora`와 바꿀 내용, 유지할 조건을 함께 준다.

수치 자료는 의미에 따라 범주·계열·시점·값·단위·분모·결측 여부를 구분한다. 표는 행·열과 묶이는 머리글을, 도식은 연결의 방향과 포함 관계를, 대화는 화자별 정확한 발언과 순서를 알려준다. 이는 필요한 내용 정보를 전하기 위한 기준이며, 모든 자료에 모든 항목이 필요한 것은 아니다.

지도는 대상 지역·지점과 학생이 읽어야 할 위치 관계나 비교 자료를 알려준다. 섬·해협·하천·행정구역 자체가 핵심이면 이름을 명시하고, 크기에 제약이 있으면 최종 외곽 폭을 함께 준다. 원자료 상세도·단순화율·도법·국경·바다색은 재현 조건일 때만 지정하고, 그 외에는 제작자가 필요한 지물과 출력 크기를 보고 선택한다. 전체 세계지도는 태평양 중심이 기본이며, 대서양 중심이 필요한 의미나 재현 조건만 알려주면 된다. 실제 자료의 위치·값을 보기 좋게 바꾸는 것은 허용하지 않는다. 위치 식별용 작은 부분도인지, 교량·항로 등의 세부 관계를 읽는 확대도인지는 짧게 구분해 주면 과확대를 줄일 수 있다. 역사·문화권처럼 시점이나 분류가 달라지는 자료는 알고 있는 시점·주제를 알려준다. 출처 지도가 없으면 제작자가 공공·학술·교육 자료를 찾아 위치와 경계를 확인한다. 사용자가 세부 좌표를 전부 제공할 필요는 없으며, 분류가 여러 가지라 정답 해석이 달라질 때만 확인한다. 나란히 놓을 소지도·평면도 등 구도에 의미가 있으면 그 관계도 알려준다.

복잡한 지도에서는 **위치를 찾기 위한 지명과 실제 인쇄할 표기**를 구별한다. 예를 들어 도시명 목록을 주어도 인쇄 내용이 점과 A·B뿐이면 그렇게 말한다. 나라별 채색인지 바다까지 감싸는 문화권인지, 작은 표시가 위치 영역인지 인구 비례원인지, 경로가 육상·연안·직선 연결 중 무엇인지도 의미가 달라지는 조건이다. 이 조건은 생략하지 않되 점 지름·선폭·점선 간격 같은 일반 스타일 수치까지 의뢰자가 계산할 필요는 없다. 점 분포·비례원의 목록은 전체 대상인지 대표 사례만 고른 것인지도 구분한다. 제공되지 않은 위치·값을 채워 원본 자료를 복원했다고 주장하지 않는다. 범례가 A·B처럼 익명이어도 제작자에게는 각 범위가 뜻하는 주제를 알려준다. 예를 들어 사막과 사막화 발생 지역, 산림과 산림 파괴 지역은 같은 채색 범위가 아니며, 제작에 필요한 의미가 곧 인쇄할 정답 이름을 뜻하지는 않는다.

한국 행정 지도는 ‘서울 종로구와 중구만 남겨 줘’처럼 전체 지명을 알려주면 된다. 시 전체인지 일반구 단위인지가 의미에 영향을 주면 구분한다. 전국·권역·해안 확대 중 필요한 범위와 남겨야 할 섬·수역, 행정경계 기준 시점만 알려주면 제작자가 단순화와 작은 섬 표시를 고른다. 참조 그림을 의뢰문으로 옮길 때는 세로형을 전국도로 추정하지 않고 실제 권역을 확인하며, 자료 대상과 함께 보여 줄 주변 도시를 구별한다. 울릉도·독도 보존은 별도로 요청하지 않아도 적용한다. 한강·빙하·판 경계처럼 필요한 주제층은 명시하되 오래된 지역 프리셋 이름을 지정할 필요는 없다. 무늬는 표현하고 싶은 의미·참조 이미지 또는 이미 저장한 견본 이름만 주어도 된다. 제작자가 사용자 라이브러리를 조회하고 검토한 새 무늬를 저장하므로, 호출자가 점 간격이나 견본 ID를 설계할 필요는 없다.

그래프 의뢰에는 각 축이 뜻하는 지표·단위와 계열 대응을 알려준다. 이름·단위가 공통 제목이나 범례에 이미 표시되는지도 구분하면 불필요한 반복을 줄일 수 있다. 제목 방향·줄바꿈·범례의 가로/세로·안/밖 위치와 축 끝 여유, 축선·화살표·상자 프레임은 의미상 고정 조건일 때만 지정한다. 특정 기출의 재현이면 원본 파일과 최종 폭을 함께 전달한다. 전체 그림 폭과 내부 자료 영역의 폭은 구분하며, 글자 간격을 외곽 폭에 맞추기 위해 임의로 압축하지 않는다. 제작자는 원본과 같은 값·범위·물리 크기로 출력해 배치·선폭을 겹쳐 확인하며, 이미지에서만 읽은 통계값은 정확한 원자료로 단정하지 않는다. 제작자는 자료와 실제 글 크기를 보고 선택하며 수치·관계는 그대로 유지한다. 범례의 자동 충돌 회피는 초안이므로 실제 그림을 보고 빈 공간의 모양에 맞춰 위치·배열을 다시 고른다. 단위만 있는 Y축은 숫자열 위치를 유지하고 단위의 실제 글 획 중심을 선행 부호를 제외한 숫자 본체 잉크열 중심에 맞춘다.

산점·버블은 각 대상의 X값·Y값과, 크기가 수량이면 그 값과 의미를 함께 준다. 0이나 축 끝에 놓인 관측값도 그대로 전달한다. 원·눈금·범례의 충돌을 피하기 위한 좌표 변경은 의뢰하지 않으며, 제작자가 표시 영역과 글자 배치를 조정한다.

지도와 나란한 그래프를 함께 의뢰할 때도 단순화율·섬 면적·축 정렬 좌표를 따로 지정할 필요는 없다. 제작자가 지도의 판독 목적에 맞는 상세도와 비핵심 섬 생략을 함께 선택하고, 좌우 직교좌표 그래프는 Y축 양 끝의 실제 높이를 맞춘다. 자료 출처와 각주 내용은 구분해 전달하며, 각주 별표·반칸·본문 시작 열은 제작자가 typography 규칙으로 조판한다.

복합 자료는 동등 비교인지, 하나가 다른 자료를 설명하는지, 전체와 확대 부분인지 등 **읽는 관계**만 추가하면 된다. 구도 미지정이면 제작자가 폭과 내용의 종횡비를 보고 나란히·위아래·주자료와 보조자료 배치를 정한다. 요소별 좌표·간격을 의뢰자가 계산할 필요는 없다.

텍스트를 넣지 않고 공간만 남길 때는 그 뜻과 필요한 줄 수 또는 글상자 크기를 명시한다. 복합 그림은 각 블록에 들어갈 내용과 읽는 순서를 함께 전달한다. 특정 인물·유물·지역을 재현해야 하면 정확한 명칭을 알려 주며, 참조 자료가 있으면 함께 제공한다.

아래 형식은 선택 사항이다. 빠진 항목을 채우려고 내부 제작 방식을 설계하지 않는다.

```text
create-kice-illustration 스킬로 다음 그림을 만들어 줘.
그림의 역할/보일 관계: …
표시할 원문·자료: …
자료의 성격/출처: …
유지할 조건/넣지 않을 내용: …
최종 외곽 폭·납품 위치/이름: [필요한 경우]
```

## 제작자에게 맡길 것

내부 recipe·분류 코드·도구 인자·좌표를 의뢰자가 지정할 필요는 없다. 문항 의미에 관계된 상대 위치와 읽는 순서만 말하고, 말풍선·상자·행의 크기, 간격, 줄바꿈, 정렬, 꼬리 위치와 일반적인 외피 구성은 제작자가 정한다. 폭이 필요하면 **제목·범례·이름표 등 표시 내용을 모두 포함한 최종 그림 외곽 폭**을 말한다. 내부 글상자나 요소별 폭은 평가 조건일 때만 지정한다.

제작자는 제공된 문구와 확정 수치·단위·부호·순서를 임의로 고치거나 요약하지 않는다. 실제 자료의 조사를 맡길 때는 읽기 좋은 단위·반올림 등 표시 가공을 제작자에게 맡길 수 있다. 이때도 원자료와 산출·표시값을 구분하고 풀이에 필요한 관계와 정확도를 보존한다. 평가 의미를 바꿀 수 있는 모순이나 누락이 있을 때만 확인하고, 나머지 조판은 최신 제작 지침과 실제 연결 기능에 맡긴다.

## 대화 발언을 수정할 때

같은 구도의 발언을 고칠 때는 바뀐 문장과 화자, 유지할 인물·배치만 알려준다. 현재 연결된 네이티브 대화 기능에서는 세로대화 말풍선이 아래로 늘어나고 그 다음 발언이 내려간다. 가로대화와 발표형은 아래 접점을 유지하며 위로 늘어나고 기존 꼬리 곡률을 유지한다. 호출자가 말풍선 크기나 다음 행의 이동량을 계산할 필요는 없다.

이 자동 재배치는 연결된 대화 요소에 적용된다. 별도 자료판이나 연결되지 않은 개체까지 함께 움직인다고 보장하지 않으며, 제작자는 실제 소유 관계와 JPEG에서 가림·행간·꼬리 접점을 확인한다. 현재 환경에서 해당 기능이나 편집 도구를 쓸 수 없으면 가능한 범위와 한계를 알린다.

## 파일 접근과 납품

파일 경로와 도구 이름만으로 접근이나 기능을 가정하지 않는다. 제작자는 현재 세션에서 원본을 실제로 열 수 있는지와 필요한 기능이 연결되어 있는지 확인한다. 접근할 수 없거나 지원되지 않으면 필요한 파일·기능을 밝히고 완료된 것처럼 보고하지 않는다.

기본 납품은 같은 본체 이름의 편집 가능한 `.vectora`와 `.jpeg` 한 쌍이다. 지정한 파일명·폴더·확장자가 있으면 우선하며, 그 위치에 실제로 쓸 수 있는지 확인한다. 제작자는 저장본을 다시 열고 저장된 JPEG를 직접 확인해 원문·자료·관계와 최종 외곽을 검수한다. 회신에는 상태, 두 파일의 실제 경로, 실측 외곽 폭, 확인 결과와 남은 문제를 적는다. 별도 검수 보고 파일은 요청이 없으면 추가하지 않는다.

문항에 그림을 넣기 전에는 출제자가 자료 해석·정답 유일성·정답이나 개념의 불필요한 노출 여부를 확인한다.
