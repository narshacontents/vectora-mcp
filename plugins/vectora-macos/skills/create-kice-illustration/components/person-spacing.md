## 인물·말풍선·이름의 실제 간격

꼬리 끝↔자기 화자 머리의 실제 빈틈 **1–2mm** 출발. 가로 배치는 끝 높이↔정수리 세로, 옆 꼬리는 머리 윤곽과 가로 거리로 잰다. 옆 이름 글 획↔같은 높이 인물 윤곽 **0.8–1.5mm**, 아래 이름↔인물 하단도 **0.8–1.5mm** 출발. 이미지 사각/투명 여백은 제외한다. 기본은 화자와 말풍선의 배치를 먼저 좁히며, 몸통 확대에 맞춰 꼬리까지 확대하지 않는다. 장소 사진처럼 핵심 배경을 보존해야 하는 공유 장면에서는 비단서 영역을 따라 긴 곡선 꼬리를 설계할 수 있지만, 불필요하게 먼 인물 배치를 꼬리만 늘여 해결하지 않는다. 끝은 자기 얼굴/입을 향하고 닿지 않는다. 예약→승인 원화의 실제 경계 재계산→최종 합성에서 형태와 간격을 각각 검사하고 실제 mm를 기록한다. 흰 이미지 배경이 끝을 가리면 배치/바깥 면부터 고친다. 이름은 받은 것만 별도 문자, 반복 위치는 일관되게 유지한다. 비대칭 곡선 꼬리는 지원되는 네이티브 배치로 우선 구현하고, 지원되지 않을 때만 경로를 보완하며 후속 재조판 제약을 확인한다.
