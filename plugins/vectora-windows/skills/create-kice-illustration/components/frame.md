## 글을 담는 외피 — ITA·ITB·ITC에서 외피가 있을 때

흰 내용 면을 먼저 확보하고 외피·장식은 그 바깥의 얕은 프레임에 둔다. 장식 때문에 기존 내용 영역/예약 공간을 잠식하거나 외피를 불필요하게 확장하지 않는다. 회색 바탕은 **#CCCCCC–#D6D6D6**, 작은 강조는 **#888888–#999999** 또는 **#555555–#777777**를 출발값으로 사용하여 지나치게 희미하거나 성기지 않게 한다. 내부 여백 **외피 폭의 2–5%**, 나란한 카드의 가로 틈 **4–6%** 출발; 실제 글·빈 공간과 얕은 외피가 우선이며 단순 균등 확대하지 않는다. 세로로 이어지는 제목·자료·응답 상자에는 가로 틈의 비율을 재사용하지 말고 **1.5–2mm의 실제 외곽 간격**부터 조정한다. 의도된 응답란 외에는 일정 높이나 종횡비를 맞추려고 빈 띠를 더하지 않는다. 원본 사진에는 이 외피 팔레트/신규 작화 계약을 적용하지 않는다.

**공통 규격은 고정된 완성 디자인을 뜻하지 않는다.** 새 그림마다 요청의 매체·내용량·자료 배치에 맞춰 제호 띠, 가장자리, 조작 아이콘의 조합을 선택한다. 한 묶음의 서로 다른 그림을 만들 때 같은 외피를 관성적으로 반복하지 않는다. 사용자가 같은 서식을 요청하거나 한 문서를 수정할 때는 기존 선택을 유지한다. 다양성을 위해 본문 폭·선택한 문자 크기·필요 여백을 흔들거나 장식을 크게 늘리지 않는다. 정해진 몇 가지 옵션은 출발점이며 모든 그림을 그 목록 안에 한정하지 않는다. 회귀 검사에서 같은 틀을 고정하는 것은 허용하되 신규 제작의 기본 규칙으로 옮기지 않는다. 종이의 겹침·말림, 압정·집게, 프레임 모서리·받침, 화면의 탭·조작부 등에서 이번 매체와 구도에 맞는 작은 구조를 조합한다. 장식의 개수·좌표는 고정하지 않으며 없는 문구나 무관한 소품으로 차이를 만들지 않는다.

외형 미지정인 새 그림은 실행 옵션을 읽기 전에 **매체를 알아보게 하는 구조, 내용 블록의 관계, 가장자리/머리부의 처리**가 다른 두세 가능성을 짧게 생각한다. 내용·예약 공간·매체의 구조에 맞지 않는 안은 제외한다. 남은 안들이 모두 자연스럽다면 항상 첫 안이나 생성기 기본형을 고르지 말고, 이번 작업에서 난수로 하나를 선택해 그 선택을 유지한다. 같은 묶음에서는 이미 사용한 외피 구조를 우선 제외한다. 난수는 동등하게 적합한 외형 사이의 선택에만 쓰며 내용·서체·크기·가독성은 바꾸지 않는다. 요청이 특정 형태를 지정하거나 기존 그림을 수정하는 경우에는 무작위 선택을 하지 않는다. 선택한 구조와 선택 근거는 그림 밖 작업 기록에 짧게 남긴다.

API 옵션 이름을 나열하는 것으로 이 설계를 대신하지 않는다. 여러 이미지를 먼저 만들거나 사용자에게 선택을 요구할 필요는 없다. 일상적인 물건의 구조로 설명할 수 없는 장식은 덜어 낸다. 생성기는 그 설계를 구현하는 기본 부품이며 옵션 목록이 허용 디자인의 전부는 아니다. **실행 옵션을 읽은 뒤 편리하다는 이유만으로 선택한 외피를 기본형으로 되돌리지 않는다.** 지원되는 내용 조판은 유지하고 미지원 외피만 편집 가능한 개체로 보충한다.

같은 요청의 대안을 여러 개 만들 때는 설계 선택을 비교해 실제 외형이 구별되게 한다. **배경 대안은 본문을 가려 보아도 외피 구조가 구별되어야 한다.** 본문 단 나누기만 바꾸기·회색 농도만 바꾸기·작은 아이콘 하나 옮기기를 별도 배경 디자인으로 세지 않는다. 원문 순서·의미·요청 구도를 바꾸는 변주는 하지 않는다.

같은 매체의 대안을 다른 매체로 교체해 수를 채우지 않는다. 서로 다른 웹사이트를 요청했는데 같은 페이지에 태블릿·노트북 껍데기만 바꿔 씌운 결과는 사이트 디자인의 다양성으로 세지 않는다. 기기까지 요청된 경우에는 내용 화면과 기기 각각의 구조를 따로 설계한다. 다양성을 만들려고 좁은 제목 전용 열이나 큰 빈칸을 추가하지 말고, 제목과 자기 본문·회신의 소속이 자연스럽게 읽히는 구도를 유지한다.

여러 기사·자료와 해설·질문과 답변·붙인 메모는 **공유 외피 하나와 읽을 블록들의 관계**를 먼저 정한다. 동등한 병렬 자료, 주자료와 보조자료, 이어 읽는 답글을 구별해 열 폭·위계·시작선을 정한다. 독립 블록을 한 글상자로 합치거나, 모든 블록에 같은 카드 테두리를 덧씌우지 않는다. 제목·본문·작성자 등 역할별 글상자는 편집 가능하게 유지하며 같은 문단의 시각적 행은 나누지 않는다. 예약 공간은 각 블록에 필요한 연속 직사각형을 따로 확보하고 여러 빈틈의 면적을 합쳐 대신하지 않는다.

검수에서는 장식이 알아볼 수 있는 형태인지, 압정·테이프가 종이에 닿는지, 그림자가 실제 겹친 쪽에 작게 놓이는지, 받침의 물건이 떠 있지 않은지 확인한다. 외곽·안쪽 경계가 우연히 겹쳐 굵어지거나 흰 덮개가 접힘·곡선을 잘라내면 고친다. 여러 블록의 내용은 풍부해도 장식 면적과 추가 빈 띠가 읽을 공간을 잠식하지 않게 한다. 짧은 보조자료 아래의 자연스러운 여백과 큰 고정 슬롯이 만든 불필요한 여백은 구별한다.

본문·표·그래프가 함께 있으면 실제 내용의 높이부터 정한다. 라이브 계약이 지원하는 `blocks`의 text/graph/component 또는 composition으로 각 자료를 편집 가능한 자식으로 연결한다. 네이티브 표·그래프를 그림으로 굳히거나 외피 위에 무관한 좌표로 얹지 않는다. 미지원 외피를 직접 만들 때도 내용 그룹과 장식의 역할을 나눠, 본문/셀 변경 후 다음 자료와 하단 접힘·말이를 함께 재배치한다. 버튼·제목·본문의 서로 다른 영역은 실제 잉크 사이 1–2mm 이상을 출발 간격으로 확인한다.

본문이 제공된 외피는 마지막 내용의 실제 획/밑줄/표 하단 뒤 **약 2–3mm의 안쪽 여백**부터 맞추고, 접힘·말이·조작부는 그 밖의 얕은 영역에 둔다. 틀의 관성적인 종횡비나 장식 크기를 유지하려고 빈 하단 띠를 만들지 않는다. 지정 응답란·그림 자리 등 의도된 빈 공간은 따로 보존한다. 열마다 내용 길이가 다르면 가장 긴 열에 맞춰 짧은 열의 말풍선/내용 상자 높이까지 강제하지 않는다.

열 폭·패딩 조정으로 내부 표나 본문 높이가 줄어든 때도 같은 원칙으로 외피·하단 버튼·캡션을 다시 맞춘다. 늘어날 때만 외피를 키우고 줄어든 때에는 이전 높이를 남겨 두지 않는다. 별도 설계한 책 외곽·접힘선·종이 겹선은 지원되는 내용 크기 연동에 명시적으로 연결하고, 자동 소속이 없는 개체만 실제 내용 외곽에서 재배치한다. 자동 연결은 형태를 선택하거나 표지·옆 자료의 균형을 판단하지 않으므로, 내용 변경 후에는 그 균형도 실제 이미지로 확인한다.

본문 정렬은 함께 준비된 prose 원칙을 따른다. 연속 본문은 양끝 정렬·마지막 줄 왼쪽 정렬로 시작하며, 문단 마지막 줄의 단어 사이를 억지로 늘리지 않는다. 공개 계약이 마지막 줄 왼쪽 정렬을 지원하는지 확인하고, `justify`만 지원하여 마지막 줄까지 벌어지면 왼쪽 정렬을 임시 사용하고 한계를 기록한다. 공백 추가·수동 줄바꿈으로 양쪽 정렬을 흉내 내지 않는다.
