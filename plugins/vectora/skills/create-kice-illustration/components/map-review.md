전역 검증 단계에서 지도별로 대상·값·단위·범례·anchor/인출선 끝·섬/해협·projection/extent/동일 배율·경계 의미·수역색·패널 척도·네 변 잘림을 최종 크기와 확대 화면으로 대조한다. ready/issues 없음은 자동 라벨–점/테두리 회피나 시각 통과 보증이 아니다. binding·수동 편집·자료 이미지·clip의 재열기 보존과 실제 JPEG의 지리선 선명도를 확인한다. 재열기에서 binding/도형 연결이 invalid이면 외관이 남아 있어도 보존 성공이 아니다. 앱 기능이 부족하면 미지원 범위를 보고하고, 실제 지원되는 프리셋 일반 편집·검증된 자료 보완 경로로 가능한 부분을 진행한다. 앱 개발로 해결 범위를 넓히지 않는다. 조판 성공·출력 결함·미수행 검증을 구별한다.

해안 상세도·단순화·선폭·작은 섬의 표시를 지도 공통 원칙에 따라 대조한다. 원형 복원·범위/상세도 변경 뒤에도 국가 채움과 해안·경계가 갈라지지 않고 필요한 섬·해협·앵커가 유지되는지 확인한다. 가장자리 위도 표시는 전체 경위선을 추가하라는 뜻이 아니다.
주제와 무관한 작은 내륙 호수·하천 조각이 육지 위에 잔선·얼룩으로 흩어지면 수역 레이어나 최소 면적으로 정리한다(오대호처럼 위치 판독에 쓰는 수역은 유지). 바깥 틀은 기본으로 `frame`을 켜고, 틀 없는 지도가 자연스러운 경우나 의뢰가 빼라고 할 때만 끈다. 범례 문구가 한 단어 묶음인데 두 줄로 꺾이면 범례 칸 폭을 넓힌다. 하천선은 검정으로 해안선보다 조금 가늘게 하고, 창 밖에서 들어오는 하천은 틀 끝부터 하구까지 이어 지도 안쪽에서 끊긴 조각으로 남기지 않는다. 지역을 가리키는 원형 그라데이션 음영은 가장자리만 흐려지고 중심은 중간 회색(대략 40~50% 농도)이 되게 해 흰 육지·연회색 바다 위에서 위치가 바로 보이게 한다. "흐릿한 음영"은 경계가 부드럽다는 뜻으로 읽고 농도를 약하게 줄이지 않는다.


최종 인쇄 크기에서 **위치점의 바깥 지름·흰 중심·외곽 굵기, 해안 실선, 국경 점선의 굵기·한 조각 길이·빈 간격**을 각각 확인한다. 같은 지도 안에서 같은 의미의 표식은 같은 규격을 쓰고 범례에도 그대로 적용한다. 고배율에서 보인다는 이유로 최종 크기에서 사라지는 점선·빈 원을 통과시키거나, 작은 점을 비례원처럼 크게 만들지 않는다. 확대 화면은 접합·지리 오류 확인용이며 최종 크기 판독 검사를 대신하지 않는다.

단독 주제도와 작은 삽입 지도 모두 프리셋의 초기 범위를 그대로 쓰지 말고, 요청한 지역과 위치 판독에 필요한 주변에 맞춰 범위와 범례 자리를 함께 계획한다. 대륙 전체 등 의미상 필요한 지리 범위와 섬은 보존하고, 그 의미를 해치지 않는 정당한 crop이나 등록된 지리 요소 선택으로만 무관한 주변을 덜어낸다. 최종 8pt 표기의 실제 폭과 가독성을 반영한다. 범례는 지도에서 지리 판독에 쓰이지 않는 옆쪽 바다·육지의 빈 공간이나 구분된 작은 칸을 우선하며, 위치 기호와 혼동되지 않게 한다. 충돌을 피하려고 큰 위·아래 띠를 새로 만들지 않는다. 필요한 해안·지역 경계를 범례 아래 숨기는 배치는 불통과다. 지도 밖 범례는 지도 창 가장자리와의 간격을 유지하고, 폭·crop 변경 뒤에도 다시 확인한다.

문서·대화 장면 안의 지도도 요청된 가로세로 비율에 맞춰 지도 창과 표시 범위를 함께 정한다. 정사각형 프리셋을 그대로 키워 아래의 발언 영역을 과도하게 밀어내거나, 비균등 확대·축소로 지형을 찌그러뜨리지 않는다. 필요한 지점·주변 지형이 모두 남는 실제 crop을 확인한다. 특정 위도선·경도선을 요청하면 해당 선과 숫자의 실제 대응을 확인한다. 자동 경위선 간소화가 그 선을 보존한다고 가정하거나, 선 없이 숫자만 추가한 것을 구현 완료로 보지 않는다.

작은 강조 구역의 라벨을 밖으로 뺄 때는 바다나 지리 판독을 방해하지 않는 빈 면을 우선한다. 다른 비교 대상의 진한 면 위에 놓여 어느 지역을 가리키는지 혼동되거나 검은 글자의 대비가 낮아지면 불통과다. 경계선과 글자가 직접 겹치지 않는다는 이유만으로 빈 공간이라고 보지 않는다. 큰 구역 내부에 명확히 읽히는 자체 라벨은 허용한다.

지시선은 객체가 존재하는지만 확인하지 말고 최종 크기에서 대상과 문자 사이의 연결로 읽히는지 본다. 대부분이 해안·국경과 겹쳐 경계선의 연장처럼 보이면 지리 앵커를 유지하고 라벨의 방향·거리를 조정한다. 지도 내부의 균일한 면에서 명확히 읽히는 선까지 바다로 옮길 필요는 없다. 수치 보충 라벨도 해안·경로와 겹쳐 숫자의 획으로 오인되지 않는 위치를 고른다.

강·해협·경로의 이름은 해당 지물 가까이에 두어 어느 선이나 수역을 뜻하는지 즉시 읽히게 한다. 지명이 경로·지시선 위에 놓여 흰 윤곽이 선을 끊고 있으면 겹침이 해결된 것이 아니므로 글자를 옮긴다. 흰 윤곽은 회색 면·해안선과의 대비용이다. 하천명은 실제 하도의 방향을 따라 한 줄을 기울일 수 있으나, 글자마다 강제로 줄바꿈하지 않는다. 긴 범례는 먼저 빈 공간의 가로 폭을 활용해 항목과 표식을 한 줄로 묶고, 좁은 상자에 불필요하게 여러 줄로 쌓아 지도보다 커지지 않게 한다.

다른 비교 대상 국가를 길게 가로지르는 지시선은 피한다. 해당 지역 가까이의 읽기 쉬운 면과 짧은 연결을 우선한다. **자동 배치는 초안**이므로 AI가 이미지에서 방향·길이·꺾임·문자와의 간격을 직접 판단하고, 어색하면 지리 앵커를 고정한 채 라벨 위치를 바꿔 연결선을 다시 생성한다. 비슷한 역할의 라벨은 가능한 범위에서 간격과 정렬을 맞추되, 보기 좋게 하려고 실제 지점을 이동하지 않는다. 자동 충돌 검사 통과만으로 적절한 연결이라고 판단하지 않는다. 채색 등급을 계산하기 위해 받은 값과 그림에 표시할 값은 구분한다. A·B 등 지칭만 요청했으면 원자료는 연결한 채 문자만 표시하며, 생성기가 덧붙이는 개별 수치·출처 설명·제목을 자동으로 채택하지 않는다. 필요한 단위·범례는 유지한다.

도법 검수는 투영 이름만 일치하는지로 끝내지 않는다. 유럽 부분도에서 스칸디나비아가 똑바로 서고 북유럽이 크게 부푼 원통 도법 결과는 고쳐야 할 결함이다(원뿔 도법으로 재투영). 해안 기준점의 상대 위치·위선 간격·중심 경도·표시 범위를 분리해 확인하고, 세계 지도 절단선이 필요한 육지를 가르는지 본다. 출처 지도에서 옮긴 영역·지점·경로는 원출처와 위치 대응을 확인하며, native 바탕과 별도 보완 path의 재투영 여부를 구별한다.

범례 칸은 틀 안 모서리에 틀선을 공유하며 붙인다. 해안·자료와 겹치면 범례 폭을 줄이거나(한 줄 문구, 짧은 견본) 다른 빈 모서리를 고르고, 그래도 안 되면 지도 범위를 바다 쪽으로 조금 넓힌다. 범례를 틀 아래·옆에 따로 매달아 그림 외곽을 들쭉날쭉하게 만들지 않는다.
지도 위 제목(〈 〉)은 틀 윗선에서 글자 잉크까지 약 1.5–2.5mm에 두고, 가운데 정렬은 틀 폭 기준이다. 제목과 틀 사이에 빈 띠를 남기지 않는다.

JPEG 검수에서 다음 중 하나라도 보이면 고친 뒤 다시 내보낸다: 지명 글자가 자기 점에서 약 2mm 넘게 떨어져 다른 지역(바다·만·다른 도시) 위에 놓임 / 경유지를 잇는 이동 경로가 꺾은 직선 / 설명 상자 셋 이상이 한쪽 열에 몰림 / 의뢰한 위치(예: 제주도 남쪽 바다)와 기호 위치가 다름 / 지도 틀 안쪽에 지도 없이 빈 흰 띠가 남음 / 경로선·화살촉이 지명 글자를 지나가거나 1mm 안으로 붙음 / 지시선 없는 설명 상자 / 설명 상자·범례가 의뢰에 나온 위치 기준 지물(예: 표류 시작점을 설명하는 제주도·남해안)을 가림 / 바다 위 출발점→해안 도시 해로가 육지를 지나거나 불필요하게 돌아감 / 상자 문장이 4줄 넘는 좁은 기둥 / 설명 상자의 지시선이 경로선이나 다른 지시선을 가로지름(상자를 대상과 같은 쪽으로 옮겨 해결). 지명은 생성기 자동 배치를 먼저 쓰고, 손으로 옮길 때도 경로·지시선과의 간격을 다시 본다.
