### 두루마리 외피

- 두루마리는 얇고 작은 위아래 말이, 나선 단면과 짧은 음영을 사용한다. 본문 길이에 비례해 말이 두께를 키우지 않는다. 종이 양쪽을 말이 끝보다 지나치게 안으로 들이지 않고 확보한 폭을 본문/여백에 돌린다. 말이 전체를 진하게 채우지 않는다.

말이의 나선 단면·작은 안쪽 틈·짧은 접촉 음영으로 구조를 읽히게 한다. 줄어든 말이 공간을 새 장식으로 채우지 않는다.

#### 선택 배경 실행

네이티브 text production에서 KICE 종이 두루마리는 `variant:"scroll"`을 사용한다. 말이 폭은 종이 안쪽으로 2mm이며, 얇은 말이와 작은 단면을 기본으로 한다. 광택 금속 막대가 명시적으로 필요한 화면형에서는 `variant:"scroll-screen"`을 사용하며 말이 폭은 4mm다. 두 variant를 혼동해 재질을 바꾸지 않는다. 기본 말이가 두껍거나 종이가 좁으면 반환 도형을 조정하고 원래 흰 내용 영역/예약 치수는 최소한 유지한다. 지정 높이가 말이를 포함한 외곽 높이로 해석되지 않게 한다.

Legacy `node scripts/build_text_frame.mjs` fallback은 기존 `variant:"scroll"` 한 가지만 지원하고, 4mm 금속 롤러 도형을 출력한다. 이 이름은 네이티브 종이 기본형과 같은 동작이 아니다. fallback 결과를 사용해야 하면 KICE 종이 두루마리 요청에 맞게 실제 편집 가능한 결과를 조정·검수한다. legacy fallback에는 `scroll-screen` 옵션이 없다.

#### 검사

말이 두께·종이 폭과 마지막 줄/예약 직사각형의 침범을 확인한다.

두루마리 외피 안의 실제 연속 내용 영역을 예약 치수와 대조한다.
