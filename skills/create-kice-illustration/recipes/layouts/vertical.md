### 세로 대화 배치

- **각 행에서 인물의 실제 보이는 정수리와 말풍선 몸통의 상단을 맞춘다.** 투명 이미지 여백·말풍선 꼬리는 정렬 기준에 포함하지 않는다. 한 줄·두 줄·긴 발언 모두 같은 기준이며, 긴 말풍선의 세로 중앙에 인물을 내리지 않는다. 인물 전체 높이는 아래의 두 줄 기준을 유지하고, 상단 정렬 후 자기 화자 쪽 꼬리와 이름 위치를 함께 계산한다.
- 순서가 있는 발언, 인물이 많거나 주고받는 대화는 위에서 아래로 쌓는다. 얼굴은 행마다 전체 그림의 왼쪽 또는 오른쪽 끝에 붙이고 말풍선은 안쪽의 넓은 영역에 둔다. 짧은 행만 중앙으로 들여놓아 인물 가쪽에 큰 흰 여백을 남기지 않는다.
- 본문 중심인 행에서는 말풍선 몸통에 전체 폭의 **약 3/4–4/5**를 먼저 배정하고 나머지에 흉상·꼬리·틈을 둔다. 사각 흉상 칸을 쓰는 인터뷰도 아래의 인물 전체 높이를 먼저 맞춘 뒤 칸을 정한다. 남은 옆 공간을 채우려고 인물을 키우지 않는다. 짧은 발언은 선택한 발언 프로필 한 줄 측정 폭+안쪽 여백까지 줄일 수 있으나, 문자 수 추정이나 임의 최소 폭으로 한 줄 가능한 문장을 두 줄로 만들지 않는다. 긴 발언은 가용 폭에서 자연 줄바꿈한다.
- **얼굴부터 목·어깨까지 포함한 인물 그림 전체 높이를 선택한 발언 프로필 두 줄 말풍선 몸통 높이와 대략 같게** 정한다. 원화의 실제 가시 영역을 기준으로 하며 투명 여백·이름은 제외한다. 말풍선은 두 줄 본문의 실측 높이에 정상 상하 안쪽 여백을 더하고 꼬리는 제외한다. 얼굴의 정수리~턱만 이 높이에 맞추어 흉상이 지나치게 커지지 않게 한다. 목·어깨가 자연스럽게 보이는 흉상을 비례 배치하고, 한 줄 발언 때문에 줄이거나 긴 답변에 맞춰 키우지 않는다. 같은 화자는 모든 행에서 동일한 인물 크기를 유지한다. 이름 때문에 행간이 넓어지면 인물을 줄이는 대신 이름을 가쪽 옆으로 옮긴다. 독립 얼굴 단품의 권장 폭을 세로대화에 그대로 적용하지 않는다.
- **이름은 인물의 가쪽 옆 또는 아래에 둔다.** 옆이면 왼쪽 화자는 `이름—흉상—꼬리—말풍선`, 오른쪽 화자는 그 반대 순서다. 이름의 글 획이 그림 끝에 오고 흉상은 바로 안쪽에 둔다. 아래 이름이거나 이름이 없으면 인물 자체가 끝에 온다. 인물과 꼬리 사이에 이름을 끼우지 않는다. 같은 화자의 반복에서는 이름 위치도 유지하며 사용자 지정 위치는 우선한다.
- **실제 조판이 2줄 이하인 발언이 연속되면 이름을 인물의 좌우 가쪽 옆에 둔다.** 왼쪽 인물은 이름을 왼쪽 끝, 오른쪽 인물은 오른쪽 끝에 놓고 얼굴~어깨 높이에 맞춘다. 이름을 아래에 두어 행 높이가 커지거나 말풍선 사이가 벌어지지 않게 한다. 같은 화자는 다른 행에서도 이 위치를 유지하며, 말풍선을 높여 인물+이름에 맞추지 않는다. 아래 이름 때문에 빈 띠가 생기는 다른 짧은 행에도 같은 조정을 우선한다. 사용자 지정 위치는 우선한다.

- 좌우 교대는 의무가 아니다. 화자 위치의 일관성과 발언 순서를 먼저 유지한다. 같은 화자가 다시 등장하면 같은 외형과 머리 크기를 사용한다. 긴 답변과 짧은 질문이 함께 있어도 실제 화자가 둘이면 한 발표자로 합치지 않는다.

조판은 **가용 폭/실제 줄 수 → 흉상·이름의 실제 외곽 → 정수리와 말풍선 몸통 상단 정렬 → 자기 화자까지 꼬리 간격 → 행 최하단+행간** 순서로 계산한다. 인물 중심·말풍선 시작점·행간을 서로 무관한 고정 좌표로 반복하지 않는다. 승인 원화 계획과 발언 순서·반복 화자 ID·동일 머리 크기를 대조하고 실제 JPEG에서 상단 정렬이 유지되는지, 어깨가 잘리지 않았는지, 이름이 가쪽인지, 짧은 발언이 불필요하게 줄바꿈되지 않았는지 확인한다.
