### 발언·인물 대응과 승인 원화

화자 목록과 발언 목록을 따로 작성하고 화자 ID·제공된 이름·원문·강조·위치를 연결한다. 사회자 등 역할명을 표시하라고 준 경우에는 빠짐없이 배치하며 미제공 이름은 만들지 않는다. 장면 설명의 역할과 표시할 이름은 구별한다. 예를 들어 ‘교사 을이 설명’에서 별도 표기 요청이 없으면 이름표는 ‘을’이며 역할을 자동으로 덧붙이지 않는다. 발언 횟수를 인물 수로 세지 않는다. 발언 전체·밑줄·기호·문장 속 빈칸을 유지하고 긴 발언을 요약하지 않는다. 화면 속 이름을 새 화자로 만들지 않는다.

#### 검사

화자 목록과 최종 그림을 대조해 발언·순서·강조·이름 대응을 확인한다. 발언마다 여러 줄을 포함한 글상자가 하나인지, 밑줄이 그 글상자의 서식인지 실제 개체로 검사한다. 행/열 배치에서 이름과 발언의 대응을 확인한다. 최종 인쇄 크기에서 과도한 빈 간격을 확인한다. 꼬리 형상·윤곽 간격 검사는 task instructions에 선택된 말풍선 조건을 적용한다.

### 말풍선 폭과 꼬리의 실측 배치

- 먼저 실제 글꼴·인쇄 크기로 발언을 측정해 잉크 폭, 진행 폭, 시각 행 수, 텍스트 프레임의 안쪽 여백을 확인한다. 말풍선 폭은 이 측정값과 해당 구성에서 실제로 쓸 수 있는 칸으로 정하며, 글이 들어간다는 이유만으로 대지 전체 폭을 채우지 않는다.
- **내용에 맞춘 최소 폭은 발언이 시각적으로 한 줄이고, 같은 말풍선 묶음에서 위아래로 이어지는 다른 발언이 없을 때만** 선택한다. 획·테두리·꼬리에 필요한 여유를 남긴다. 묶음은 화자의 동일성이 아니라 반복되는 행·열 정렬과 시각적 구성으로 구분한다. 교사의 단독 상단 안내와 하단 학생 가로열처럼 서로 다른 구도·열을 갖는 묶음은 분리하며, 화자가 달라도 같은 열에서 반복되는 세로 대화행은 같은 묶음이다. 같은 묶음에 위아래 발언이 있으면 내용 한 줄만으로 폭을 줄이지 않고, 그 구성 칸의 폭을 자연스럽게 사용한다. 같은 세로 묶음의 한 줄 말풍선은 폭을 맞추며, 그 폭을 맞추려고 글을 억지로 두 줄로 바꾸지 않는다.
- 말풍선이 여러 줄이면 발언을 읽을 수 있는 폭을 먼저 확보하고 남는 구성 칸을 자연스럽게 사용한다. 발표형의 약 70–80% 초기 배분값은 실제 글 측정과 인물·이름·자료의 위치로 다시 조정한다.
- **발표형의 구성 칸은 빈 대지가 아니라 인물·이름표·자료판이 이루는 장면을 기준으로 정한다.** 말풍선만 인물·이름표보다 바깥으로 돌출하고 그 아래가 비어 보이면 위치와 폭을 함께 조정한다. 필요한 경우 장면 외곽 요소의 실제 보이는 끝에 맞추되, 이름표 한 개의 좌표를 모든 장면의 고정 기준으로 삼지 않는다. 글자를 축소하거나 강제 줄바꿈해서 정렬을 맞추지 않는다. 이 원칙은 장면 외곽 정렬을 위한 것이며, 내용에 맞춘 최소 폭은 위의 ‘단독 한 줄’ 조건을 충족할 때만 허용한다.
- 꼬리는 화자의 얼굴 가까이에서 말풍선 몸통으로 연결되는 짧고 선명한 비대칭 곡선으로 설계한다. 장식용으로 길게 늘이지 않는다. 장소 단서를 보호해야 하는 연결은 짧은 기본 꼬리보다 길 수 있으나 화자 대응과 간결한 곡선을 유지한다. 거리가 멀면 꼬리부터 늘리지 말고 말풍선과 기존 인물 위치를 함께 재검토한다.
- 인물이나 꼬리를 사진 위로 옮길 때는 배경 사진의 중요한 윤곽·건물·자료를 먼저 확인한다. 빈 하늘이나 다른 여백을 우선 사용하고, 중요한 사진 내용이 가려지면 다른 위치를 택한다. 기존 승인 인물 자산과 사진 원본은 보존한다.
