# D2-02_StackedBar — 누적 막대·띠

막대 내부 분할. 절대량 누적·100% 띠

절대량 합계 비교와 100% 구성비를 구별한다. 실제 누적값으로 경계를 계산하고 순서·범례를 유지한다. 작은 구간을 최소 높이로 키우지 않는다. 구간 위의 이름은 해당 구간 중심에 맞추되, 이웃 이름과 충돌하지 않으면 구간보다 넓어도 된다. 작은 구성비에 맞추려고 이름을 글자마다 줄 바꾸지 않으며 바깥 이름의 돌출까지 전체 폭에 포함한다. 시점 간 구간 경계를 비교하는 요청에서만 내부 누적 경계를 가는 점선으로 연결한다. 양/음수 누적이 있으면 영점 양쪽 합산 의미를 확인한다.

한 연도 안에서 단일 막대와 여러 계열을 쌓은 막대를 나란히 비교할 때는 **범주와 누적 묶음**을 구별한다. 원자료의 연도를 중복하거나 관측하지 않은 0을 넣어 외형만 만들지 않는다. 실제 생성기가 계열별 누적 묶음을 지원하면 같은 범주 안에서 그 묶음으로 배치하고, 양·음수 합계와 축 범위도 묶음별로 계산한다. 미지원이면 원자료를 보존한 보충 제작의 한계를 밝힌다. 서로 다른 단위를 한 축 눈금으로 읽도록 의뢰된 경우 각 계열의 단위 대응을 범례·단위 표기로 분명히 한다.

`stacked-column|stacked-bar|percent-column|percent-bar`, type bar. percent 엔진은 항목별 제공 값의 합으로 100%를 계산하므로 분모를 확인한다. 결측 없는 비음수·양수 합계가 필요하고 값 축은 0–100이다. 이미 비율인 입력을 반올림 합계 오류 때문에 몰래 정규화하지 않는다. 절대량 입력의 합이 100일 필요는 없다. 결측 누적은 표시된 부분만의 합이며 warnings를 완전 합계처럼 해석하지 않는다.
