# I3-22_Route — 경로·선 기호도

질적 주제도. 양 없는 선: 원정로·교역로·이동 경로·산줄기·사건 순서

수량 없는 경로의 굵기를 이동량으로 추정하지 않는다.

경로가 굵거나 짧으면 화살촉까지 과도하게 커지지 않는지 확인한다. 지원되는 `routes[].arrowScale`로 촉 크기를 조절하고 출발·도착 기호와 분리하되 지리 좌표는 옮기지 않는다. 자동 경로와 독립 보충 화살표를 중복해 그리지 않는다.

역사 원정로·진격로처럼 경유지를 따라가는 경로는 몇 개 점을 잇는 꺾은 직선으로 끝내지 않는다. 지도 생성기의 `routes[]`에 `curve:"smooth"`, `arrowEvery:"segment"`, `via`(경유 위경도)를 지정해 만들고, 독립 곡선을 손으로 그리지 않는다. 곡선이 육지·바다를 잘못 가로지르면 `via`에 바다/육지 쪽 보조 경유점을 더한다. 육로는 해안선 안쪽 육지를 따라, 해로는 해안에서 약간 떨어진 바다를 따라 부드러운 곡선으로 그리고, 육로가 바다를, 해로가 육지를 가로지르지 않는지 확인한다. 긴 경로는 방향이 바뀌는 구간마다 작은 화살촉을 두어 진행 방향이 경로 중간에서도 읽히게 한다. 전투·사건 기호의 지명은 기호 바로 옆 빈 면에 붙이고 경로선과 겹치지 않게 한다. 지역명(반도 등)을 강조하라는 요청은 굵은 글꼴로 구별한다.
