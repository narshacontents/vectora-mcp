# 출제 에이전트용 일러스트 의뢰 가이드

`create-kice-illustration`에 **그림에 들어갈 내용과 읽어야 할 관계**를 전달한다. 복잡한 자료는 긴 설명·표·목록으로 충분히 상세하게 의뢰해도 된다. 요청을 짧게 줄이느라 원문·수치·대응을 생략하지 않는다. 자세히 정할 것은 내용이며, 구체적인 배치 수치를 많이 지정하는 것이 목표는 아니다.

## 공통으로 전달할 내용

- **읽을 관계:** 무엇과 무엇을 비교하는지, 어떤 변화·연결·포함 관계를 읽게 할지. 정답이나 해설을 알려줘야 이해되는 조건은 `그림에 표시하지 않을 맥락`으로 분리한다. 문항 전문은 필요한 부분만 보낸다.
- **그림에 넣을 내용:** 문구·이름·기호·수치·단위·빈칸·강조와 그 대응을 빠짐없이 준다. 제목·각주도 인쇄할 문구가 정해졌을 때 전달한다. 위치를 찾는 실제 지명과 그림에 쓸 A·B 같은 표기는 구별한다.
- **자료의 성격:** 제공 자료, 조사할 실제 자료, 가상 자료, 정성적 관계를 구별한다. 실자료 조사라면 지표·지역·기간과 출제상 고정된 정의를 준다. 이미 확보한 출처·참조 파일은 함께 전달하되, 모르는 수치·경계·분모를 임의로 채우지 않는다.
- **있을 때만 추가:** 실제 지면의 최종 폭·높이 제한, 정확히 재현할 원본, 필수 배치, 표시하면 안 되는 내용. 고정 스타일을 다시 쓸 때는 어떤 이전 그림의 구조인지 알려준다. 수정 의뢰는 기존 그림과 변경할 내용이면 된다.

구성비는 패널별 항목 순서와 원값을, 풍향도는 방위 순서·횟수/백분율·무풍 포함 여부를 전달한다. 비교 지도·격자 자료는 같은 장소·칸의 대응과 비교 시점을 구별한다. 지도 설명창은 `실제 표시 지점 → 기호 → 설명`을 짝지어, 설명 속 다른 지명을 연결 지점으로 오인하지 않게 한다. `0`과 `O`, 아래첨자 등도 원문대로 구별한다. 이처럼 **숫자나 관계의 해석을 바꾸는 정보**가 상세 의뢰의 핵심이다.

그래프의 보조선은 "점선 격자"처럼 일반 표현으로 적으면 평가원식 파선으로 만들어진다. 작은 점 격자가 꼭 필요할 때만 그렇게 적는다. 지도는 위치를 읽는 데 필요한 수역(오대호, 큰 호수, 하천)을 이름으로 적어야 단순화 과정에서 지워지지 않는다. 지도 바깥 틀은 기본으로 그려지므로 틀 없이 떠 있는 위치도가 필요할 때만 밝힌다. "점선"은 평가원식 짧은 파선으로 그려진다. 확대도는 범위만 적지 말고 무엇을 보기 위한 창인지(예: 항로와 항구) 함께 적는다. 음영·채색은 "흐릿하게"보다 "가장자리가 흐려지는 진한 회색 원"처럼 농도와 경계를 나눠 적는다. 진격로·항로는 출발→경유→도착 지명을 순서대로 적고 육로와 해로를 구분한다. 하천은 "하류"처럼 구간을 줄여 말하면 그 구간만 그려지므로, 필요한 범위(예: 지도 틀에서 하구까지)를 적는다. 선그래프 계열 이름을 선 끝에 붙일지, 범례로 둘지는 자료 해석에 영향이 없으면 제작자에게 맡긴다. 누적·구성 막대에 값을 주더라도 그림에 수치를 적을지(눈금으로만 읽게 할지)를 함께 밝힌다. 지면 폭은 그림이 넘지 말아야 할 최대치로 읽힌다. 원그래프·순서도처럼 작게 그려야 자연스러운 자료를 폭에 맞춰 키우라는 뜻이면 따로 적는다. 무늬는 "빗금·+·점"처럼 종류와 계열 대응만 적고 밀도·크기는 맡긴다. 경제 좌표도는 축에 보일 숫자를 나열하면 되고, 원점 0과 축 제목 위치는 제작자가 정한다. 다만 "40, 50만 표시"처럼 `만`을 붙이면 원점 0까지 지워지므로, 0을 빼려는 의도가 아니면 `만`을 쓰지 않는다. 설명 상자가 달린 지도는 창에 꼭 들어가야 할 지역을 경계 지명으로 적는다(예: 북쪽은 랴오둥반도, 동쪽은 한반도 서해안까지). 그래야 상자 자리를 만들려고 범위를 잘라 내지 않는다. 좌표도의 이동은 "E(1,000, 1,000)에서 A로 화살표"처럼 출발·도착 점만 적고 촉 크기·간격은 맡긴다. 축의 생략은 "0과 800 사이 생략"처럼 생략 구간만 적는다. 찢긴 종이는 찢김의 방향("오른쪽 위에서 왼쪽 아래로 비스듬히")과 무엇이 잘려 보이지 않는지만 적는다. 교실 장면에서 학생이 넷 이상이면 이름과 발언을 왼쪽부터 순서대로 적는다. 학생 말풍선의 높이·폭 맞춤은 제작자가 한다.

## 여러 오브젝트의 구도 전달

먼저 각 요소가 **동등한 비교 자료 / 주자료와 설명 / 하나의 공유 장면 / 전체와 확대** 중 어떤 관계인지 정한다. 관계가 정해지면 제작자가 실제 내용에 맞춰 폭·높이·간격을 조정할 수 있다. 꼭 필요한 배치는 확정 조건으로, 선호하는 구도는 조정 가능한 제안으로 구분한다.

| 구성 | 전달하면 좋은 구도 의도 | 불필요하게 고정하지 않을 것 |
|---|---|---|
| 지도 + 그래프 | 지도는 어디인지 찾는 자료인지 주제 분포 자체인지, 그래프는 어느 지점/지역을 비교하는지, 지도 기호와 계열 대응. 넓은 전체 지도와 비교 그래프들이면 지도 위·그래프 아래부터 검토하고, 좁은 지역도와 단일 그래프면 나란히도 가능 | 모든 패널을 같은 크기로 만들기, 지도 높이에 그래프를 억지로 맞추기, 범례를 무조건 바깥에 두기 |
| 그래프 여러 개 | 동등 비교인지 주·보조 관계인지, 공통 척도·계열·시점. 동등한 좌우 비교는 비슷한 비중과 같은 실제 축 위끝/아래끝을 의도하고 공통 범례는 한 번만 | 컨테이너의 좌표만 같게 지정하기, 글·범례 포함 전체 높이를 억지로 맞추기, 내용과 무관한 폭 배분 |
| 칠판/화면 + 사람 + 말풍선 | 한 장면임을 명시하고 판 안의 내용, 발언자, 가리키는 대상을 연결한다. 자료판을 주자료로 두고 인물과 발언은 그 가까이에 묶는다. 판의 빈 배경·테두리는 겹쳐도 되며 읽을 내용은 가리지 않는다. 학생이 여럿이면 "교사는 칠판 옆에 서고, 학생 뒷모습은 칠판 아래 한 줄, 학생 발언은 그 아래 한 줄"처럼 공간 관계만 한 문장으로 적는다 | 판과 인물을 각각 독립 패널로 만들기, 판 크기와 무관한 작은 흉상, 말풍선의 폭·좌표를 미리 고정하기 |
| 지도 + 확대도/설명창 | 실제 확대 대상과 창의 대응, 확대가 필요한 이유, 빠지면 안 되는 위치 관계 | 확대도의 무조건 동일 축척, 모든 창을 지도 바깥에 배치, 전체 지도와 확대도 크기를 동등하게 만들기 |
| 여러 본문 블록 + 표/그림 | 같은 기사·화면의 하위 블록인지 별개의 자료인지, 읽는 순서·제목 위계·각 블록의 소속 | 모든 블록의 높이를 동일하게 고정, 내용을 쪼개거나 장식으로 빈 공간을 채우기 |

내용이 긴 대화에서는 **발언이 대응하는 자료와 화자 순서**를 자세히 준다. 한 줄씩 엔터를 넣거나 말풍선의 예상 행 수로 구도를 강제하지 않는다. 반복 양식을 요청할 때도 고정할 것은 구조이며, 글과 값이 들어갈 공간의 미세 조정은 맡긴다.

> 단위는 지수이고 지역별 증감 크기를 비교한다. 정확한 값도 읽을 수 있어야 한다. 지도는 위치 확인용 보조자료이고 그래프가 주자료다. 두 자료의 A·B·C 대응이 쉽게 읽히도록 배치하며, 남북한 전체를 보여줄 필요는 없다. 최종 폭은 지면상 90mm 이내다. 그래프 형식과 범례 위치는 비교 목적에 맞게 정한다.

**칠판·인물·발언이 결합된 장면**

> 교사가 칠판의 자료를 가리키고 학생 갑·을이 서로 다른 관점을 말하는 한 장면이다. 칠판 제목은 ‘변화를 설명하는 관점’, 표는 ‘관점/설명’ 두 열로, ‘A/개인의 선택을 강조한다.’와 ‘B/사회 구조의 영향을 강조한다.’를 넣는다. 교사 발언은 ‘두 관점으로 같은 현상을 설명해 봅시다.’, 갑은 ‘선택의 이유에 주목해야 합니다.’, 을은 ‘선택을 제약하는 조건을 살펴야 합니다.’이다. 표와 학생 발언을 대조할 수 있어야 하고, 어느 학생이 A·B에 해당하는지는 따로 표시하지 않는다. 칠판이 중심이며 교사·학생 발언은 소속이 분명하게 가까이 배치한다. 각 발언을 억지로 같은 줄 수로 만들 필요는 없다.
