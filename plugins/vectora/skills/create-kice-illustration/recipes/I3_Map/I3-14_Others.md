# I3-14_Others — 기타 지도

일반도. 평면·배치도, 반구·지구본, 특수 투영 모식, 카토그램

- 원형 외해·도식 대륙 분할·중심 지점의 의미 관계를 독립 면/선/문자로 구성한다. 회전된 지명/수역 띠는 의미·읽기 방향을 보존하고 글과 지리 도형을 분리한다.
- 수량에 따른 면적/형상 변형 근거가 없으면 카토그램이라 부르지 않는다. 역사적 왜곡과 수량 인코딩은 다르다. 실제 좌표가 아닌 개념 공간에 정확한 거리·축척·투영 계산/지리 등록을 부여하지 않는다.

## site-plan — 도시·유적·시설 평면/배치도

- 실재 장소의 배치는 제공되거나 조사한 출처 평면 이미지를 직접 확인한다. 출처의 기관·문서·도면/쪽·시점과 확인 가능한 방향·외곽·주요 구획·상대 위치를 대조하고, 확인하지 못한 성문·도로·건물의 상세 배치를 창작하지 않는다. 근거가 부족하면 필요한 평면 자료를 요청하거나 확인 가능한 범위와 누락을 밝힌다. 검색 요약이나 현대 GIS 바탕만으로 역사 평면을 확정하지 않는다.
- 가상 계획도는 `dataSource:hypothetical`로 지정하면 요청한 기하 배치를 설계할 수 있다. 실제 유적의 복원도로 오인되지 않게 가상임을 구별하고, 출처가 없는 치수·방향·축척을 실측값으로 제시하지 않는다.
- 이 별칭의 schematic/일반 벡터 평면 재구성은 위 지도 공통의 등록 GIS 프리셋 절차를 무조건 요구하지 않는다. 출처 도면의 좌표·비례·방향을 유지하며 node-diagram의 기하 구조 지침과 현재 지원되는 schematic/일반 벡터 보충 경로를 사용한다. 출처 이미지 좌표를 위경도로 해석하지 않는다. 실제 등록 바탕이 필요한 경우에만 적합성과 현재 지원을 확인해 지도 경로를 선택한다. 명시적으로 `spec.kind:map`을 선택했다면 map-preset·map-native·map-runtime 등 실제 지도 실행 계약을 읽고, research 조건에는 real-data-map도 적용한다. 두 경로 모두 실재 배치의 출처 평면 이미지 확인이 필요하다.
- 구획·외곽·도로·건물·라벨을 편집 가능한 면/선/문자로 분리하고, 노드/관계로 표현 가능한 부분만 schematic으로 만든다. 도시평면 전용 생성기·미확인 layout·앱 기능을 가정하지 않으며 미지원 경계와 형태는 일반 벡터로 보충한다. 실제 출처와 최종 평면의 주요 배치·누락·추정 표시를 검수한다. 역사 평면을 새로 재구성하는 작업과 원본 스캔을 그대로 쓰는 old-map을 구별한다.
- 구획 안의 사선 길은 양 끝을 해당 경계와 만나는 교점으로 계산한다. 선의 외곽 너비를 눈대중으로 늘려 맞추지 않으며, 독립 경로를 보충하거나 구획을 옮긴 뒤에는 경계 밖 돌출과 끊김을 확인한다. 실제로 경계를 넘어 이어지는 길만 출처·요청대로 연속시킨다.
