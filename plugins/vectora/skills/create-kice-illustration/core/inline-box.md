# 문장 안의 네이티브 박스

박스 라벨의 `(가)`·`(나)`·`(다)` 등은 일반 본문에 같은 문자열을 입력할 때 적용되는 **UND 전용 괄호 글리프**로 표시한다. 라벨 원문은 실제 괄호 문자열로 보존한다. 일반 본문 글꼴로 직접 그리거나 사설 문자 코드로 원문을 치환하지 않는다. 화면·측정·내보내기에서 같은 표시 변환이 적용되는지 확인하고, 연결 앱이 박스 라벨에 이를 적용하지 못하면 앱 기능 오류로 보고한다.

**문장 속 `(가)`·`㉠` 박스를 요청하면 네이티브 문단 박스**를 쓴다. 라이브 `inlineTextBox` 지원 확인 후 같은 본문에 `{type:"inlineTextBox",id,start,end,box:{label:"(가)",widthMm:요청폭}}`; 위치는 현재 grapheme 범위, 라벨/폭 수정은 `update:true`. 본문·폭을 먼저 확정하고 삽입 뒤 범위 서식 위치를 갱신한다. 표셀·검색창·독립 상자는 별개이며 별도 사각형, 토큰 직접 입력, `inlineBlanks`로 대체하지 않는다. 박스 본문에 `style.text` 전체 교체를 쓰지 말고 토큰·서식 보존 범위 편집만 사용한다(미지원은 보고). 박스 측정 계약이 없으면 실제 삽입된 글상자를 측정한다. 바깥 틀·후속 자료를 실제 높이에 맞추고 재열기에서 원문·박스·밑줄·하단 여백을 확인한다. `preserve` 성공은 재조판 완료가 아니다.

**문장 속 박스 바로 뒤에는 Vectora Alt+Space 반칸 `U+2002` 한 개**를 둔다. 예를 들어 `[박스 (가)] 라고`처럼 박스 바깥 본문의 공백이며 라벨 안에 넣지 않는다. 기존 일반/반칸 공백을 중복하지 않고, 실제 문단 끝·개행 앞에 불필요한 후행 공백은 만들지 않는다. 일반 괄호 문자열까지 박스로 간주하지 않는다. 측정 전에 공백을 확정하고 실제 본문을 기준으로 박스·밑줄 범위를 재계산하며, 범위 편집·재조판·재열기 후에도 한 개와 원래 강조 대상을 확인한다.
