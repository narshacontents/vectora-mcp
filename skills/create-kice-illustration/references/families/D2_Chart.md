# D2_Chart — 제작 공통

## 모든 차트의 공통 원칙

- 항목·계열·시점·단위·결측과 척도를 확정한다. 결측은 0이 아니다. 계열과 채움·무늬·선·표식 대응을 전체에서 유지한다. 같은 채움 견본만으로 구별되지 않는 계열은 직접 영역명이나 서로 다른 무늬·선·표식으로 대응시킨다.

- 작은 차트의 범례는 실제 문구와 견본에 필요한 폭·행수로 정하며 본체에 비해 과대하게 잡지 않는다. 직접 계열명으로 충분하면 범례를 생략하고, 범례를 위해 자료 영역을 불필요하게 축소하지 않는다.

유한 관측값과 분모·단위를 유지하며 실제 지원하는 graph 생성기로 최대한 만들고 미지원 부분만 추가한다. 수치 좌표가 두 축에 있고 점·이동 화살표만 있으며 실제 연속 곡선이 없으면 경제 자료도 Scatter다. 무수치 속성 높음/낮음은 Schematic으로 구별한다.
