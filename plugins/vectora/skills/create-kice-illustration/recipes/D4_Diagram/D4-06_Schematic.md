# D4-06_Schematic — 모식도

일반 모식도 배치 원칙은 [`components/schematic-layout.md`](../../components/schematic-layout.md)를 따른다.

방사형·삼각형 축 도식의 범례는 도식 옆 빈 모서리(예: 오른쪽 아래 축 이름 옆)에 넣고, 범례 상자 높이가 도식의 아래쪽 축 이름 높이와 겹치게 둔다. 범례를 도식 아래로 내려 축 이름과 각주 사이에 빈 띠를 만들지 않는다.

건물의 방·복도·출입문이 있는 실내 평면도는 `site-plan` 경로로 준비한다. 일반 관계 노드의 상자 배치로 대신하지 않는다.
