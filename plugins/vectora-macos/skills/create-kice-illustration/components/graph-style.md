## 차트·연속 그래프의 축·개형 표현 — chart/graph에만

독립된 생산가능곡선처럼 두 재화의 조합·선택 영역을 보는 개념 좌표도는 다른 자료·긴 라벨이 비례를 제한하지 않으면 **플롯의 X·Y축 길이가 비슷한 정사각형**을 출발점으로 한다. 바깥 글자까지 포함한 그림 전체를 정사각형으로 만드는 규칙이 아니며, 두 축의 수치 척도를 같게 바꾸라는 뜻도 아니다. 소득 구간별 급여·세율 등 가로 구간을 비교하는 꺾은선은 가로형 플롯부터 검토하고, 자료 최고점 위 공간은 라벨·화살촉에 필요한 만큼만 둔다. 개형이라는 이유로 세로축을 길게 늘리지 않는다. 시계열·관측 차트, 병렬 패널·화면 속 그래프에는 해당 내용의 가용 영역을 우선한다.

생성기 출력은 구도의 초안이다. 실제 크기의 그림에서 자료선·막대·교점이 한쪽에 몰리고 반대쪽에 큰 빈 공간이 남는지 확인하고, 플롯 종횡비·표시 범위·축 연장·라벨과 범례 배치를 적극적으로 조정한다. 정량 자료의 값·척도 대응은 유지하며, 정성 개형의 내부 배치 좌표는 지정된 기울기 방향·대소관계·교점 순서·이동 방향을 보존하는 범위에서 다시 설계할 수 있다. 여백을 채우려고 자료점만 임의로 옮기지 않는다. 보정은 source 설정을 우선하고, 미지원 라벨 배치는 네이티브 소유 역할의 보존 가능한 편집으로 처리한다. 그래프를 일반 도형으로 해체하지 말고 저장·재열기 뒤 더블클릭 편집과 값 갱신이 작동하는지 확인한다.

## 축 제목·단위의 선택

제목·단위 배치는 **지표의 의미와 최종 폭**으로 선택한다. 아래 상황별 출발점으로 생성하며, 사용자가 원본 재현을 명시한 경우에는 제공된 원본의 구성을 따른다. 일반 생성에는 기출 검색·열람이 필요하지 않다. 항상 세로 제목·항상 단위 분리·항상 축 바깥 범례 같은 단일 형식을 강제하지 않는다.

| 상황 | 먼저 검토할 배치 |
|---|---|
| 제목·범례가 지표명을 이미 설명하는 막대·시계열 | Y축 숫자열 위에 짧은 단위만, 연도/월 X축은 끝 눈금 옆 단위만. 중복 축 제목은 만들지 않는다. |
| 두 수량의 관계를 보는 산점·버블 | 긴 Y제목은 숫자열 왼쪽의 직립 세로쓰기, X제목은 눈금 아래 중앙. 짧은 단위는 Y숫자열 위·X끝 눈금 옆으로 분리한다. |
| 가격·수량·재화 등 짧은 개념 좌표도 제목 | Y축 끝 왼쪽과 X축 끝 아래에 가로쓰기. 짧으면 제목+단위 한 줄, 길어지면 단위 앞에서 한 번 줄바꿈한다. |
| 긴 지표명을 가진 작은 패널·기후 이중축 | 상단 가로 제목+다음 줄 단위와 바깥 세로 제목+상단 단위를 비교해 빈 폭이 적은 쪽을 고른다. 좌우 보조축의 지표·단위·계열 대응은 각각 유지한다. |
| 기준연도=100 지수·성비·정성 개형, 값이 직접 적힌 구성비 | 원문 정의·공통 표기만으로 충분한 중복 표기는 생략할 수 있다. 단위 없는 지수/성비에 %를 추정해 붙이지 않는다. 필요한 기준·분모·범주·시점은 남긴다. |

- 간격 검수는 최종 인쇄 mm와 `간격/그림 전체 크기`, `간격/자료 영역 크기`를 구분한다. 간격은 역할·구도와 실제 글 크기에 맞춰 조절하며, 글자가 같은 크기인 두 그림을 전체 폭만으로 일괄 확대·축소하지 않는다. 수치 눈금 사이 거리는 자료 좌표에서 나오며, 문자열 내부 자간·장평과 별개다. 충돌을 피하려고 검증 없이 장평이나 자간을 바꾸지 않는다.
- 축 제목·단위·공통 표제는 **표시할 내용과 위치를 구분**한다. 명시된 재현 조건은 우선하고, 제목/범례에 같은 정보가 이미 있어 반복이 불필요할 때만 축 쪽 표시를 생략한다. 공간 부족만으로 필수 지표명·단위·눈금을 지우지 않는다. 요청의 괄호·배율·‰/ %·위첨자와 실제 수량 척도를 유지한다.
- 두 축이 같은 역할이면 결합/분리 방식을 가능한 한 맞춘다. 한쪽이 범주·시간, 다른 쪽이 측정량이거나 서로 다른 이중축이면 역할에 맞는 다른 배치가 자연스럽다. 원본에서 서로 다른 배치를 썼다면 억지로 통일하지 않는다.
- 세로 제목은 원문을 유지한 **실제 세로 텍스트박스**로 만든다. 한 글자마다 엔터를 넣은 가로 글상자, 낱글자 개체, 가로 글상자 회전으로 흉내 내는 경로는 금지한다. 긴 가로 제목은 의미 단위 또는 단위 앞에서만 줄을 나눈다. 단위 문자열 자체를 낱글자로 세우지 않는다.
- 가로 글상자에서 **축 제목과 단위를 줄바꿈으로 묶으면 내부 줄은 가운데 정렬**한다. X축·Y축·보조축 모두 하나의 편집 가능한 글상자를 사용하며, 글상자 전체의 축 바깥·축 끝 배치는 별도로 유지한다. 단위를 따로 배치한 경우나 실제 세로쓰기에 이 내부 정렬 규칙을 확대 적용하지 않는다.
- Y 상단 가로 제목은 왼쪽 축의 **오른쪽 글 획이 축을 넘지 않는 바깥쪽**, 오른쪽 보조축은 그 반대로 둔다. 긴 제목을 안쪽으로 밀어 해결하지 않는다. 세로 제목은 눈금 숫자열 바깥, X제목은 축/눈금 아래 또는 끝 바깥에 둔다. 같은 높이의 좌우 상단 표기는 실제 획 기준으로 맞춘다.
- **Y축에 단위만 표시하면 눈금 숫자의 위치는 유지하고 단위만 숫자 열의 실제 글 획 중심에 맞춘다.** 축선 기준 정렬과 단위 전체를 축 바깥에 제한하는 조건은 사용하지 않는다. 음수의 선행 부호 때문에 숫자 본체의 중심이 치우치지 않게 하고, 보조 Y축은 자신의 숫자 열을 기준으로 한다. 최상단 숫자와는 짧은 세로 간격을 둔다. 단일 그래프의 공통 제목은 중앙에 두고 **단위보다 위쪽**의 위계를 유지한다. 제목 아래 획과 단위 위 획 사이 약1mm부터 검토하되 원본의 구조와 문구에 맞춘다. 패널 이름이 끼는 복합 제목은 별도 계층이므로 이 간격으로 압축하지 않는다. X단위가 마지막 숫자와 나란하면 **최종 기준선을 함께** 맞춘다. 제목↔단위·최고 눈금↔단위·단위↔화살촉을 각각 검사하며, 글상자 사각형만 떨어져 있다고 통과시키지 않는다. 눈금 숫자열↔세로 Y제목은 실제 글 획 사이 약1.4mm(참고 범위 약1.2–1.6mm), 아래 숫자행↔X제목은 약1.4mm(약1.1–2.0mm)를 출발점으로 삼는다. 두 방향의 인지적 여백을 맞추되 수치를 항상 같게 강제하지 않는다. 가로·세로 글상자 자체의 여백을 거리로 비교하지 않는다.
- 축 끝 옆에 제목을 두려면 자료 영역과 화살촉을 구분한다. 필요한 경우 **자료 좌표·숫자 범위는 그대로** 두고 축 선만 연장하여 그 옆에 제목 공간을 확보한다. 짧은 경제 개형은 **Y제목은 위쪽 축 연장부의 왼쪽, X제목은 마지막 눈금 오른쪽 축 연장부 아래**를 먼저 검토한다. X제목을 축선 높이와 일직선으로 두는 것을 기본으로 삼지 않는다. 전체 폭 안에서 실제 글자 폭을 예약해 플롯을 줄인다. X제목은 축선 아래 약0.9mm, 마지막 눈금 잉크 뒤 약2.5mm, Y제목은 축 바깥 약1.1mm를 이 구성의 출발값으로 삼으며, 긴 문구는 단위 앞 줄바꿈과 공간 예약을 함께 선택한다. 이는 플롯의 물리 크기 조정이며 원자료·척도·자료 최고값이나 100% 끝을 임의로 낮추는 것이 아니다. 모든 그래프에 일정 비율의 위쪽 여백을 강제하지 않으며, 버블 반경·끝 라벨·범례까지 함께 본다.

정량 chart와 축/개형을 가진 graph에 적용한다. **막대·관측 선그래프에서 개별 값 라벨을 생략하면 주요 Y눈금에 맞춘 가로 파선을 우선 사용**하여 대소관계와 값을 읽게 한다. 전면 세로 격자까지 자동 추가하지 않는다. 수량 눈금은 **실제 수량 척도가 있는 경우만**; 정성 이론 그래프에 새 숫자 눈금·전면 격자를 자동 추가하지 않는다. **수치를 생략하더라도 요청된 시점·범주명과 자료의 대응은 표시한다.** 숫자 눈금 숨김 설정이 의미 있는 축 라벨까지 없애지 않는지 계획과 실제 출력에서 확인한다.

## 축선·화살표·상자 프레임

- **단순 축선**: 한정된 시점·범주의 관측값과 추세를 비교할 때 먼저 검토한다. 화살표가 없다고 의미가 누락되는 것은 아니다.
- **화살표 축**: 가격·수량의 관계, 증가 방향·연속 개형을 보여 줄 때 먼저 검토한다. 자료 최고점과 축 끝을 구별하고 제목 공간을 확보하되, 화살표를 모든 수치 그래프에 자동 추가하지 않는다.
- **상자 프레임**: 두 축의 관측 범위·격자 영역을 하나의 판으로 읽는 자료에서 검토한다. 같은 시계열·산점도에도 단순 축선이 있으므로 유형명만으로 선택을 강제하지 않는다. 상자를 고르면 화살표를 겹쳐 붙이지 않는다.
- 눈금 방향은 프레임과 별개다. 상자 안쪽 눈금은 약0.7mm부터, 일반 축의 짧은 눈금은 약0.7–1.0mm부터 검토한다. X는 바깥·Y는 안쪽처럼 축별 방향을 다르게 선택할 수도 있다. 격자가 눈금 위치를 충분히 표시하거나 범주명이 직접 대응되면 별도 눈금선을 생략할 수 있다. 명시 재현에서는 원본 방향·길이를 따른다.

- 축은 **0.4pt**(대략0.3–0.4), 독립된 자료선·개형은 **0.8pt**(대략0.6–1.1), 보조선은 **0.2pt**(대략0.15–0.3)를 출발값으로 쓴다. 선그래프·큰 독립 방사형에서는 자료선이 축보다 보통 약2배, 보조선보다 더 뚜렷하게 읽히게 한다. 계열이 조밀하거나 작은 패널이면 범위 아래쪽, 한두 선의 추세·이동을 강조하면 위쪽을 선택한다. 몇 가지 숫자 중 하나만 고를 의무는 없고 최종 인쇄 크기로 판정한다. **누적면적·구성비처럼 면 자체가 자료인 경계는0.2–0.3pt**부터 사용하며 굵은 독립 곡선 규격을 적용하지 않는다. 범례 견본에도 본체의 실제 굵기를 반영하고 채운 화살촉에 외곽선을 덧대지 않는다.
- 파선의 선/간격도 역할별 출발값이다. 보조선은 **1.5/1pt**, 자료선의 긴 파선은 **3/1.5pt**(작고 조밀하면2/1pt), 일점쇄선은 **6/1.5/1.5/1.5pt**부터 검토한다. 의뢰에서 통상적으로 말하는 ‘점선’은 짧은 선분이 반복되는 파선부터 선택하며, 작은 둥근 점의 연속은 그런 표식을 명시하거나 필요한 계열 구별이 있을 때 쓴다. 제공된 선종류·계열 구별을 유지하고 굵기·곡선 길이에 맞춰 주기를 조정한다. 같은 계열의 본체·범례·비교 패널에는 같은 설정을 쓴다. 엔진이 범위 안의 다른 주기를 사용했다는 이유만으로 불필요하게 다시 그리지 않는다.
- 꺾은선의 원·사각·삼각 표식은 새 제작에서 기본 크기 약1mm부터 비교한다. 실제 외곽에는 선폭·삼각 꼭짓점이 더해지므로 실원만 보지 말고 빈 도형과 함께 형태 구별·시각적 무게·축 숫자와의 간격을 검수한다. 선보다 과하게 강조되면 크기를 조정하며, 수량을 뜻하는 버블·지도 기호에 이 크기를 적용하지 않는다.
- 선종류가 미지정인 여러 계열은 실선·파선·일점쇄선 또는 표식으로 **최종 인쇄 크기에서도 구별되는 조합**을 선택한다. 서로 다른 계열에 같은 검정 파선과 같은 표식을 주고 범례 문자만 다르게 적지 않는다. 네이티브 범례는 실제 계열 스타일에서 생성하며, 여러 패널의 공통 범례는 같은 계열 ID·명칭·선종류·표식을 대조한다. 한 패널 소유 범례를 공통으로 사용했다면 다른 패널의 편집까지 자동 연동된다고 가정하지 않는다.
- 제목·눈금·단위·범례·외부 라벨 공간을 먼저 제외하여 자료 영역 계산. 긴 범주명은 의미 단위 줄바꿈과 실제 폭 측정, 한 음절 고립·이웃 라벨 접촉 금지. 비수량 범주 간격만 라벨 폭에 맞춰 변경할 수 있다.
- 두 축이 같은 원점을 공유하면 `0`은 한 번만 표시한다. 투영·기간 보조선이 개형을 가로지르는 것은 의미상 필요한 교차일 수 있으므로 무조건 피하지 않는다. 기간 화살촉·글자가 개형에 붙어 한 기호처럼 보이는 충돌은 피하되, 이를 위해 자료 좌표나 기간 끝점을 바꾸지 않는다.
- 점·곡선의 이름과 수치 라벨은 보조선에 획이 관통하지 않게 두고, 곡선명은 가까운 투영 보조선이나 다른 곡선이 아니라 자기 곡선에 분명히 연결되게 배치한다. 의미가 지정된 A 등 점과 곡선·자료 좌표는 그대로 두고 라벨의 가로·세로 위치만 검토하며, 같은 역할의 간격을 맞춘다. 보조선 위에 놓여야 하는 라벨은 공통 규칙의 작은 흰 배경으로 판독성을 확보하고 정렬을 유지한다. 선을 문자 뒤로 보냈다는 사실이나 글자 외곽에 가는 흰 선을 두른 것만으로 충돌이 해결됐다고 판단하지 않는다.
- 수량 축의 일반 눈금은 일정 간격을 출발점으로 삼되, 구간별 함수의 꺾임점·임계값을 읽는 그림은 해당 값만 실제 척도상의 위치에 표시할 수 있다. 이를 임의 범주처럼 등간격으로 옮기거나 정상적인 임계값 표시를 불규칙 눈금이라는 이유로 지우지 않는다. 짧은 숫자는 가로쓰기를 우선하고, 실제 인접 숫자끼리 겹칠 때만 표시 간격·배치·회전을 검토한다. 금액·인원 등 큰 수량은 천 단위 쉼표를 표시값에 사용하고, 연도·식별자와 원자료 숫자는 바꾸지 않는다. 생략 뒤에도 척도/눈금 간격 유지. 같은 의미의 비교 패널은 척도·크기 공유, 패널 사이 틈은 내부 틈보다 크게.

축 제목과 단위를 같은 줄에 쓰면 `연도(년)`·`강수량(mm)`처럼 사이를 띄우지 않는다. 연도 눈금 뒤 시간 단위도 `2024(년)`처럼 붙인다. 단위 내부의 `만 원` 같은 띄어쓰기는 유지한다. 그 외 마지막 항목 옆 제목·단위는 **마지막 라벨의 실제 글자 끝**에서 짧게 띄운다. 항목 간격이나 막대 뒤 반 칸의 자료 여유를 제목 간격으로 더하지 않는다. 단독 단위는 보통 `(mm)`·`(만 원)`처럼 괄호로 구분한다. 원문이 표기 형식까지 지정하면 그대로 유지한다. 추세·지역 차이 비교용 선그래프는 모든 점의 수치를 기본으로 덧붙이지 않는다. 정확한 값 판독이 필요할 때 주요 눈금·투영선 또는 값 라벨 중 적절한 경로를 선택한다.

- 축 위의 작은 물결 생략 표시는 생성기의 축 생략 기능을 사용하고 두 선의 간격과 굴곡을 유지한다. 그래프 폭에 맞춰 좌우로 늘이지 않으며, 자료 영역 전체를 가로지르는 생략 띠와 구별한다.

단일 묶음 세로 누적 막대의 자동 폭은 범주 중심 간격의 약 절반부터 비교하며, 약 40%·50%를 조정 후보로 검토할 수 있다. 이는 모든 막대의 고정 비율이 아니다. 최종 폭·범주 수·계열 묶음에 맞게 조정하고 명시된 폭은 보존한다. 막대 외곽선이 두꺼워 내부와 간격이 답답해 보이는지도 함께 확인한다.
