# D2-03_Pie — 원·도넛


**필수 경로:** 원·도넛의 조각 이름·작은 조각 바깥 지시선은 생성기의 `labelOffsets`, 도넛 가운데 이름은 `panelLabelPosition:"center"`, 기준 연도는 `chartOptions.note`로 만든다. 이름·지시선을 별도 글상자로 다시 만들면 진회색 조각 위 흰 윤곽 등 자동 처리가 빠지므로 실패다.
부채꼴·고리 구성비

**조각마다 이름을 적는 원그래프는 흰 조각과 검은 테두리가 기본이다.** 회색·무늬는 의뢰가 요구하거나 이름 없이 범례로 조각을 구별할 때만 쓴다. **바깥 이름은 조각 중심 방향(예: 오른쪽 아래 조각은 `lower-right`)으로 `labelOffsets`를 지정해 원 둘레 가까이 짧은 지시선으로 붙인다.** 지시선이 원 아래로 길게 내려가거나 꺾여 돌아가면 방향을 다시 고른다.

구성비 비교 원은 동일 지름·1:1이고 12시부터 같은 계열 순서로 시계 방향, 각도=비율×360°다(명시 순서 우선). 비율 합계 100을 확인하고 오류·반올림 차이를 몰래 정규화하지 않는다. 0%는 조각 없음, 100%는 완전한 원. 면적 자체가 수량이면 반지름은 수량 제곱근에 비례하며 구성비 비교와 구별한다.

제목·라벨·범례 후 지름을 정한다. 원 사이 틈은 지름의 약 1/4–1/2부터, 가운데 범례는 폭+양옆 여백을 추가한다. 중심 높이·제목 기준을 맞춘다. 큰 조각에는 항목명+수치 두 줄을 중심 정렬; 실제 글상자가 안에 들어가지 않는 조각만 외부 인출선으로 옮긴다. 일률적인 % 임계로 라벨을 나누지 않는다. 작은 원의 비교처럼 더 읽기 쉬우면 공통 범례·수치표로 정리할 수 있다. 점무늬는 글 주위 점만 비우고 흰 상자로 다른 조각을 가리지 않는다. 도넛은 고리·빈 중심·라벨 공간을 별도 확보하고 가운데는 제공된 패널 식별자·총량·시점을 넣을 수 있으며 임의 정보를 추가하지 않는다.

**지름은 지면 폭을 채우는 값이 아니다.** 원 두 개를 비교하는 108mm 자료도 각 지름은 약 22–28mm(세 개면 약 20–24mm)에서 시작하고, 남는 폭은 원 사이 틈과 각주가 쓴다. 전체 높이가 폭의 약 0.6을 넘거나 원이 각주 폭에 맞춰 커졌다면 원을 줄인다. 원 안 수치는 본문 8pt가 조각에 들어가는 크기면 충분하다. 원 밖 작은 조각 라벨은 그 조각의 바깥 방향 가까운 빈 쪽(대개 아래·옆)에 두고, 조각 가운데에서 바깥으로 곧게 나가는 약 3–5mm 지시선 하나로 잇는다. 제목 쪽으로 길게 끌어올리거나 꺾지 않는다.

새 16 chartStyle에는 pie/도넛이 없다. 우선 legacy `kind:"graph",type:"pie",series,panels:[{label,values,outside?}],labelMode:"category-percent"|"percent"`(합계100, 같은 지름, outside는 계열 인덱스)을 사용한다. 라이브 계약이 지원하는 `innerRadiusRatio`로 도넛을 만들고 `series[].pattern:"hatch"`로 사선을 자료에 연결한다. 지원하지 않는 앱에서만 해당 표현을 보충하며, 수동 무늬는 값 편집 때 자동 갱신된다고 하지 않는다. `relative`는 이 경로의 지원 옵션으로 추정하지 않는다. 실제 `vectora_apply`의 pieChart는 합계 대비 비율로 정규화하므로 사전 합계 검증 없이 비율 입력에 사용하지 않는다. 작은 조각의 라벨은 기본 행간을 압축하기보다 위치·인출선을 조정한다. 항목명+수치는 `category-percent`로 연결하고, 라이브 계약의 `piePercentUnit:"first"`로 패널별 첫 양수 조각에만 %를 쓰거나 `"none"`과 공통 단위를 사용한다. 반복 단위를 지우려고 라벨을 수동 문구로 대체하지 않는다. 자동 인출선은 삭제만 하면 재생성 때 돌아올 수 있으므로 보존되는 표시 보정을 사용한다. 최종 보정 뒤 값을 수정·복원해 항목명·수치·조각·사선과 표시 상태를 함께 확인한다.

작은 조각의 바깥 이름은 live schema의 `labelOffsets:{seriesId:{"패널번호":{direction:"upper-left"|"left"|"right"|…,content:"name"}}}`로 생성기 안에서 지정한다. 조각을 수동 도형으로 다시 그리지 않는다. 도넛 구멍 안 국가·패널 이름은 `panelLabelPosition:"center"`(굵게)로 생성기에 맡기고, `(2023년)` 같은 기준 연도는 `chartOptions.note`로 만든 뒤 마지막 원 아래 빈 모서리로 올려 글자 아랫선을 원의 아랫선 근처에 맞춘다. 원·도넛은 반드시 생성기로 초안을 먼저 만들고, apply가 실제로 거부하거나 JPEG에서 빠진 요소만 보충한다. 지원 여부를 추측해 전체를 수동 조각으로 그리면 실패다. 조각 안 글자의 흰 윤곽(무늬 없는 진회색)·작은 흰 받침(무늬 면)은 앱 자동값(effect auto)을 쓰고 직접 덧붙이지 않는다.

좁은 폭에서 아래쪽 조각의 긴 바깥 이름은 원 옆으로 밀지 않고 원 아래에 가로로 놓는다. 생성기가 예산 초과 시 자동으로 아래 배치를 시도하며, 특정 조각만 지정할 때는 `labelOffsets`의 `direction:"below"`를 쓴다. 라벨 폭 오류가 나면 원 지름을 손으로 줄이거나 라벨을 수동 글상자로 바꾸기 전에 이 배치를 먼저 쓴다.

항목명과 수치를 한 줄에 쓸지 두 줄로 쌓을지, 수치에 괄호를 씌울지, 소수 자릿수는 live schema의 `labelFormat:{layout:"inline"|"stacked",valueWrap:"paren"|"none",decimals}`로 정한다. 의뢰 원문이 `9.0`처럼 소수 한 자리면 `decimals:1`로 끝자리 0을 유지한다. 라벨을 수동 글상자로 바꾸지 않는다.
