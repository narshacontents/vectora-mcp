# ITB-1_ImageBoard — 그림 보드

그림 교체형. 사람 없이 사진·지도·그래프·삽화 칸이 든 판(신문 사진, 웹 사진, 답사 계획서 지도)

인물 해설자 없이 교체 가능한 그림/사진 자료 칸이 든 판이다. 자료 칸과 글/캡션을 대응시키고 내용에 따라 사진 원본 보존 또는 신규 삽화 제작을 선택한다.

그림과 본문을 좌우로 놓고 그림 폭이 미지정이면, 원화 종횡비에 따른 그림+캡션 높이와 8pt 제목+본문 높이를 함께 측정해 열 폭을 정한다. 그림을 관성적으로 전체 폭의 1/3로 잡아 짧은 본문 아래에 큰 빈 면을 남기지 않는다. 원화 비율·글자 크기·원문은 유지하고 열 폭을 조정하며, 명시된 그림 치수·예약 공간은 보존한다.

웹페이지의 native browser 외피에 등록한 scene 자산 하나를 배치할 때, 현재 `vectora://production/text`가 자동 열 폭 측정을 지원하면 미지정 `background.asideWidthMm`는 생략하고 문서 자산을 포함한 plan으로 확인한다. 자동 계산값을 고정 숫자로 다시 저장하지 않아야 본문·캡션·전체 폭을 바꿀 때도 재측정된다. 사용자 지정 열 폭·`asset.sceneWidthMm`·예약 치수는 유지하며, 다른 외피나 여러 자료 칸에 이 동작을 확대 적용하지 않는다.
