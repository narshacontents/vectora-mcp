# I3-23_Symbol — 점 기호도

질적 주제도. 범례가 점 기호(●□△)에 범주를 줌

같은 크기의 범주 기호를 수량 비례로 추정하지 않는다.

양적 도형을 지도에 놓는 요청을 이 유형으로 선택했다면 `proportional-map`과 내부 자료 unit으로 지침을 다시 준비한다.

원·세모·네모 등 닫힌 빈 기호는 흰 채움과 검정 외곽선으로 그려, 기호 안으로 해안선·국경이 비치지 않게 한다. 지리 위치는 기호의 실제 중심에 대응시키고, 글리프의 기준선이나 글상자 모서리를 중심으로 삼지 않는다. 기호 밖의 지형까지 넓게 지우는 흰 판은 넣지 않는다.

범례와 지도에는 같은 모양·물리 크기를 쓰고, 지시 문자는 실제 기호 외곽에서 떨어뜨려 해안·다른 문자·지도 틀과 겹치지 않게 한다. 필요한 경우 짧은 지시선을 쓴다. 현재 생성기의 지원 범주 기호·연결 범례를 우선 사용하고, 미지원 모양만 편집 가능한 벡터 도형으로 보충한다. 폭 변경 후에는 지리 중심과 기호·범례 대응을 다시 확인한다.
