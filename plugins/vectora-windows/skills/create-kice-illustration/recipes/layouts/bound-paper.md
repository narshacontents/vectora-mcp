### 제본된 페이지 — 책·노트·고리 카드·앨범

책 펼침면, 한쪽 페이지만 보이는 책, 스프링 노트, 고리로 묶은 자료카드와 앨범에 적용한다. 제본 방향·읽을 면의 수와 각 면의 내용 관계를 먼저 정한다. 단순한 종이를 자동으로 책으로 꾸미지 않는다.

- **책**: 두 페이지는 하나의 표지와 가운데 골을 공유한다. 중앙 골과 페이지 바깥쪽의 얇은 겹선·곡선으로 두께를 표현하고, 본문에는 원근 왜곡을 주지 않는다. 양쪽의 동등한 자료는 비슷한 유효 폭과 시작선으로, 사료와 해설처럼 역할이 다르면 내용에 맞는 폭으로 나눈다. 한쪽 페이지형은 읽지 않는 반대쪽을 큰 빈 면으로 만들지 않는다.
- **노트·일기·대본**: 한 변의 좁은 제본 영역과 연속된 내용 면을 유지한다. 날짜/항목/사진과 설명은 실제 관계대로 배치하며 페이지 전체를 관성적으로 동일 카드 격자로 나누지 않는다. 고리 제본을 선택한 경우에만 고리 아래 구멍과 종이 겹침으로 고정 위치를 보이게 하고 큰 타원 고리를 본문 위에 띄우지 않는다. 일반 일기·대본에 스프링을 자동 추가하지 않는다.
- **고리 카드·색인 카드**: 모서리 고리와 몇 장의 얇게 어긋난 종이 끝, 필요한 경우 작은 옆 색인으로 카드 묶임을 표현한다. 노트 전체를 작은 카드 여러 개로 대체하지 않는다. 활성 색인은 해당 면과 이어지게 하고 임의의 색인 문구를 만들지 않는다.
- **앨범·스크랩북**: 사진/우표와 캡션을 같은 묶음으로 다루고 제본 골 양쪽의 유효 면을 나눈다. 우표 톱니·사진 모서리·테이프는 선택한 재료에만 적용한다. 사진이 있어야 하는 칸을 텍스트나 빈 사각형으로 대신하지 않는다. 사진 참조 또는 새 작화 조건도 함께 준비한다.

두 면에 표와 그래프처럼 높이가 다른 자료를 넣을 때는 자료의 기본 높이를 그대로 채택하지 않는다. 문자 크기·데이터 관계를 유지하며 그래프의 세로 규모와 본문 배분을 먼저 조정해 양쪽의 시각적 무게를 맞춘다. 남는 면을 가상 문구로 채우거나 짧은 표의 행을 과도하게 늘리지 않는다.

#### 제작과 검사

현재 라이브 계약에 전용 제본 외피가 없으면 native paper/문단·표·그래프 또는 composition으로 내용부터 만들고 표지·책등·고리·겹친 페이지를 편집 가능한 보충 개체로 구성한다. 내부 API에 `variant:"book"` 같은 미지원 값을 만들지 않는다. 각 페이지는 하나의 읽기 면이며, 서로 독립인 페이지까지 한 글상자로 연결하지 않는다. 기본 paper의 테두리가 가운데 골·외피와 중복되면 지원되는 스타일 설정으로 정리한다.

본문 증가·삭제 때 내용 면과 아래 페이지 끝/제본 범위를 함께 맞춘다. 공통 외피에 필요한 가장 긴 면의 높이를 사용하되, 짧은 면에 의미 없는 빈 카드나 빈 줄을 더하지 않는다. 기본 고리의 보이는 전체 길이는 본문 한 행 높이 안팎, 페이지 밖 돌출은 약 1–2mm부터 검토한다. 작은 구멍에 걸린 짧은 곡선으로 만들고 긴 단일 타원으로 대신하지 않는다. 내부 내용 컴포넌트의 흰 배경이 페이지 곡선/겹선을 덮지 않도록 채움·쌓임 순서를 확인한다. 저장 후 고리가 가장자리에 걸려 있는지, 골·페이지 겹선이 글에 닿지 않는지, 마지막 내용 아래에 큰 빈 띠가 생기지 않는지 본다. 보충한 제본의 자동 재조판은 실제로 확인한 범위만 약속한다.
