# 출제 에이전트의 의뢰와 완료 응답

외부 출제 에이전트에서 의뢰한 경우만 적용한다. 상세 의뢰 도움말은 references/caller/exam-agent-guide.md이며 일반 제작자의 필수 읽기 문서가 아니다.

- 간단한 의뢰는 자연어로, 복합형은 상세 문장·표/JSON·첨부 자료로 받는다. 내부 분류 ID·좌표·도구 인자를 호출자가 작성하게 하지 않는다.
- 입력: 신규/수정 범위·그림의 역할과 제공된 의뢰 식별자, **표시할 원문/이름/기호/빈칸/강조**와 대상별 대응, **표시 금지 출제 맥락/정답/해설**을 분리한다. 제작 의도·검수 메모·파일명은 자동 표시하지 않는다.

- 자료/제약: 실제 제공/실제 조사/가상/정성 자료를 구별하고 값·단위·분모·시점·결측·관계·직접 출처/조사 범위·참조 파일·유지/금지 조건을 받는다. 그림 전체 외곽 목표 폭(mm), 높이 제한과 내부 내용 상자 치수를 구별하고 저장 폴더·파일명·형식·덮어쓰기 범위를 따른다. 지정 없는 저장 위치·조판은 스킬 기본값을 적용한다. 의미를 바꾸는 누락/모순은 확인하며 선택적 조판은 제작자가 결정한다.

- 완료 응답에는 의뢰 식별자(제공된 경우), 상태, 원본·JPEG 경로, 실측 외곽 치수, 실제 저장·재열기·JPEG 검수 결과와 남은 문제를 전달한다. 실자료 출처·가공과 편집 한계는 해당할 때 포함하고, 내부 분류·상세 audit 기록은 요청하거나 문제 설명에 필요할 때만 덧붙인다. 미실행·실패를 합격으로 보고하지 않으며 별도 보고 파일은 기본 납품에 추가하지 않는다.

- 후속 편집을 의뢰받으면 실제 연결 범위를 확인한다. 값→자료 도형, 지리 범위→위치, 공통 척도→범례는 서로 다른 연결이다. 연결된 범위는 해당 원자료를 갱신하고 미연결 보충 개체는 제작자가 재배치한다. 자동 연동이 없는 부분을 자동이라고 보고하지 않는다.

- 값 수정이나 짧은 본문 추가·삭제 뒤의 자료 연동·재조판도 제작자가 맡는다. 인간이 수동으로 폭·위치를 반복 조절해야 한다는 전제로 납품하지 않는다. 장식·구도·정보 우선순위는 스킬의 판단 영역이며 앱에 하나의 완성 형식을 강제하지 않는다.
