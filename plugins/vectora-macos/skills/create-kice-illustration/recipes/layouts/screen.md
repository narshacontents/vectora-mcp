### 화면 외피

웹·앱·휴대폰 화면 또는 발화 없는 방송 자막 외피다. 필요한 탭·주소창·조작부·스크롤바를 기존 프레임 안에서 선택한다. 모든 화면에 같은 아이콘을 강제하지 않는다. 방송 화면 안 장면과 자막의 역할을 분리하고 말풍선을 자동 추가하지 않는다.

요청에 화면·사이트 이름과 본문 제목이 함께 있으면 둘을 구별해 표시한다. 사이트 이름은 선택한 사이트 머리부·제호·탭 중 소속이 자연스러운 곳에 둔다. 사이트명이 있다는 이유만으로 탭이 있는 브라우저 외피를 선택하지 않는다. 이름을 생략한 빈 장식이나 제목의 임의 중복으로 명시된 매체명을 대체하지 않는다. 미제공 이름은 새로 만들지 않는다.

댓글형 화면은 본문 줄 수와 작은 흉상의 실제 높이 중 큰 값에 최소 상하 여백을 더해 행 높이를 정한다. 한 줄 댓글은 흉상 높이 약4–5mm·상하 약1mm부터 검토하며 큰 초상 슬롯 때문에 매 행을 두껍게 만들지 않는다. 교사 소개와 자료가 함께 있으면 초상·이름·소개·자료의 관계와 실제 높이로 조판하고 큰 빈 공간을 피한다. 초상 옆 소개는 가능한 구성 하나이며 모든 화면의 고정 상단으로 사용하지 않는다. 긴 본문·사용자가 지정한 초상 크기는 실제 높이에 맞춘다.

외형을 지정하지 않은 신규 제작에서는 같은 웹페이지라는 이유만으로 이전 외피 선택을 재사용하지 않는다. 같은 작업에서 여러 새 화면을 만들면 의미상 동등하게 적합한 외피 중 서로 다른 조합을 선택한다. 조작부의 구성과 작은 회색 면, 요청에 포함된 삽화의 위치·크기로 변화를 주되, 사용자 지정 구도와 충분한 본문 공간을 우선한다. 이전 완성 그림을 참조하거나 가상의 사이트명·장식 문구를 더해 다양성을 만들지 않는다. 같은 문서의 수정 요청에는 이 신규 선택 규칙을 적용하지 않는다.

#### 검사

작은 조작부는 읽을 수 있는 단순한 네이티브 벡터 아이콘을 우선한다. 뒤로/앞으로는 대칭의 같은 크기, 새로고침은 분명한 열린 원호와 촉, `+`는 가로·세로가 같은 십자로 만든다. 글꼴 문자나 여러 짧은 선을 부정확하게 겹쳐 실제 버튼을 흉내 내지 않는다. 최소화·최대화·닫기는 같은 크기의 가상 버튼 칸 안에 중심 정렬하고 칸 간격을 균등하게 한다. 작은 크기에서 판독이 어려운 비필수 아이콘은 단순화하거나 생략하되, 그 원칙 때문에 모든 웹페이지에 동일 조작부를 강제하지 않는다.

탭·주소창·작은 머리부의 글은 실제 잉크 외곽과 경계·닫기 버튼 사이에 여백을 둔다. 먼저 해당 장식 슬롯만 필요한 만큼 넓히거나 높이고, 문제 단서가 아닌 짧은 UI 이름은 읽을 수 있는 범위에서 글자 크기를 줄여도 된다. 본문을 축소하거나 탭 글자를 잘라 맞추지 않는다. 108mm 전체 그림의 확대 화면뿐 아니라 실제 인쇄 크기에서도 확인한다.

내용과 조작부/자막 경계, 옆 삽화에 의한 예약 공간 침범, 마지막 줄과 프레임 충돌을 확인한다.

화면 외피와 내부 자료 컴포넌트·예약 영역을 구별한다.

화면 내부에 주제 탭을 선택한 경우 브라우저 탭과 다른 계층으로 구성한다. 선택된 주제 탭은 자기 자료 면과 경계를 이어 주고, 비선택 탭은 뒤로 물려 보이게 한다. 질문·답변이 한 게시글이면 제공된 날짜·작성자·답글을 공유 게시글 안의 위계로 구성하며, 독립 카드로 분리할지는 요청된 관계로 판단한다. 장식을 선택한 경우 내용 면을 침범하지 않는 작은 영역에 두고, 구체적 대상은 식별 가능한 형태로 표현한다. 무관한 도형 덩어리를 겹쳐 장식으로 대신하지 않는다. 자연스러운 복잡한 무늬를 직접 그리기 어렵다면 선택된 원화 제작 경로로 작은 배경 자산만 보완하고, 읽을 글과 조작부는 편집 가능하게 둔다. 탭·배너·특정 무늬를 모든 화면의 필수 부속으로 추가하지 않는다.
