# 내용 실측으로 외곽 결정



1. **실제 본문 측정/지정 내용 상자 예약 → 내용 영역 → 주변 요소 → 최종 외곽** 순서. 실제 UND 계열과 선택한 문자 역할의 장평·자간으로 줄바꿈·줄높이를 측정하고 괄호/문장부호가 잘못 고립되지 않게 한다. 부분 굵게·기울임·바탕 지정이 있으면 그 실제 혼합 서식 그대로 측정한다. 글자 수·다른 폰트 평균폭·이전 폰트의 프레임 치수로 완료하지 않는다.

2. 내용 틀 높이 = 실제 조판 높이 + 위아래 여백. 제목·작성자·삽화·꼬리·둥근 모서리는 별도 공간. 프레임/글 획/밑줄 경계를 구별한다. **첫 생성부터** 최종 폭의 실제 줄바꿈·범위 서식·문단 박스·표 높이를 측정하고 그 결과로 외피와 다음 요소를 배치한다. 임의 고정 높이에 넣은 뒤 여백을 사후 보정하는 방식을 기본으로 삼지 않는다.

3. 다음 행 y = 현재 행의 **몸통·꼬리·인물·이름·소품까지 포함한 최하단 외곽 + 행간**. 전체 높이에 비례하여 모든 y를 늘리지 않는다. 비교 요소는 기준선·틈을 일관되게 하되 글 분량에 따라 영역을 조정한다. 내부보다 항목 사이 간격을 크게 해 묶는다.
