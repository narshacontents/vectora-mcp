# D1-04_Nested — 병합헤더표

헤더 2겹 이상 또는 병합 셀·섹션 띠. 대각선 모서리 칸만으로는 Nested 아님(R6)

헤더 2겹 이상, 병합 셀 또는 섹션 띠가 있는 표다. 상위 헤더 범위와 하위 열/행을 정확히 맞추고 병합 내부에서만 격자선을 생략한다. 데이터 셀까지 병합 의미가 번지지 않게 한다. 섹션 띠·소계·총계는 제공된 구획만 사용한다.

셀에 native `content`가 있다는 사실만으로 이 분류를 선택하지 않는다. D1-04는 병합 헤더·병합 셀·섹션 띠의 표 구조를 뜻한다.

행마다 병합 경계가 다를 수 있다. 본문 셀이 상위 머리글 경계를 넘어 여러 하위 열을 묶는 요청은 그 범위까지 보존하고, 모든 행의 세로선을 일률적으로 맞추지 않는다. 아래 설명의 문단 박스와 표 안의 같은 기호는 의미를 대응시키되 별도 편집 요소로 유지한다. 표 밖에서 보충한 화살표는 자동 셀 내용으로 간주하지 않으며, 행 높이·열 폭을 바꾼 뒤 해당 셀과의 대응을 다시 맞춘다.

지원 연결본에서는 task instructions에 선택된 표 family의 현재 제작 계약을 사용한다. 지원되는 rowSpan/colSpan으로 병합하고 모든 칸의 유일한 소유를 확인한다. 대각선 머리글을 함께 쓰는 경우도 live 셀 계약에 맞춰 소유시키고 실제 병합 영역 안의 배치를 확인한다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
