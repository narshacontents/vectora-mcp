# I2_Illustration — 새 삽화

자료 분류에는 하위 코드가 없지만 제작 시에는 `illustration-portrait`(독립 얼굴/흉상), `illustration-object`(물체/생물), `illustration-scene`(동작/풍경/복원 장면) 중 하나를 선택한다.

원래 I2 계열의 신규 작화다. 유물·주화·국기·문장의 선화 재작화도 포함한다. 실제 사진/스캔/기존 작품 자체의 복제는 Photo다. 형태·재질·행동을 전달하는 자연 장면은 Illustration, 연결·단면·공간 구조·속성 좌표 등의 관계가 핵심인 모식은 Diagram이다. ‘모식도’라는 명칭이나 정량값 유무만으로 자연 장면을 일괄 분류하지 않는다. 공간 기준 위의 위치·영역·분포·이동은 Map이다.

장면 속 사람도 인물 예외 원칙의 해당 조건을 확인한다. 여러 대상이 있어도 하나의 장면이면 한 단위다. 발화가 핵심이면 ITA·ITB·ITC의 분류 경계를 적용하되 장면을 정형 가로대화로 강제 변환하지 않는다. 독립된 완결 자료가 있는 복합형만 요소를 분리한다.

지정 대상의 참조 검색과 벡터화 여부·공통 변환·검수는 선택한 세부 문서의 조건을 적용한다. 핵심 대상이 가장 큰 비중이며 배경·소품은 의미를 보완한다. 실루엣→겹침→명암→세부 순으로 제작한다. 문자·식별 기호·인출선·자료 도형은 별도 개체다. 라벨마다 뜻하는 실제 대상/부위를 먼저 지정하고 인출선 끝이 그 영역에 닿는지 확인한다. 가까운 사람·기계 외곽이나 모호한 경계로 대신하지 않는다.

소품의 윤곽·망·세부 밀도는 주대상과 맞춘다. 소형 출력에서는 공통 회색조 화풍의 큰 면과 명료한 선화를 우선하고 사진 같은 표면 질감·촘촘한 털선·음영을 줄여 식별 구조를 남긴다. 작은 테두리/격자가 검정 덩어리로 뭉치면 배율과 최종 물리 굵기를 확인하고 세부를 단순화한다. 미세 획 개수를 완성도로 대신하지 않는다. 대상 수·식별 특징·구조·일관된 화풍을 확인하고 임시 도식만 만든 것을 완성 삽화로 보고하지 않는다.

## 선택 세부 문서 준비

- 인물이 있으면 `--people`; 생물 구조/부분 확대는 `organic`; 내부까지 순수 벡터를 명시한 경우만 `vectorize`.
