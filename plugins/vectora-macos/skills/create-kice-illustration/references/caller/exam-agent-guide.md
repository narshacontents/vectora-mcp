# 출제 에이전트의 일러스트 의뢰

출제자는 평가 요소·정답·자료 타당성을 정하고, `create-kice-illustration` 제작자는 편집 가능한 그림과 JPEG를 만든다. 이 이름은 MCP 함수명이 아니라 스킬이다. 제작 환경에서 원본 파일을 실제로 열 수 있고 필요한 Vectora 도구가 연결되어 있는지 확인한다. 다른 컴퓨터의 경로만 전달해 파일이 공유됐다고 보지 않는다.

## 의뢰에 담을 내용

간단한 의뢰는 자연어로 충분하며, 복합 자료는 상세 문장·표·JSON·첨부로 전달해도 된다. 아래에서 해당하는 내용만 알려준다. 정해진 스키마를 채울 필요는 없다.

- **역할과 표시 범위:** 학생이 읽을 관계·비교 목적과 실제 인쇄할 원문·이름·기호·값·단위·빈칸·강조를 구별한다. 제작에 필요한 정답·해설·출제 의도는 표시 금지로 분리하고, 출처 표기와 각주 원문도 따로 준다. 파일명·제작 메모는 자동으로 인쇄하지 않는다.
- **자료의 성격과 근거:** 제공된 실제 자료 / 조사할 실제 자료 / 가상 / 정성 자료를 구분한다. 실제 자료는 지역·기간·정의·단위·분모·결측과 직접 출처·참조 파일 또는 조사 범위를 준다. 알려진 라이선스·이용 조건·필수 크레딧도 전달하고, 조사할 자료는 제작자가 이를 확인한다.
- **관계와 구도 의도:** 항목 간 대응·순서·방향·포함 관계와 각 블록의 내용을 준다. 복합형은 동등 비교, 주자료와 설명, 전체와 확대 부분 중 어떤 관계인지 알린다. 나란히·위아래 등 의미상 고정된 배치만 지정한다.
- **보존·금지:** 유지할 원문·수치·원본 특징·관계와 바꾸거나 추가하면 안 되는 내용을 준다. 특정 인물·유물·지역은 정확한 명칭과 있는 참조를 전달한다. 원본 재현은 해당 파일과 재현 범위를 명시한다.
- **신규·수정과 크기:** 수정은 접근 가능한 기존 `.vectora`, 바꿀 대상·내용, 유지할 조건을 준다. 필요한 크기는 제목·범례·이름표까지 포함한 **최종 외곽 폭(mm)**과 높이 제한으로 말하고, 내부 자료 영역·예약 상자 치수와 구별한다. 빈 공간만 남기면 용도와 줄 수 또는 크기를 준다.
- **납품:** 필요한 폴더·파일명·형식·덮어쓰기 범위, 의뢰 식별자가 있으면 함께 준다. 미지정 사항은 스킬 기본값을 따른다.

## 의미가 달라질 수 있는 조건

- **표·도식·대화:** 표의 행·열·묶이는 머리글, 도식의 연결 방향·포함 관계, 화자별 정확한 발언·순서를 준다. 발언 수정은 바뀐 문장·화자·유지할 인물과 구도면 충분하다.
- **그래프:** 범주·계열·시점·값과 각 축의 지표·단위·계열 대응을 준다. 이중축의 좌우 대응, 기간의 두 끝점, 구성비의 패널별 계열 순서, 정확한 값 라벨이 풀이에 필요한지도 구별한다. 산점·버블은 대상별 X·Y와 크기가 뜻하는 수량을 준다. 정성 개형은 숫자를 만들지 말고 대소관계·시점 순서·이동 방향·교점과 기호를 준다. `0`과 `O`, 아래첨자, 원점·축과 만나는 위치의 의미를 보존한다.
- **지도:** 대상과 주변 맥락 지역, 전체 지명·행정 단위·기준 시점·주제층, 반드시 남길 섬·수역·지물을 준다. 위치 찾기용 지명과 인쇄할 A·B 등의 표기를 분리하되 익명 범례의 실제 의미는 제작자에게 알린다. 국가별 채색/문화권, 위치 기호/수량 비례원, 전체 목록/대표 사례, 육상·연안·직선 경로를 구별한다. 위치 식별용 부분도인지 세부 관계를 읽는 확대도인지, 역사 영역의 시대·분류, 등고 간격·피해 범위 기준이 평가 조건인지도 알려준다. 지도 설명 상자는 `표시 지점 → 기호 → 설명 원문`으로 대응시킨다. 설명 속 출발지·경유지를 연결 지점으로 추정하지 않는다.

지도 출처가 없으면 공공·학술·교육 자료에서 위치·경계·시점을 확인하도록 의뢰할 수 있다. 세부 좌표를 모두 준비할 필요는 없다. 도법·중심·상세도·경계 표현이나 그래프 축·범례·무늬의 모양은 평가 의미 또는 원본 재현에 필요한 조건만 지정한다. 무늬는 의미·참조·저장한 견본 이름으로도 전달할 수 있다.

반복 양식은 “두 사람의 비판 관계도, 갑·을과 A·B, 범례·예시를 같은 고정 양식으로”처럼 자연어로 의뢰한다. 등록 구조와 맞으면 도형·연결·간격을 보존하고 제공한 내용만 바꾼다. 고정 그래프는 축·패널·범례의 형태를 유지하면서 값에 따른 막대·곡선·점만 바꾼다. 같은 양식의 폭만 달리 요청할 수 있으며, 미지정 독립 그림은 형식별 작은 기본 폭을 사용한다. 새 분기·인원은 별도 구도로 요청한다. 범례는 내용에 따라 상자도 커지거나 작아지며, 위아래 범례·예시는 같은 너비와 내부 가운데 정렬을 유지한다. 글이 고정 칸에 넘칠 때 원문을 줄이거나 글씨를 몰래 축소하지 않으며, 의미를 보존할 다른 구도가 필요한지 알린다. 신문·웹페이지·일반 그래프·지도까지 하나의 외형으로 고정하는 규칙은 아니다.

지도 경로는 출발·도착과 필요한 경유지를 주고 **실제 노선/정성적인 이동 연결**을 구별한다. 지역 경계가 평가 요소이면 기준 시점도 준다. 격자 자료는 행·열 순서와 같은 칸의 대응을 전달한다. 정성 경제 개형은 곡선 역할·이동 방향·교점 순서를 주면 충분하며, 의미 없는 제작 좌표나 선 끝 위치까지 정할 필요는 없다.

## 제작과 수정의 경계

내부 recipe ID·도구 인자·요소별 좌표·간격·스타일 수치는 제작자가 정한다. 제작자는 내용 묶음·대응·보존 조건·검수 항목을 짧게 계획하고 실제 결과에 맞춰 보정한다. 일반 생성에 기출 이미지 검색·열람을 추가하지 않는다. 명시한 원본 재현에서는 같은 값·범위·물리 크기로 대조한다.

원본과 확정 문구·수치·단위·부호·순서는 보존한다. 실제 자료 조사에서 허용한 환산·반올림·표시 가공은 원자료와 구분하고 출처·방법·정밀도를 남긴다. 이미지에서 추정한 값·임시 배치 수치·임의 곡선을 실측값으로 쓰거나 미제공 자료를 복원했다고 하지 않는다. 정답 해석을 바꾸는 누락·모순만 확인하고 일반 조판은 제작자에게 맡긴다.

충돌은 배치·라벨·가용 영역을 고쳐 해결하며 실제 자료 좌표나 의미를 바꾸지 않는다. 후속 편집은 연결된 원자료·본문을 수정하고, 값→자료 도형·지리 범위→위치·공통 척도→범례의 연결을 각각 확인한다. 외부 GIS 파일 확보나 독립 도형 편집 가능만으로 재투영·자료 연동을 약속하지 않는다. 자동 재배치는 실제 소유 관계가 연결된 범위에만 적용되며, 별도 자료판·보충 개체는 제작자가 다시 배치한다. 인간의 반복 위치·폭 보정을 전제로 납품하지 않는다.

## 받는 파일과 확인 결과

기본 납품은 같은 본체 이름의 **`.vectora` + `.jpeg` 한 쌍**이다. 지정 형식·위치가 우선하며 제작자는 실제 쓰기 가능 여부를 확인한다. 저장본 재열기와 저장된 JPEG 직접 검수로 원문·자료·관계·최종 외곽을 확인한다. 회신에는 의뢰 식별자(있는 경우), 상태, 두 파일의 실제 경로, 실측 외곽 치수, 저장·재열기·JPEG 검수 결과, 해당하는 출처·가공·편집 한계와 남은 문제를 받는다. 미실행·접근 불가·미지원은 완료로 보고하지 않으며 별도 검수 파일은 요청할 때만 추가한다.

문항에 넣기 전 출제자가 자료 해석·정답 유일성·불필요한 정답 노출을 확인한다.
