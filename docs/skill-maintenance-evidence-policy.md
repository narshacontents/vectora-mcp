# 스킬 기본값의 유지보수 근거와 제작 경계

2028 평가원 예시문항 우선은 앱·스킬의 시각 기본값을 개선하는 유지보수 기준이다. 일반 그림 생성에는 기출 검색·열람·기출 원본 이미지 확보·사례별 재보정을 요구하지 않는다. 배포 스킬에는 추출된 역할별 원칙·수치 시작값·적용 조건을 자립적으로 남긴다. 사용자가 명시한 원본 재현, 실제 데이터 조사·웹 검색, 실존 인물·유물·장소의 참조 확인은 해당 요청의 제작 절차로 유지한다.

유지보수자가 여백·축·선폭·상세도 등 기본값을 변경할 때는 2028 예시문항을 우선하고 최근 5개년의 같은 역할·구도 기출을 최소 2문제 확인한다. PDF 배치 크기의 잉크 간격·선폭·자료 영역과 전체 그림/자료 영역 대비 비율을 측정하고, 같은 값·범위·물리 크기로 재현해 겹쳐 비교한다. 원본 래스터의 불확실성과 정확한 자료/이미지 추정값을 구별한다. 감각적 의견과 근거가 다르면 차이를 설명하고 기출 근거를 우선하며, 비례성이 확인된 항목만 크기 연동 기본값으로 만든다. 이는 개발 검증이며 일반 생성 단계가 아니다.

개별 시험 식별자·원본 위치·측정표·비교 렌더·회귀 이력은 유지보수 기록에 둔다. 상세 이력을 배포 지침에 복사하거나 유지보수 기록을 생성기의 조회 의존성으로 연결하지 않는다. 추출된 수치 계약과 조건은 출처 문구를 제거한다는 이유로 삭제하지 않으며, 특정 사례의 수치를 다른 역할에 보편 강제값으로 넓히지 않는다. 지도 원자료의 시점·통계 단위·좌표·권리 및 라이브 기능 확인은 실행에 필요한 정보로 보존한다.

축 간격의 기존 관찰 요약: 경제 개형 두 사례의 전체 폭 약 56/70mm에서 X제목–마지막 눈금은 약 2.7/2.5mm, Y제목–축은 약 1.10/1.14mm였다. 전체 폭 일괄 비례보다 같은 글 크기에서의 짧은 실제 잉크 간격을 지지한다. 생성 지침에는 이 비교 이력 대신 역할별 간격 시작값과 적용 조건을 남기며, 새 기본값 변경의 측정 증거를 이 요약만으로 대체하지 않는다. 한국 지도 보존율도 90m 전처리 바탕의 제작 시작값이며 기출의 실제 작업 수치로 해석하지 않는다.
