# ITC_Fixed

고정형. 특정 인물·실존 인물 사진·특정 장소/사건·시대 복장이 식별 단서인 경우이며 ITA·ITB보다 먼저 판정한다. 갑·을 같은 화자 기호만으로 특정 인물로 분류하지 않는다.

| 세부유형 | 선택 기준 |
|---|---|
| [ITC-1_Figure · 특정 인물](../subtypes/ITC_Fixed/ITC-1_Figure.md) | 고정형. 얼굴·차림으로 누군지 알아보는 특정 역사 인물·사상가(칸 만화 포함) |
| [ITC-2_RealPhoto · 실존 인물 사진](../subtypes/ITC_Fixed/ITC-2_RealPhoto.md) | 고정형. 실제 인물의 초상·보도 사진이 단서 |
| [ITC-3_Place · 특정 장소·장면](../subtypes/ITC_Fixed/ITC-3_Place.md) | 고정형. 특정 건축물·광장·유적·사건 현장이 배경이자 단서 |
| [ITC-4_Costume · 시대 복장 인물](../subtypes/ITC_Fixed/ITC-4_Costume.md) | 고정형. 특정인은 아니지만 복장(관복·승복·갑옷 등)으로 시대가 정해진 인물 장면 |

SKILL.md의 조건부 제작 규칙에서 실제 발언·인물·외피·내부 자료에 해당하는 절만 적용한다. 독립적으로 완결된 내부 표·차트·지도는 공통 복합형 경계에 따라 분리한다.
