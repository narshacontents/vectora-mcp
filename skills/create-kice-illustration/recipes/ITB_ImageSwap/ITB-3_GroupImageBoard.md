# ITB-3_GroupImageBoard — 여러 명 + 그림 보드

그림 교체형. 여러 사람 + 지도·그래프·그림 보드·자료

여러 해설자와 교체 가능한 그림 자료를 대응시킨다. 발언 순서와 자료 지시 대상을 유지하고 인물/말풍선이 주자료를 가리지 않게 한다.

보드 속 지도·그래프·표는 실제 정보 외곽으로 배치하고 독립 편집 관계를 유지한다. 명시된 교실 앞뒤·집단 토론 장면은 그 공간 관계를 보존한다. 발언과 인물은 비내용 배경을 덮을 수 있지만 점·축 제목·범례·주석을 가리지 않는다. 아래쪽에 여러 발언을 놓을 때 주자료의 최하단과 학생 머리/말풍선의 실제 최상단을 기준으로 간격을 잡아 빈 가로 띠를 남기지 않는다.

화면을 보는 청중의 뒷모습은 머리·목·어깨로 식별 가능한 작은 흉상부터 배정한다. 줄 폭을 인물 몸통으로 꽉 채우거나 불필요한 허리까지 보여 주어 자료보다 사람 행이 커지게 하지 않는다. 이름은 각 인물의 가쪽 빈 배경에 붙이는 기본을 유지하고 검은 머리·의복 위에 겹쳐 놓지 않는다. 여러 인물의 개별 위치·크기 편집이 필요한 구성은 각각의 자산으로 배치한다. 한 장의 집단 원화를 선택하면 사람별 독립 편집이 제한됨을 기록한다.
