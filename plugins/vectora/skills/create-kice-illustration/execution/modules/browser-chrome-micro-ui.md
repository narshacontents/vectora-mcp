# 브라우저 탭·도구 모음

브라우저를 알아보게 하는 작은 장식 UI에만 적용한다. 기사 제목·본문·말풍선의 기본값을 바꾸지 않는다.

- 새 `compact-v2` 외피는 현재 앱의 기본 높이로 시작한다. 기본 높이가 10mm인 앱에서는 이를 반복 명시하지 않는다. 기존 문서나 사용자의 명시 높이·글꼴·크기는 보존하며, 실제 겹침이 있을 때만 해당 장식 영역을 재계획한다.
- 탭 제목은 **실제 글 획**을 기준으로 위아래 테두리와 떨어져야 한다. 위아래 약 0.6–1mm를 출발 여백으로 보고 최종 인쇄 크기에서 판단한다. 창/탭 높이를 늘리면 본문 시작점과 외피도 같은 네이티브 소유 관계에서 따라오게 한다. 장식 영역만 키운 뒤 본문에 겹쳐 덮지 않는다.
- 긴 이름은 한 줄 잉크 폭과 진행 폭, 닫기 표식, 양끝 여백을 함께 측정한다. 닫기 표식과 글 획이 붙지 않게 약 0.6mm 이상부터 검토하고 탭의 가로 폭을 배분한다. 탭 행 높이만 늘려 가로 충돌이 해결됐다고 하지 않는다. 사용자 지정 내용·서식은 유지하며, 장식용 문자의 축소가 허용되더라도 먼저 외피의 남는 공간을 확인한다.
- 뒤로/앞으로·새로고침·닫기는 지원되는 작은 벡터 장식으로 일관되게 사용한다. 뜻이 불분명한 임의 도형이나 문자 조합을 추가하지 않는다. 본문보다 장식이 더 넓거나 짙게 주목되지 않게 한다.
- 저장된 JPEG에서 짧고 긴 이름 모두 글의 위·아래·오른쪽 간격을 확인한다. 새 생성과 내용 갱신·재열기에서 동일하게 유지되는지 확인하고, 정해진 브라우저 한 가지 모양을 반복할 필요는 없다.
