# I3-11_Locator — 위치 지시도

일반도. 칠한 면·그은 경계·점이 정답 후보 자리일 뿐이고 (가)·A~E로 '어디(어느 나라)인가'를 맞추게 함. 면을 칠했든 아니든, 범례가 수도·국경 기호뿐이면 여기

칠한 면이 단순 위치 후보이면 영역 주제도로 바꾸지 않는다.

2028 예시문항의 위치 지시도처럼 **위치점만 비교하는 자연 배경**과 **국가 자체를 비교하는 배경**을 구별한다. 전자는 필요한 해안선·위치점 중심으로 국경을 생략하고, 후자는 해안선 실선·국경 파선 위에 선택 국가의 중간 회색 면을 둔다. 바다와 육지 명도는 두 영역이 쉽게 구별되도록 선택하며 두 형식을 한 색 규칙으로 강제하지 않는다. 작은 세로 지역도는 얇은 사각 창에 필요한 주변까지 담고, 적도 표시만 필요한 경우 위경도 전체 격자를 추가하지 않는다. 기존 도법·범위 선택 원칙은 유지한다.
