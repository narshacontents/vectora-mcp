# 공통 제작 기준

필수 제약과 사용자 지정 사항을 보존한다. 기본값은 별도 지시가 없을 때 적용하며, 조건부 예외는 해당 대상에만 적용한다. 자료 분류는 검색 정보이며 읽기 계층이 아니다.

## 기본 스타일의 기준

**2028학년도 평가원 예시문항 시험지의 형식을 기본 기준으로 한다.** 해당 시험지에 있는 구성은 거기서 추출해 이 스킬에 정리한 선·명도·서체 역할·배치·간격을 적용한다. 해당 시험지에 없는 구성만 기존 평가원 기출에서 정리한 기본값으로 보완한다. 같은 유형의 예전 기출이나 과거 생성 결과가 다르다는 이유로 기본 기준을 되돌리지 않는다. 복합형도 구성요소별로 이 우선순위를 적용한다.

사용자의 이번 명시 조건, 보존해야 하는 원문·자료·편집 구조가 기본값보다 우선한다. UND 3.1 계열의 선택한 문자 스타일·실제 pt·장평·자간 등 제작 규격을 유지한다. 원본 폰트 차이까지 픽셀 단위 동일하다고 약속하지 않는다. **생성 때 시험지나 완성 예시를 다시 열어 복사하는 방식이 아니라**, 선택된 지침의 형식 원칙으로 새 내용을 조판한다. 구도와 장식의 다양성은 그 원칙 안에서 유지한다.

## 필수 보존

사용자 제작 원칙이다. 현재 요청에서 설계하고 과거 예시·기출·카탈로그·측정표·완성 템플릿 복사/추적·예시 ID 선택을 하지 않는다. 이번 요청의 자료·명시된 원본 재현/동일 인물·승인 지도 바탕은 참고/재사용할 수 있다.

- **한 문항의 가로폭은 약 108mm**다. 전체 단을 쓰는 자료의 미지정 폭은 108mm로 하고, 삽입된 부분 자료·독립 소형 그림은 그 안의 상대 폭 또는 사용자 지정 폭을 따른다. 원본 분석도 시험지의 문항 단 폭에서 계산하며, 글자를 8pt로 맞추려고 그림 전체를 축소하지 않는다. 사용자 지정 폭은 대지가 아니라 **그림 전체의 실제 외곽 폭**이다. 선택한 문자 스타일의 pt·선폭을 유지하며 줄바꿈·영역·간격 조판으로 먼저 지정 폭에 가깝게 맞춘다. 대지만 지정 폭으로 늘이거나 가짜 배경으로 폭을 채우지 않는다. 높이 상한으로 해석하지 않는다.

- 원문·밑줄·식별 기호·빈칸·수치·소수 자릿수·관계를 유지한다. 수량 자료는 무엇을 측정한 값인지 알 수 있도록 요청에 있는 지표명·한정어를 머리글·범례·공통 표제 중 적절한 곳에 보존한다. 이를 충실히 표시하는 것은 임의 제목 추가가 아니다. 빈칸 정답, 요청 없는 이름·제목·해설·기관·연도를 추가하지 않는다. 유형별 매체 기본 표기(신문의 ○○신문·기호 날짜)는 적용하고 실제 기관명·현재연도를 추정하지 않는다. 제작/검사 기록은 그림 밖에 둔다. 자료가 가상이라는 작업 조건도 그림에 표시할 문구는 아니므로, 표시 요청 없이 ‘제공된 가상 자료’ 등을 주석·출처로 넣지 않는다. 실자료 확인·환산은 아래 조건을 따른다.

- 단위·기준 시점은 적용 자료 가까이, 주석·출처는 그 아래 여백에 둔다. 독립 표·지도·그래프가 함께 있으면 각각의 단위 적용 범위를 읽을 수 있어야 한다. 공통 표기가 모두에 적용됨이 명확하지 않으면 자료별로 표시하고, 한 자료 아래 범례의 단위만으로 다른 자료의 단위를 대신하지 않는다. 여러 자료의 단위/출처를 섞지 않는다.

- 새 그림은 별도 문서, 수정은 지정 범위만. 문자·말풍선·자료 그래프·도식은 독립 편집 요소; 원화는 이동·비례 크기·교체 가능한 포함 이미지여도 된다. 전체 조판 래스터화/본문 전체 윤곽선화를 편집 원본으로 취급하지 않는다.

- 벡터 선·화살촉·선 역할의 채움 경로는 **#000000, 유효 불투명도 100%**(상위 그룹 포함). 강약은 굵기/실선·파선으로 구별한다. 아래 판독성 처리의 흰 받침·흰 윤곽은 검정 본선을 읽게 하는 예외이며 본선 색은 유지한다. 미지정 선폭은 아래 기본값을 따른다.

- 회색 **채움/명암 면**은 허용한다. 원화 픽셀은 검정으로 치환하지 않는다. 매체/활동 외피의 구조·작은 장식·접촉 그림자에 필요한 국소 회색 선은 이유·요소를 기록하고 허용하되 기본 윤곽은 검정. 이를 내부 표·차트·대화·도식의 회색 선 예외로 확장하지 않는다. JPEG 안티앨리어싱은 설정상 회색 선과 구분한다.

- 원은 1:1, 인물·사물은 자연스러운 종횡비, 상대 크기는 머리끼리 비교한다. 글·선 규격을 유지하며 영역·줄바꿈·라벨을 조정하고 전체 Scale/압축/textLength로 맞추지 않는다. 지도 바탕만 문자·지시선 전에 비례 조정한다.

## 미지정 시 기본값과 AI의 판단

- **시각적 묶음과 정렬을 먼저 설계한다.** 한 자료로 읽을 도형·라벨·단위·범례는 서로 가까이, 독립 자료 사이에는 그 내부 간격보다 넉넉한 틈을 둔다. 모든 틈을 같은 값으로 만들거나 충돌만 피한 채 라벨을 고립시키지 않는다. 같은 역할의 요소는 공통 정렬선을 사용한다. 글상자/투명 바탕의 외곽이 아니라 실제 보이는 문자 획과 도형의 외곽으로 간격·중심을 판단한다.
- 한 묶음 안의 여백은 지침 범위의 작은 쪽에서 시작하고, 실제 획이 닿거나 대응이 흐려질 때만 늘린다. 라벨↔자기 선·표식, 행 이름↔행 시작, 손끝↔가리키는 자료를 서로 고립시키지 않는다. 생성기 패딩과 제작자가 추가한 간격이 중복되었는지 먼저 확인한다. 독립 자료 사이의 구분 공간·본문 판독 여백·지정 예약 영역까지 일괄 축소하지 않는다.
- 전체 제목은 전체 내용 영역의 가로 중앙, 소제목은 자신이 설명하는 자료 영역의 중앙을 기본으로 한다. 축 제목·단위·본문의 문단 정렬은 전체 제목과 구별하며, 사용자 지정이나 매체상 의미가 있는 정렬은 보존한다.
- **선의 역할별 위계**를 먼저 정한다. 일반 틀·범례 테두리·인출선은0.3pt, 보조선은0.2pt, 축은0.4pt를 출발값으로 삼되 대략0.2–0.4pt 안에서 조밀함·최종 인쇄 크기에 맞춘다. 자료선·상태/기간 화살표처럼 내용을 전달하는 주선은 해당 유형의 더 굵은 기본값을 쓴다. 모든 선을 같은 굵기로 맞추지 않으며, 자료선 > 축·틀 > 보조선의 구별이 실제 JPEG에서 읽히는지 판단한다. 회색 면 경계·원화·작은 지도 기호에는 독립 자료선의 굵기를 일괄 적용하지 않는다.
- 유형별 수치는 사용자가 고정하거나 기술 계약이 요구한 값을 제외하면 출발값이다. 기출에서 읽히는 역할·밀도·위계를 따른 범위와 기본값이며 모든 원본을 정밀 역산한 규격표가 아니다. 내용이 읽히는 대응·묶음과 자연스러운 비율을 먼저 확보하며, 범위를 벗어나야 한 실제 이유만 남긴다. 내용·글 크기를 바꿔 숨기지 않는다.
- 구도·장식·회색 면·소품은 해당 매체의 공통 형태와 내용 여유 안에서 제작자가 선택한다. 과거 결과의 같은 외피·좌표·장식을 반복할 의무가 없고, 다양성을 위해 무관한 장식이나 의미를 추가하지도 않는다.
- 숫자 변경이나 짧은 문구 수정 뒤에도 자료 관계와 읽기 순서가 유지되는 편집 원본을 만든다. 필요한 재조판은 AI가 마무리하며 사용자에게 폭·위치의 반복 수정을 떠넘기지 않는다.

## 선·회색 바탕 위의 판독성

- 점선·눈금 보조선·상자 윗선 위에 글자를 놓아야 하면 **문자 뒤에 작은 불투명 흰 배경**을 둔다. 정렬·자료 대응 위치는 유지하고 실제 글 획 전체와 글자 사이 공간을 덮되, 여백은 약0.15–0.3mm부터 최소한으로 정한다. 빈 글상자 전체를 흰색으로 채우지 않는다. 가는 글자 윤곽만으로 글자 사이를 지나는 선까지 가려졌다고 판단하지 않는다.
- 회색 면 위 글자는 바탕을 크게 지우는 사각형 대신 **읽히는 두께의 흰 윤곽선**을 사용한다. 미지정이면 #AAAAAA 정도 이상으로 어두운 회색에서 적용하고, 더 연한 면도 무늬·선 때문에 획이 묻히면 적용한다. 보이는 바깥 테두리 **0.7pt**를 기본으로 실제 인쇄 크기로 확인하며 글자를 두껍게 만들거나 내부를 흰색으로 바꾸지 않는다. 이 농도·두께는 판단의 출발값이다.
- 색칠된 지도 위 지시선에는 **같은 경로를 따라 양옆에 얇은 흰 테두리**를 두고 그 위에 검정 본선을 유지한다. 지리 anchor·연결 끝점·선 굵기는 바꾸지 않고, 흰 띠는 약0.2–0.3pt씩부터 검토한다.
- 위 처리로 자료점·자료선·중요한 경계·다른 글을 가리지 않는다. **흰 받침은 뒤의 보조선을 가리는 수단이지 관측값을 이은 자료선을 지우는 수단이 아니다.** 실제 글 획뿐 아니라 흰 받침 외곽도 자료선과 대조한다. 문자·선에 연결된 효과를 우선하고, 별도 배경을 보충했다면 글/경로 수정·이동·저장 재열기 뒤 크기와 위치도 따라 맞춘다. 배경을 피하려고 정렬된 숫자 하나만 옆으로 밀거나 자료 좌표를 바꾸지 않는다.
