# D1-04_Nested — 병합헤더표

헤더 2겹 이상 또는 병합 셀·섹션 띠. 대각선 모서리 칸만으로는 Nested 아님(R6)

헤더 2겹 이상, 병합 셀 또는 섹션 띠가 있는 표다. 상위 헤더 범위와 하위 열/행을 정확히 맞추고 병합 내부에서만 격자선을 생략한다. 데이터 셀까지 병합 의미가 번지지 않게 한다. 섹션 띠·소계·총계는 제공된 구획만 사용한다.

지원 연결본에서는 유형 공통의 현재 제작 계약을 사용한다. 지원되는 rowSpan/colSpan으로 병합하고 모든 칸의 유일한 소유를 확인한다. 대각선 헤더는 전용 표의 지원으로 주장하지 않는다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
