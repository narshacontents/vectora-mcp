## 면 채움·무늬·면 라벨이 있을 때

- 해안 띠·문화권처럼 국경과 무관한 영역도 바탕 지도는 지도 생성기로 만들어 단순화·작은 섬 정책을 적용하고, 그 위에 영역 면만 보충한다. 해안선 자료를 직접 그려 바탕 지도를 대신하지 않는다.
- 동일 회색 국가 강조·서로 다른 명목 범주·국경과 무관한 산업/문화 영역을 구별한다. 농도 차이로 수치 등급을 추정하지 않는다. 사용자 정의 영역은 제공 윤곽이나 근거 있는 자료로만 만든다.
- **대륙·국가 규모 지도에서 산업 지역·광산·도시권은 실제 면적이 아니라 기호 크기로 그린다.** 실제 경위도 범위가 최종 출력에서 2.5mm보다 작으면 중심을 유지한 채 점을 바깥으로 넓혀 긴 쪽 약 3mm로 만든다. 미리보기에서 지시선 끝보다 작아 보이면 실패다.
- 산업 지역·도시권처럼 작은 지점형 영역은 실제 분포 방향을 따라 약간 길쭉하고 불규칙한 작은 면(최종 출력에서 긴 쪽 약 2.5–4mm, 1.5mm보다 작으면 키운다)으로 그린다. 점은 육지 안에 찍어 면이 호수·바다를 덮지 않게 한다. 점을 고른 간격·같은 반지름으로 찍으면 매끈한 타원이 되므로, 간격과 중심 거리를 들쭉날쭉하게 해 한쪽이 들어가거나 튀어나온 모양을 만든다. 정다각형·육각형·완전한 원처럼 기계적인 모양은 쓰지 않는다. 지도 `overlays:[{kind:"area",points:[{longitude,latitude}… 4–8점],interpolation:"smooth",fill,legendCategoryId}]`로 실제 분포 위치의 경위도를 찍어 만들고, 손으로 다각형을 그리지 않는다. 범례 견본은 `legendCategoryId`로 연결한다.
- 정성적 분포를 허용한 경우에도 제공된 지역의 띠·분리 면·육지/바다 관계를 유지한다. 사막화·삼림 감소처럼 넓고 불규칙한 분포를 근거 없이 몇 개의 원·타원으로 치환하지 않는다. 반대로 개략적 범위를 정밀한 통계 경계처럼 표현하지 않는다.
- 문화권·역사 영역처럼 **범위 자체를 구별하는 자료**는 면·연속 경계와 라벨이 함께 그 범위를 읽게 해야 한다. 몇 개의 라벨과 중간에 끊긴 선만 놓고 영역 표시를 대신하지 않는다. 개략 윤곽도 긴 직선 조각의 임의 다각형처럼 보이지 않게 하되, 보기 좋게 다듬는 과정에서 경계의 의미나 육지·바다 관계를 바꾸지 않는다.
- 주변 바다까지 감싸는 문화권 표시와 육지에만 분포하는 자연환경 채움은 서로 다른 표현이다. 모든 영역에 육지 마스크를 강제하지 않는다. 좁은 후보 지역은 작은 면으로 표시하며, 수량이 없는 위치 영역을 임의 크기의 비례원으로 바꾸지 않는다.
- 명목 범주는 채움·점/선무늬·범례로 구별한다. 중복 범주의 겹침과 복수 대응을 유지하며 순서 있는 수치 단계로 바꾸지 않는다.
- 면 내부 라벨 또는 바깥 인출선을 크기에 따라 선택한다. 한 라벨로 본토/여러 섬을 식별하면 필요한 여러 인출선을 쓴다. 인출선은 도시 점과 별개다.
- 무늬는 확인한 대상 폴리곤 전체에 적용한다. live production create의 `spec:{kind:"pattern",sourceId,pattern:"dots"|"hatch",spacingMm,…}`와 실제 지원 dotDiameterMm/strokePt/angle·옵션/상한을 스키마로 확인한다. source 면·윤곽 복제·marks 순서와 mask를 검수한다. 같은 국가의 분리면도 빠짐없이 대응시키고 무늬가 영역 밖으로 새지 않게 한다.
- 지원되는 native pattern을 우선한다. SVG 보완이 필요하면 가져오기의 무늬 보존을 확인하고, 반복 무늬 전체의 공통 마스크 또는 영역과 교차 계산한 선분을 쓴다. 복잡한 해안 마스크를 점·빗금 하나마다 복제하지 않는다. 채움/marks 위의 필요한 해안·국경·작은 섬 윤곽을 보존한다.
- 보완 채움의 육지 마스크는 국가별 틈이 없는 동일 좌표계의 합친 면으로 확인한다. 내보낸 SVG를 보완할 때 숨은 국경·기존 흰 획을 마스크에 복사하거나 해안선을 중복해 덧칠하지 않는다. 다시 가져온 결과의 실제 선폭과 면 내부 흰 이음새를 JPEG에서 확인한다.
- 주제 해칭·점무늬의 선과 점은 검정이 기본이다. 회색 무늬는 의뢰나 다른 무늬와의 위계 때문에 필요할 때만 쓴다. 주제 해칭은 배경 해안·국경보다 약해 사라지지 않게 한다. 보통 0.3–0.4pt와 약 0.8–1mm 간격부터 보고, 최종 면 크기·정보 밀도에 맞춰 조절한다.
- 가장자리가 흐려지는 영역은 단색 점무늬로 대체하지 않는다. 필요한 경우 native radial/linear gradient 채움과 점무늬를 함께 사용한다. live gradient 명령이 정규화 `radius`를 지원하면 실제 면의 종횡비·끝색 위치를 보고 조절하며, 기본 반지름을 넓히기만 해서 흐림이 경계에서 갑자기 끊기지 않게 한다. 회색 바다 위에서 흰 사각형이 남지 않도록 투명 끝색을 검토한다. 흐림은 표현 방식이며 출처 없는 밀도 수치를 뜻하지 않는다.
- 반복 무늬가 있으면 준비 요청에 `contains:["pattern"]`을 포함해 사용자 견본 저장·재사용 지침을 함께 읽는다. 같은 견본의 native 설정을 다른 영역에도 적용하되 닫힌 면의 형태·gradient 범위·marks clip을 다시 확인한다. 관리 지도 자식을 직접 대체해 재투영 관계를 끊지 않는다.
- 범례는 지도와 **같은 점 간격·해칭 각도/굵기·채움·그라데이션**의 독립 샘플+문자다. 원래 단색 칸을 남겨두거나 임의 축소로 무늬 밀도를 바꾸지 않는다.
- 해안을 따라 안쪽으로 일정 폭인 띠(예: 서해안 띠)는 다각형을 손으로 그리지 않고 지도 `overlays:[{kind:"coastBand",from:[경도,위도],to:[경도,위도],widthMm,fill 또는 appearance}]`를 쓴다. 띠 폭은 최종 출력 기준 약 2–3mm에서 시작한다.
