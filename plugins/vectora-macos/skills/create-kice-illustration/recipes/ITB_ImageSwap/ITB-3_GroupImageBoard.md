# ITB-3_GroupImageBoard — 여러 명 + 그림 보드

그림 교체형. 여러 사람 + 지도·그래프·그림 보드·자료

여러 해설자와 교체 가능한 그림 자료를 대응시킨다. 발언 순서와 자료 지시 대상을 유지하고 인물/말풍선이 문제 풀이에 필요한 정보를 가리지 않게 한다. 주자료의 모든 배경을 보호 영역으로 취급하지 않는다.

보드 속 지도·그래프·표는 실제 정보 외곽으로 배치하고 독립 편집 관계를 유지한다. 명시된 교실 앞뒤·집단 토론 장면은 그 공간 관계를 보존한다. 발언과 인물은 비내용 배경을 덮을 수 있지만 점·축 제목·범례·주석을 가리지 않는다. 아래쪽에 여러 발언을 놓을 때 주자료의 최하단과 학생 머리/말풍선의 실제 최상단을 기준으로 간격을 잡아 빈 가로 띠를 남기지 않는다.

화면을 보는 청중의 뒷모습은 머리·목·어깨로 식별 가능한 작은 흉상부터 배정한다. 줄 폭을 인물 몸통으로 꽉 채우거나 불필요한 허리까지 보여 주어 자료보다 사람 행이 커지게 하지 않는다. 이름은 각 인물의 가쪽 빈 배경에 붙이는 기본을 유지하고 검은 머리·의복 위에 겹쳐 놓지 않는다. 여러 인물의 개별 위치·크기 편집이 필요한 구성은 각각의 자산으로 배치한다. 서로 겹치지 않는 집단 원화라면 원본 바이트를 보존한 이미지 인스턴스별 네이티브 클리핑으로 사람을 분리할 수 있다. 한 장을 통째로 배치하면 사람별 독립 편집이 제한되며, 분리 클립도 발언 길이에 따른 자동 재배치까지 보장하지 않는다.

교사·해설자의 **역할을 강조하는 원형 초상**은 학생보다 실제 보이는 인물을 크게 배치한다. 학생 흉상 높이의 약 1.35–1.5배를 출발점으로 프레임을 채우는 클리핑을 적용한다. 단순히 원형을 지정했거나 역할이 동등하면 이 크기 위계를 강제하지 않는다.

큰 교사 초상 때문에 짧은 질문 아래에 넓은 빈 가로 띠를 만들지 않는다. 위치·폭 배분을 조정하거나 **문제 풀이에 필요 없는 영역에 초상을 일부 겹쳐** 질문과 다음 발언군의 실제 외곽 간격을 줄일 수 있다. 지도 지점·기호·해석에 필요한 지형/경계·위경선·범례·본문은 보호한다. 겹침 허용 여부는 지도의 색이나 테두리 유무가 아니라 의뢰 내용과 풀이에 필요한 정보로 판단한다. 초상을 키운 만큼 행 전체를 늘리거나 질문 높이를 빈 패딩으로 키우지 않는다.
