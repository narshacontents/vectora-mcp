# D2-02_StackedBar — 누적 막대·띠

막대 내부 분할. 절대량 누적·100% 띠

절대량 합계 비교와 100% 구성비를 구별한다. 실제 누적값으로 경계를 계산하고 순서·범례를 유지한다. 작은 구간을 최소 높이로 키우지 않는다. 양/음수 누적이 있으면 영점 양쪽 합산 의미를 확인한다.

`stacked-column|stacked-bar|percent-column|percent-bar`, type bar. percent 엔진은 항목별 제공 값의 합으로 100%를 계산하므로 분모를 확인한다. 결측 없는 비음수·양수 합계가 필요하고 값 축은 0–100이다. 이미 비율인 입력을 반올림 합계 오류 때문에 몰래 정규화하지 않는다. 절대량 입력의 합이 100일 필요는 없다. 결측 누적은 표시된 부분만의 합이며 warnings를 완전 합계처럼 해석하지 않는다.
