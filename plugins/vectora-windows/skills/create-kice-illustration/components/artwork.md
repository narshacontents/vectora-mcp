## 새 원화와 참조 검색 — 원본 photo에는 적용하지 않음

매체의 검색·조작 아이콘이나 단순 정면 기기의 평면 도식처럼 기본 도형만으로 의미가 완결되는 작은 보조 기호는 편집 가능한 벡터로 만들 수 있다. 인물·자연물·장면·유물의 특징이나 질감을 읽는 삽화, 특정 실물의 외형 재현을 이런 기호로 대신하지 않는다. 아래 원화 절차는 실제 새 작화가 필요한 대상에 적용한다.

- 새 인물·사물·장면은 **현재 세션에 실제 연결된 이미지 생성/편집 도구**(Codex의 imagegen 또는 Claude에 연결된 외부 이미지 생성 MCP 등)로 만들고 기본은 이미지 그대로 배치한다. 도구 이름·입력 스키마·참조 이미지/투명 배경 지원은 실제 도구에서 확인하며 imagegen이라는 이름의 도구가 모든 클라이언트에 있다고 가정하지 않는다. 회화 질감·자연물을 아이콘/기하 부품으로 대체하거나 추적 때문에 원화를 단순화하지 않는다. Photo의 제공/확인 원본 비트맵은 새 작화 화풍·no-statues 검사에서 제외한다.
- 새 원화의 raster 생성 프롬프트는 현재 선택된 고정 화풍 계약을 맨 앞에 전문 그대로 한 번만 둔다. 자유 장면에 사람이 있어도 장면의 자유 원화 계약 하나를 쓰고, 인물 지침의 정체성·해부·승인 원칙은 적용하되 별도 인물 고정 계약을 덧붙이지 않는다. 그 뒤에 요청된 대상·행동과 명시된 정확한 수량, 요청된 정체성·복식 특징을 간결하게 적고, 꼭 필요한 시점·배치 기하와 별도 편집 요소의 공간 예약, 분리 배치할 때 실제 외곽 바깥의 투명 배경 조건만 덧붙인다. 편집 가능한 레이아웃 프레임은 별도 벡터 요소를 위한 예약을 뜻하며, 칠판 자체 프레임 같은 요청된 장면 소품은 보존한다. 요청되지 않은 화풍·패션 수식어와 부수 장면 연출은 계약과 경쟁시키지 않도록 보태지 않되, 요청된 정체성·복식·소품과 원자료의 의미는 유지한다. 이 순서는 새 작화 생성에만 적용하며 원본 사진 재현·편집은 제공된 원본과 해당 예외를 따른다.
- 새로 생성할 장면 원화에 편집 가능한 보드 안의 표·그래프·문자를 둘 때만, 이미지 생성 전에 원문·값 그대로 지원되는 네이티브 plan/build로 자식 전체의 선택한 문자 스타일 paint 경계(제목·단위·축·눈금·라벨 포함)를 재고 필요한 보드 내부 폭·높이와 여백을 정한다. 전체 조판 폭을 raster 폭으로 간주하지 말고, 말풍선·이름/headcap을 반영해 원화에 실제 배정될 물리 크기에서 안전영역 비율을 환산해 생성 프롬프트에 예약한다. 읽을 자료와 말풍선·이름 안전영역은 분리하되 의미 없는 배경은 겹칠 수 있게 하며, 요청된 데이터·문구·구도와 선택 화풍을 유지한다.
- 새로 생성한 원화의 보드·화면 안에 편집 가능한 그래프·표·문자를 놓으면 프레임·손을 제외한 실제 빈 영역을 확인하고, 자연스러운 안쪽 여백을 둔 안전 영역을 원본 픽셀 좌표로 기록해 실제 장면 변환으로 매핑한다. 요청한 그래프 plot 폭만으로 판단하지 말고 제목·단위·라벨까지 포함한 자식 전체의 실제 렌더 경계를 측정하며, 폭·문자·데이터 변경 뒤에도 선택한 문자 스타일의 실제 pt를 유지해 다시 확인한다. 자식을 보드 밖으로 키우거나 글자 크기를 줄여 맞추지 않고, 제공 문구·데이터를 바꾸거나 라벨을 임의 축약하거나 사람을 덮지 않는다. 공간이 부족하면 허용된 레이아웃 또는 원화의 공간 예약을 조정한다. 네이티브 영역 바인딩이 지원되면 사용하고, 미지원이면 수동 배치 의존성을 기록한다. 생성 프롬프트의 예약 기하는 확인을 대신하지 않으며, 실제 원본 픽셀 영역을 다시 검사한다.
- 벡터 배경 위에 겹치는 분리 원화는 인물·소품의 실제 윤곽 밖이 투명한지 확인한다. 원화의 흰 사각 배경이 칠판·선을 지우는 것은 인물 자체가 배경을 자연스럽게 가리는 것과 다르다. 불투명 원화는 그 사각 배경 전체가 의도된 장면 영역일 때만 그대로 사용하며, 그 밖에는 이미지 편집 도구로 외부 배경을 제거한다.
- 생성 도구가 없으면 사용자가 제공했거나 재사용을 명시한 원화를 실제로 먼저 검토한다. 새 원화가 여전히 필요하면 위 프롬프트 순서에 따라 대상·포즈·시점·식별 특징·배경 조건을 담은 생성 프롬프트와 **비최종 벡터 조판**을 준비하고 필요한 원화를 요청한다. 프롬프트는 응답 본문에 제공하며 별도 납품 파일을 추가하지 않는다. 받은 원화는 직접 열어 검수하고 포함 이미지로 배치하며 문자·말풍선·도형은 독립 편집 요소로 유지한다. 도구 부재를 손그린 코드 도형·임시 얼굴·과거 예시로 대체하지 않고 원본 Photo도 생성 대체하지 않는다. 원화/검수가 미충족인 조판은 완료로 보고하지 않는다. 이 규칙은 Codex·Claude·Gemini CLI 모두에 적용한다.
- 이름이 지정된 실제 인물·구체적 유물/사물은 생성 전에 인터넷 참조 이미지를 검색하고 실제 이미지 및 원문 명칭·설명을 확인한다. 박물관/소장 기관/공공 아카이브 우선; 얼굴·복식/주요 부위·비례·문양 특징을 추출하고 변형들을 섞지 않는다. 일반 사상가/학생/꽃병에 특정 이름을 붙이지 않는다.
- 확인 이미지를 참조 입력으로 전달하거나 지원되지 않으면 확인 특징을 문장으로 전달한다. 외형은 식별 가능하게, 화풍은 선택된 인물/자유 원화 계약으로 새로 그린다. 사람의 조각상 참조는 얼굴·복식 근거일 뿐 재질/받침대는 재현하지 않는다. **유물 자체가 조각품인 요청**에는 그 대상의 형태·재질을 보존한다. 참조 URL·대상·반영 특징은 작업 기록에, 그림 안에는 임의 출처를 넣지 않는다. 검색/열람 실패는 확인 완료로 보고하지 않는다.
- 편집할 **로컬 이미지 경로는 먼저 실제로 열어 보고** 선택한 도구가 지원하는 참조 입력으로 전달한다. Codex imagegen에서는 로컬 참조 경로를 사용하고, 로컬 경로 없는 대화 이미지는 필요한 최소 최근 이미지 수를 사용하며 두 방식은 혼용하지 않는다. 외부 도구에 imagegen 전용 인자를 추측해 보내지 않는다. 필요한 이미지 누락 시 다시 첨부를 요청한다. 배경 제거/내용 수정은 이미지 편집 도구를 사용하고 코드 픽셀 편집으로 대체하지 않는다. 참조 이미지가 전혀 없는 신규 생성에만 편집 참조 인자를 붙이지 않는다. 지명 인물·유물의 확인된 이미지 참조 입력은 위 참조 검색 절차대로 허용한다.
