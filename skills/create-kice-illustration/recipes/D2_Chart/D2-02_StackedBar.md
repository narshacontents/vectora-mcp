# D2-02_StackedBar — 누적 막대·띠

막대 내부 분할. 절대량 누적·100% 띠

절대량 합계 비교와 100% 구성비를 구별한다. 구간 이름으로 구별되는 누적 막대는 흰 구간+검은 테두리가 기본이며, 회색·무늬는 범례로 계열을 구별해야 할 때만 쓴다. 축 눈금으로 읽는 막대에 구간 수치를 따로 적지 않는다(의뢰가 값 표시를 요구할 때만). 막대 두께는 안쪽 이름 한 줄이 위아래 여백과 함께 들어가는 정도(8pt 기준 약 5–6mm)에서 시작하고, 긴 이름 때문에 막대를 두껍게 만들지 말고 이름을 지시선으로 막대 밖에 둔다. 가로 막대의 값 눈금축은 막대 아래에 둔다(위쪽 축은 의뢰가 요구할 때만). 바깥 이름은 대상 구간 위·아래 중 빈 쪽에 두되 마지막 막대 아래 이름이 축과 부딪히면 위로 올린다. 가로 막대 사이 간격은 막대 두께의 약 0.7–1배로 시작하고, 사이에 바깥 이름이 들어가는 줄만 그 글 높이만큼 넓힌다. 각주 아래 기준 연도 `(2022)` 같은 출처 표기는 마지막 각주 줄의 오른쪽 끝에 같은 줄로 둔다. 실제 누적값으로 경계를 계산하고 순서·범례를 유지한다. 작은 구간을 최소 높이로 키우지 않는다. 구간 위의 이름은 해당 구간 중심에 맞추되, 이웃 이름과 충돌하지 않으면 구간보다 넓어도 된다. 작은 구성비에 맞추려고 이름을 글자마다 줄 바꾸지 않으며 바깥 이름의 돌출까지 전체 폭에 포함한다. 시점 간 구간 경계를 비교하는 요청에서만 내부 누적 경계를 가는 점선으로 연결한다. 양/음수 누적이 있으면 영점 양쪽 합산 의미를 확인한다.

한 연도 안에서 단일 막대와 여러 계열을 쌓은 막대를 나란히 비교할 때는 **범주와 누적 묶음**을 구별한다. 원자료의 연도를 중복하거나 관측하지 않은 0을 넣어 외형만 만들지 않는다. 실제 생성기가 계열별 누적 묶음을 지원하면 같은 범주 안에서 그 묶음으로 배치하고, 양·음수 합계와 축 범위도 묶음별로 계산한다. 미지원이면 원자료를 보존한 보충 제작의 한계를 밝힌다. 서로 다른 단위를 한 축 눈금으로 읽도록 의뢰된 경우 각 계열의 단위 대응을 범례·단위 표기로 분명히 한다.

`stacked-column|stacked-bar|percent-column|percent-bar`, type bar. percent 엔진은 항목별 제공 값의 합으로 100%를 계산하므로 분모를 확인한다. 결측 없는 비음수·양수 합계가 필요하고 값 축은 0–100이다. 이미 비율인 입력을 반올림 합계 오류 때문에 몰래 정규화하지 않는다. 절대량 입력의 합이 100일 필요는 없다. 결측 누적은 표시된 부분만의 합이며 warnings를 완전 합계처럼 해석하지 않는다.
