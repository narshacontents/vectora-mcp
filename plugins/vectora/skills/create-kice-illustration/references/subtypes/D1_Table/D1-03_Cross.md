# D1-03_Cross — 교차표

행·열 모두 범주, 셀=교차값(동질). 전치해도 성립. 대각선 모서리 헤더 허용

행·열 모두 범주이고 셀은 두 범주의 동질 교차값이다. 전치해도 관계가 성립하는지 확인한다. 대각선 모서리 헤더를 쓰면 각 제목이 자기 삼각 영역 안에 온전히 들어가게 하고 행/열 제목 대응을 명확히 한다. 대각선 하나만으로 nested에 배정하지 않는다.

지원 연결본에서는 부모 유형의 현재 제작 계약을 사용한다. 교차값의 행·열 기준을 ID로 각각 보존한다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
