## 실제 사진·스캔·기존 작품을 사용하는 경우

I1_Photo·I3-13_OldMap·ITC-2_RealPhoto 및 매체에 삽입한 실제 원본에만 적용한다. 신규 작화 화풍을 원본 사진에 강제하지 않는다.

## 원본 선택과 출처

- 요청에 제공된 사진이 있으면 그 사진을 우선한다. 별도 지정이 없으면 적합한 실제 원본 이미지를 인터넷에서 찾는 것이 기본이다. AI 합성 이미지를 실제 사진/스캔의 대체물로 생성하지 않는다.
- 대상·사건·판본·해상도·이용 조건이 적합한 후보 중에서는 흑백 사진을 우선하되 컬러 사진도 사용할 수 있다. 흑백 여부보다 요청 대상의 정확성과 식별에 필요한 세부를 우선하며, 적합한 컬러 원본을 확보했다면 흑백본이 없다는 이유만으로 작업을 중단하지 않는다. 사용자 제공 컬러 사진도 그대로 사용할 수 있다.
- 박물관·소장 기관·공공 아카이브·공식 제작자 등 원본과 대상을 검증할 수 있는 출처를 우선한다. 검색 썸네일만으로 확정하지 말고 원문 페이지와 실제 이미지를 열어 대상명·작가/기관·촬영/제작 시점·소장품 식별정보 중 관련 항목을 확인한다. 사진/작품이 나타내는 사건·내용·날짜가 요청과 캡션에 실제로 맞는지 확인한다. 비슷한 다른 사건·제목·작품으로 대체하거나 서로 다른 판본/유물을 섞지 않는다.
- 사용 가능한 원본 해상도와 라이선스·이용/재배포 조건·필요한 크레딧을 확인해 출처 URL, 원본/이미지 URL, 대상명과 조건을 제작 기록에 남긴다. 필수 크레딧은 조건에 따라 제공하며 자료에 없는 권리를 추정하지 않는다. 이용 조건 또는 대상 식별이 불확실하면 그 상태를 밝히고 다른 적합한 원본을 찾는다. 검색/이미지 열람 실패를 출처 확인 완료로 보고하지 않는다.

### 재현과 배치

- 인터넷에서 확인한 실제 원본을 이미지 개체로 유지한다. 컬러 원본은 편집 가능한 .vectora에도 원래 색으로 포함하며, 기본 회색조 변환은 공통 납품 지침에 따라 최종 JPEG/PNG 내보내기에서만 적용한다. 본문이 색을 언급하거나 원본이 컬러라는 이유로 컬러 납품을 임의 선택하지 않는다. 생성 모델로 흑백화하면서 질감·세부 획·기존 문자를 다시 그린 결과는 원본 복제로 인정하지 않는다.
- 배치의 비례 크기 조절·최종 회색조 내보내기와 원본 픽셀 편집을 구별한다. 별도 요청한 자르기·방향 정리·대비 변경은 사용자 원본 보존 조건과 상위 이미지 편집 도구 지침 안에서만 수행한다. 원본을 보존하고 편집 범위를 기록하며 대상 구조·질감·문자·의미 있는 계조를 원본과 대조한다. 코드 픽셀 편집으로 도구 지침을 우회하지 않는다. 원본에 없는 요소·임의 복원·과도한 보정·추적을 더하지 않는다.
- 회색조 출력 뒤에도 식별 특징·의미 있는 계조가 구별되는지 확인한다. 색이 핵심 정보여서 필요한 구별이 사라지면 같은 대상의 더 적합한 원본을 검토하고, 그래도 충족할 수 없는 조건만 밝힌다. 컬러 원본이라는 이유만으로 별도 흑백화 승인을 요청하지 않는다. 요청된 회색조 내보내기가 실제 적용되지 않았다면 흑백 완성본으로 보고하지 않는다.
- 종횡비와 필요한 대상 범위를 보존한다. 원본의 일부를 확대하면 같은 원본 부위를 사용하고 해상도도 확인한다. 스캔의 원문/도안은 실자료로 보존하며 별도 요청한 설명·표시·인출선은 독립 개체로 둔다. 사진 안 기존 문자를 새 편집 문자로 가장하지 않는다.
- 흰 외곽이나 사진 배경은 원본의 일부인지 먼저 판단한다. 불필요한 외곽 정리로 중요한 물체·작품 가장자리·식별 표시를 잘라내지 않는다. 역사적 작품의 손상·표면·명암을 임의 복원하지 않는다.
- 사진 크기는 원본 사각형보다 **실제로 보이는 대상과 식별할 세부**를 기준으로 정한다. 본문과 캡션의 높이를 맞추려고 사진을 작은 아이콘처럼 축소하지 않는다. 자동 배치의 가시성 하한은 세부 식별을 보장하지 않으므로, 계획 결과의 실제 사진 크기를 확인하고 필요한 비례 크기를 첫 조판에 지정한다. 출처·부연 설명이 사진보다 더 두드러지지 않게 한다.

- 대화·발표·인물 비교에 쓰는 초상은 배치한 자리에서 상대나 본문 안쪽을 바라보는지 확인한다. 바깥쪽을 향하면 Vectora의 이미지 개체 좌우 뒤집기를 사용하고, 원형 클리핑·가시 크기·중심은 유지한다. 원본 이미지 파일은 보존하고 이름·말풍선·본문은 뒤집지 않는다. 사진 속 문자·유물 방향·역사적 장면의 의미를 바꾸는 반전은 피하고 사진 선택 또는 배치로 해결한다.

### 검사

원본과 실제 표시 결과를 대조해 대상·사건/내용·날짜·판본·방향·범위·질감·문자·명암을 확인한다. 새 합성 요소가 없고 허용된 가벼운 편집만 적용됐는지, 흑백/대비 변환 뒤에도 식별 특징·의미 있는 계조가 유지되는지, 출처/라이선스 기록과 필요한 크레딧이 있는지 확인한다. 해상도나 출처 검증이 부족하면 그 제한을 명시한다.
