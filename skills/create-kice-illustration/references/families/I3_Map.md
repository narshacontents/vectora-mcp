# I3_Map — 제작 공통

## 모든 지도의 공통 원칙

지리 기준 위의 위치·범위·방향·경계·자료 시점을 유지한다. 원자료의 투영·범위·시점과 실제 지원을 구별하고, 근거 없는 지물·수치·경계를 만들지 않는다. 문자/범례는 지리 도형과 독립 편집하며 내용 좌표를 움직여 겹침을 해결하지 않는다. 최종 크기와 확대에서 위치·주제 의미·인출선 끝·섬·잘림·선명도를 확인한다.

기존 지도 사진/스캔은 `I3-13_OldMap`을 우선한다. 새 바탕이 필요한 지도만 실제 프리셋에서 시작한다. 같은 회색 면도 후보 위치이면 Locator, 범주 영역이면 Area, 값 구간이면 Choropleth다. 기온/강수 등치선은 Isoline, 고도 등고선은 Topographic이다. 범례가 정량/정성/위치 중 무엇을 뜻하는지 먼저 확인한다.

## 새 지도에서 선택할 기본형

**2028 예시문항의 지도 형식·판독 원칙이 제1 기준**이다. 다른 평가원 기출은 예시문항에 없는 주제와 부족한 조건만 보강하며, 충돌하면 예시문항 기준을 적용한다. 과거 사례의 빈도만으로 이 우선순위를 뒤집지 않는다. 아래는 미지정 시 판단 기준이며, 명시된 재현 요청이나 기존 문서 편집에서는 지정된 경계·바다색을 보존한다. 제작 때 사례 이미지를 다시 열거나 배치를 복사할 필요는 없다.

| 지도가 전달할 정보 | 기본 경계 선택 | 바다색 판단 |
| --- | --- | --- |
| 자연환경·기후 지점·국경과 무관한 분포/권역 | 해안 실선 중심. 불필요한 국경은 생략하고 권역 판독에 필요한 경계만 남긴다. | 회색 분포·해양 주제가 있으면 흰 바다 우선. 흰 육지의 위치만 읽는 지역 지도는 연회색 바다도 가능. |
| 국가 식별·국가별 수치/비교 | 해안 실선 + 필요한 국경 점선. 단순 국가 강조 때문에 모든 경계를 실선으로 바꾸지 않는다. | 국가 음영·등급과 구별하기 쉬운 흰 바다 우선. 연회색 바다를 쓰면 가장 옅은 자료 등급과도 구별한다. |
| 섬·해협·항구·연안 경로/지역 확대 | 해안 형태와 주요 섬을 우선하고, 국가·행정 경계는 설명에 필요할 때만 추가한다. | 흰 육지를 분명히 보여주는 연회색 바다를 검토한다. 확대라는 이유만으로 회색을 강제하지 않는다. |

연회색 바다는 `#E7E7E7` 부근을 출발값으로 삼되 출력 대비에 맞춰 약 `#D9D9D9`–`#EEEEEE`에서 조절한다. 회색 주제 면과 회색 바다의 공존 자체는 금지가 아니다. 범례의 자료색·흰 육지·수역이 명확히 구별되는지가 기준이다. 해양 분포를 나타내는 채색은 배경 바다색이 아니라 주제 자료다.

행정구역 통계는 실제 집계 경계를, 등치선·지형도는 연속 선과 지형을, 유선·이동 지도는 방향과 굵기를 우선한다. 이를 모두 국경 점선으로 통일하지 않는다. 행정 경계는 해안·국경보다 가늘게 구분할 수 있고, 주제선과 혼동되는 불필요한 바탕선은 생략한다. 경위선·방위표·축척은 위치/거리/방향 판독에 필요하거나 요청된 경우에만 추가한다.

## 해안선의 상세도

전체 세계지도와 지역 확대 지도는 **최종 표시 범위·물리 크기**에 맞는 바탕을 각각 고른다. 비슷한 이름의 등록 바탕이 여러 개면 도법·중심경도·등록 원지리·역할 제어와 실제 범위를 대조한다. 이름에 ‘해안선’이 있다는 이유만으로 첫 후보를 선택하지 않는다. 같은 50m 등급도 등록 방식과 초기 범위가 다를 수 있으며, 국경을 숨길 수 있는 바탕도 해안선 지도의 후보가 된다. 저상세 세계지도를 잘라 크게 늘리면 긴 직선·뾰족한 꺾임이 드러날 수 있으므로, 그때는 등록된 더 상세한 지역/국가 프리셋을 먼저 검토한다. Natural Earth의 110m/50m/10m 표시는 축척 등급(각 1:1억1천만/5천만/1천만)이지 미터 단위 위치 정확도가 아니다. 더 세밀하다고 항상 좋은 것도 아니며 작은 출력에서 해안이 검게 뭉치지 않아야 한다.

세계지도의 중심 경도는 표시할 지점과 주요 대륙의 연속성을 함께 보고 고른다. 태평양 중심이라는 이름만 맞추고 양 끝에서 주요 육지가 잘리거나 같은 지역이 조각나 반복되는 구도를 그대로 쓰지 않는다. 필요한 범위를 보존하는 등록 도법·중심·crop을 선택하며, 원자료나 명시 중심 경도는 유지한다.

선이 거칠거나 군도가 뭉쳐 보이면 **상세도와 최종 물리 선폭을 따로 비교**한다. 먼저 같은 범위·바탕에서 선폭을 낮춰 보고, 긴 직선이나 꺾임이 남으면 더 상세한 바탕으로 바꾼다. 작은 지도에도 큰 지도와 같은 선폭을 명시하여 크기별 자동 기본값을 고정하지 않는다. 반대로 얇은 선으로 잘못된 지형을 감추지 않는다. 사용자 지정 선폭·기존 문서의 보존 스타일은 유지하며, 지도 창 크기를 바꾼 뒤에는 실제 내보낸 이미지에서 해협·섬·주제 면의 판독성을 다시 확인한다.

지리 좌표를 임의 곡선으로 둥글리거나 섬·해협을 지워 매끈하게 만들지 않는다. 선의 접합 모양과 바탕 지리의 상세도를 구별하고, 도법·범위·상세도·선폭을 함께 확인한다. 비슷해 보이는 공개 지도도 출처가 확인되지 않으면 ‘평가원이 사용한 동일 원본’으로 부르지 않는다.
