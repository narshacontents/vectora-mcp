# 표시 텍스트 조판

원문의 뜻·기호는 보존하면서 **측정 전에** 아래 조판 공백을 적용한다. 원문 제공/따옴표만으로 공백까지 고정한 요청은 아니다. 문자 코드·공백 그대로 보존을 명시한 요청과 URL·코드 구문에는 적용하지 않는다. 공백 삽입 후 부분 서식·밑줄·박스 범위를 최종 문자열의 grapheme 기준으로 계산한다.

일반 공백은 U+0020, 반칸은 Vectora **Alt+Space의 U+2002**, 고정 한칸은 Ctrl+Alt+Space다. 실제 앱 측정 폭을 사용하며 일반/전각/중복 공백으로 흉내 내지 않는다. 반칸은 일반 공백 폭의 절반으로 고정되고 인접 자간에서 제외된다.

| 조건 | 조판 |
|---|---|
| 알파벳이 대상을 지칭하는 이름표 + 종류 명사 | `A 지역`, `B 펀드`, `A 주식`처럼 반칸 1개. `A에서는`·영어/고유명 내부·수식 변수는 제외 |
| 설명·라벨의 콜론 | `주제 : 비교 우위` — 앞 반칸, 뒤 일반 한 칸 |
| 시간·비율의 콜론 | `12 : 30`, `1 : 2` — 양쪽 반칸 |
| 이항 연산자 × + = − (원문 - 코드 유지) | `A + B = C`, `10 − 3`처럼 양쪽 반칸. 단항 부호 `−5`·`+3`, 날짜/범위/식별자 하이픈은 제외 |
| ○ △ □ ☆의 묶음 뒤 설명·이름 | `○○ 신문`처럼 반복 기호 사이는 붙이고 묶음 뒤에만 반칸. 차트/도식 표식·수식의 문자 그대로 표기는 제외 |

기존 주변 공백을 중복하지 않는다. 중첩 자료의 제목·단위·범례와 제작자가 추가한 문구도 대상이다. 기간 `t+1기`·`t+2기`의 `+1`·`+2`는 **위첨자가 아니라 같은 기준선의 일반 문자**이며 이항 연산자 간격을 적용한다. 실제 거듭제곱·명시 위첨자는 보존한다. 다른 연산자·복합 기호를 쪼개거나 비슷한 문자로 바꾸지 않는다.

원문자와 밑줄이 있으면 `core/underline.md`, 목록표는 `core/prose.md`, 각주의 별표·접두부 간격은 `core/footnotes.md`를 읽는다. 위의 일반 반복 공백 금지는 각주에 정한 접두부 공백을 없애라는 뜻이 아니다. 검사 도구의 경고는 판단 보조이며 미검사 필드까지 정상임을 보증하지 않는다.
