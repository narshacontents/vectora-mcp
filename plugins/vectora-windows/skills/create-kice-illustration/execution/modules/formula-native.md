# 편집 가능한 산출식·분수

분자와 분모를 가로 분수선으로 나누거나, 그 옆에 좌변·연산자·배수를 놓는 경우에만 읽는다. 일반 문장의 슬래시 표기를 임의로 분수로 바꾸지 않는다. 수식을 계산하거나 미지수를 채우지 않고 요청한 문자열·관계를 보존한다.

현재 앱의 `vectora://production/schematic/schema`와 `vectora://production/schematic`에서 `layout:"formula"` 지원을 확인한다. 지원하면 글상자·분수선을 따로 붙이는 대신 `kind:"schematic",layout:"formula",widthMm,formula:{version:1,items}`를 사용한다. `items`는 표시 순서대로 고유한 안정 ID를 가진 다음 둘 중 하나다.

- 일반 문자열: `{id,kind:"text",text,richText?}`
- 분수: `{id,kind:"fraction",numerator:{text,richText?},denominator:{text,richText?}}`

좌변·등호, 분수, 바깥 배수의 역할을 구별한다. 예를 들어 배수가 분모 일부가 아니면 별도의 text item으로 둔다. 연산자 양옆 반칸은 실제 U+2002를 해당 문자열에 넣고, 화면상 띄워 보이게 할 좌표나 반복 공백으로 대신하지 않는다. 문자열과 `richText.text`를 함께 보내면 서로 일치해야 한다. 공통 문자 스타일은 `formula.textProfile`·필요한 `fontPt`로, 부분 서식은 해당 part의 `richText`로 지정한다. 지원되는 서식만 보내고 LaTeX 명령이나 임의 수식 평가를 요구하지 않는다.

분수선은 더 긴 분자/분모의 **실제 글 획**을 기준으로 약0.5mm씩 양옆에 여유를 두고, 글과 선의 틈은 약0.55mm, 검정 선은0.4pt에서 시작한다. 분자·분모는 분수선 중앙, 식 바깥 문자는 분수선의 높이에 실제 획 중심이 맞아야 한다. 일반 프레임 행간이나 큰 빈 글상자로 높이를 부풀리지 않는다. 앱이 제공하는 이 기본 배치를 먼저 사용하고 결과의 정렬·여백을 확인한다.

표의 머리글·셀 안에서는 `cells[].content`에, 종이/학습지 안에서는 `blocks`의 `{id,type:"component",spec}` 항목에 이 컴포넌트를 넣는다. 포함된 식의 실제 높이가 셀·외피 조판에 반영되게 하며, 표 밖에서 만든 분수 세 개체를 셀 위에 떠 있게 얹지 않는다. 본문·표·식이 여러 블록이면 해당 소유 구조를 유지한다. 기능이 없는 앱의 수동 보충은 자동 연동이 확인된 것처럼 보고하지 않는다.

목록 안의 산출식은 함께 준비된 산문 지침의 항목 위계를 따른다. 같은 단계의 일반 문장과 분수식의 표지 시작선을 맞추고, 상위 항목보다 적절히 들여쓴다. 내부 식의 분자·분모 중앙 정렬과 항목 전체의 배치 정렬은 별개다. 상위 text-frame의 공개 block 스키마가 지원하면 `{id,type:"component",align:"left",indentMm:<단계에 맞는 들여쓰기>,spec}`로 관계를 지정한다. `indentMm`을 뺀 가용 폭으로 자식을 측정하고, 사용자가 폭을 고정하지 않았다면 내부 `widthMm`은 생략해 슬롯 폭을 물려준다. 일반 문장 항목은 네이티브 문단의 첫 줄/본문 열로 같은 단계에 맞춘다. 단순 가운데 배치 기본값을 그대로 적용하거나 공백/개별 좌표로 관계를 흉내 내지 않는다.

표지를 포함한 좌변 text item에도 **고정 본문 열**을 전달한다. 일반 문장에만 접두부 정렬을 적용하고 식에는 `• `처럼 공백 한 칸만 넣으면 같은 단계의 본문 시작선이 달라진다. 해당 item의 `richText.paragraphLayouts`에 `{paragraphStart:0,prefix:{end:<표지와 뒤 공백의 끝>,bodyStartMm:<식 안에서의 본문 열>}}`을 지정한다. 바깥 block의 `indentMm`은 항목 단계, 안쪽 `bodyStartMm`은 표지 뒤 간격이므로 중복 합산하지 않는다. 수치는 같은 단계의 일반 문장과 공유하고, 특정 예시의 들여쓰기 값을 모든 그림에 고정하지 않는다.

`widthMm`은 글꼴 축소 비율이 아니라 가용 폭이다. 좁아지면 분자·분모의 자연스러운 줄바꿈으로 재측정하고, 그 밖의 문자열은 한 줄을 유지한다. 용량 오류가 나면 상위 셀/블록 폭과 구성을 재계획한다. 글자 축소·분모 삭제·뜻이 다른 슬래시 표현으로 조용히 바꾸지 않는다. 원문 자체가 다른 식이 되는 강제 개행도 넣지 않는다.

수정은 같은 식의 원문/스타일 또는 폭을 갱신한다. 전체/상위 그룹의 비균등 확대, 분수선만 수동 이동, 고정 위치 override로 맞추지 않는다. 분자 길이를 바꾼 뒤 분수선·분모 중심·바깥 연산자와 부모 셀/다음 블록이 함께 재조판되는지 확인한다. 저장·재열기에서도 원문·ID·관계가 유지되어야 한다. 첫 제작의 시각 합격과 후속 편집의 연동 합격을 구별한다.
