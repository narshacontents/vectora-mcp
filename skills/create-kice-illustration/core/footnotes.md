# 자료 아래 각주가 있을 때

- 각주 순서대로 ASCII `*`, `**`, `***`를 쓰고 뒤에 Vectora Alt+Space 반칸 U+2002 하나를 둔다. 각주 N개 중 i번째(1부터)는 표지 앞에 반칸 **2 × (N−i)개**를 둔다. 1개면 0개, 2개면 2·0개, 3개면 4·2·0개다. 자동 줄바꿈이 아니라 각주 항목 수를 센다.
- 각주 글상자는 **왼쪽 정렬**한다. 오른쪽·가운데 정렬하면 접두 반칸이 시작 열을 맞추지 못한다. 각주 묶음을 자료 오른쪽에 붙여야 하면 글상자 위치를 옮긴다. 출처 행만 오른쪽 정렬할 수 있다.
- 한 편집 가능한 글상자의 항목별 문단으로 만들고, 긴 각주의 후속 행은 본문 시작 열에 맞춘다. 지정 공백 수는 유지한다. 각주가 모두 한 줄이면 반칸 개수만으로 시작 열이 맞으므로 `paragraphLayouts.prefix`를 쓰지 않는다. 후속 행이 있거나 별표 폭 때문에 어긋날 때만 쓰며, `bodyStartMm`은 가장 긴 접두부(`***`+반칸 등)의 실측 폭 이상으로 둔다. 어림값으로 더 좁게 두면 별표 뒤 반칸이 본문에 덮인다. 최종 JPEG에서 모든 별표 뒤 반칸 틈이 보이는지 확인한다. 이 접두부 공백은 반복 공백 정렬 금지의 예외다.
- 출처 행과 각주는 구분하고 요청되지 않은 각주 내용을 만들지 않는다. 실행은 `execution/paragraphs.md`의 고정 본문 열 계약을 따른다.
- 각주와 출처·연도 행은 같은 글자 크기를 쓴다. 각주만 줄였다면 출처도 같이 줄인다.
