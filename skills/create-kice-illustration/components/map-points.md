## 위치·점·라벨이 있을 때

- 같은 크기의 원/사각/삼각/기호는 위치·범주이며 수량 비례로 추정하지 않는다. 작은 장소의 타원/국지 영역 표시는 국가 전체 채움·자연 경계와 구별한다.
- 등록 좌표 또는 바탕에서 확인한 위치에 기호 **중심**을 맞춘다. 고정 anchor를 이동해 겹침을 해결하지 않는다. 부가 수치는 의미·단위를 명시한다.
- 라벨의 실제 잉크 상자와 점 외곽 사이 약 **0.7–1.5mm**를 시작 간격으로 쓴다(보편 강제값 아님).
- 첫 배치부터 위·아래·좌·우의 빈 면 후보를 실제 글 폭과 대조해 고른다. 모든 점에 같은 offset을 적용하거나 halo만 넣으면 지리선 충돌이 해결됐다고 가정하지 않는다. 해안·국경·경로가 글 획을 통과하면 라벨만 옮기고, 가까운 빈 면이 없을 때 짧은 인출선을 해당 점에 연결한다. 점의 지리 anchor는 고정하고, 흰 배경/halo로 중요한 해협·섬·경계를 크게 덮지 않는다.
- 한 지점의 이름·수치·작은 수치 상자는 **하나의 주석 묶음**으로 먼저 측정한다. 묶음 전체가 들어갈 가까운 빈 면을 고르고, 지시선은 점에서 묶음 바깥쪽까지 연결해 자기 상자나 다른 문자를 관통하지 않게 한다. 이름만 자동 배치한 뒤 수치 상자를 덧붙이거나, 충돌할 때 이름 하나만 멀리 옮기지 않는다. 필요한 지형 판독을 보존하며 별 의미 없는 빈 바다를 찾으려고 인출선을 과도하게 늘이지 않는다.
- 문자·인출선·기호를 분리하고 필요한 기호 범례만 둔다. 화살촉 없는 기본 관계/비교 연결에 이동 방향을 부여하지 않는다.
- 일반 add의 ellipse/polygon/path와 독립 text는 자동 위경도 변환이 아니다. 문서 anchor와 등록 좌표를 구별하고 바탕 배율 변경 후 기호 중심/크기·인출선의 대응을 확인한다.

문구·값을 바꾼 뒤에는 지리 앵커·자료 대응과 주석 묶음의 배치를 보존했는지 확인한다. 글 폭이 달라져 문자 가장자리의 인출선 종단이 조금 재계산되는 것은 정상 재조판이다. 지점 자체 이동·다른 대상 연결·자기 상자 관통과 구별한다.
