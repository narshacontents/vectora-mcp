# D1-06_Others — 기타 격자

선택지 띠, 퍼즐 격자, 카드 나열

선택지 띠·퍼즐 격자·카드 나열 등이다. 인접·행열 순서·칸 수가 뜻하는 관계를 먼저 정해 유지하고 표 헤더를 억지로 붙이지 않는다. 카드의 틈과 퍼즐의 공유 경계를 구별한다. 배치만으로 정답·연결 규칙을 추가하지 않는다.

지원 연결본에서는 task instructions에 선택된 표 family의 현재 제작 계약을 사용한다. 격자로 표현할 수 없는 부분은 편집 개체로 보충하고 지원하지 않는 spec 필드를 만들지 않는다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
