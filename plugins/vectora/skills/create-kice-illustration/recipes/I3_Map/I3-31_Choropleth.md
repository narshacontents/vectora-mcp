# I3-31_Choropleth — 단계 구분도

양적 주제도. 구역·격자별 음영 등급이 값의 구간

- 단계구분과 등급별 기호의 범례는 각 구간의 상·하한과 포함/제외 조건을 명시해 빈틈·중복을 막는다. 비율/밀도 단계구분은 순서 있는 농도를 쓴다. raw 값·구간·표시 반올림을 분리하고 결측을 최저 등급으로 칠하지 않는다. 상/하위 순위 채움은 서열 통계이며 미제공 지표명을 만들지 않는다.

라이브 map 스키마에 `thematic` 계약이 있으면 구역별 값을 독립 채움·문자로 나누기 전에 연결된 단계 구분도 제작을 우선한다. 검증한 feature ID와 anchor를 `records`에 대응시키고 `classes`의 하한 포함·상한 제외, `missing`, `unlistedFill`, 단위·범례를 명시한다. 값이나 등급을 바꿀 때 같은 컴포넌트에서 갱신하여 음영·값 표기·범례가 함께 바뀌는지 확인한다. 배열 갱신은 실제 병합/교체 계약에 맞춰 요청하지 않은 자료도 보존한다.

라벨을 표시하지 않아도 필수 anchor를 모든 구역의 같은 문서 좌표로 채우지 않는다. 구역 대표점은 등록 원지리의 해당 면 안에 두고 구멍·다른 구역·도서 구성을 확인하며, 재투영·크기 변경을 위해 가능한 한 geographic anchor로 보존한다. 실제 도시·시설 위치가 요구되면 면의 대표점으로 대체하지 않는다.

같은 지역의 두 지도를 비교하면 바탕·표시 범위·도서 포함 방식·가시 크기를 통일하고 제목의 높이를 맞춘다. 공통 범례는 등급 의미·농도·결측 정책이 같은 경우에만 공유하며, 각 지도에 중복 표시하지 않는다. 공통 범례를 독립 보충 개체로 만들었다면 자동 연동된 것으로 보고하지 말고 등급·색·문구 변경 때 두 지도와 함께 갱신한다. 한 지도의 순위만 바꾸는 요청은 다른 지도 및 미변경 지역을 보존하고, 상·하위 개수와 제외 지역을 원자료로 다시 확인한다.

`dataSource`는 제작 근거이며 표시 문구가 아니다. 별도 표시 요청이 있을 때만 `displayNote`를 사용한다. 자동 라벨 배치가 실패하거나 다른 강조 구역 위로 옮겨져 대상이 혼동되면 미완료다. 폭 변경 실패를 원래 폭 유지로 대체해 완료하지 않고, 지원되는 라벨/창 배치를 조정한 뒤 요청 폭과 데이터 관계를 함께 재검증한다. 이 계약을 다른 주제도의 자동 제작 지원으로 확대해 해석하지 않는다.
