# D1-05_Checklist — 응답체크표

셀이 ○×·✓·빈칸·점수. 조건 대응용

응답 조건에 대응하는 ○×·✓·빈칸·점수를 셀별로 보존한다. 체크 여부, 입력할 빈칸, 점수 0은 별개다. 선택 가능/불가능·단일/복수 응답이 제공되면 그 관계만 반영하고 정답이나 체크를 추측하지 않는다. 반복 기호의 크기와 중심을 정렬한다.

한 글자 응답 열은 머리글·기호 중 넓은 실측 폭에 읽기 편한 좌우 여백을 더해 같은 폭으로 정하고, 남은 폭을 질문 열에 준다. 응답 열을 임의의 큰 고정 폭이나 질문 열과 같은 비율로 나누지 않는다. 질문이 불필요하게 줄바꿈하는데 기호 양옆에 넓은 빈칸이 남으면 응답 열부터 줄인다. 가장 긴 질문까지 실제로 조판해 마지막 한 음절과 물음표만 다음 줄에 고립되지 않게 하고, 짧은 종결부만 다음 줄로 넘어갈 때도 남은 열 폭을 재분배할 수 있는지 확인한다. 긴 질문은 자연스럽게 여러 줄로 두되 그 행만 높인다. 대각선 머리글은 두 항목을 각 삼각 영역 안에 두고, 열 폭 변경 때 대각선 끝점·두 항목·바깥 기호 설명도 셀 경계를 따라 갱신한다.

지원 연결본에서는 task instructions에 선택된 표 family의 현재 제작 계약을 사용한다. state의 blank/zero/notApplicable/unknown을 구별하고 응답을 추측하지 않는다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
