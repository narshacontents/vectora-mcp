# 공통 제작 기준

현재 요청의 내용에서 새 구도를 설계한다. **일반 생성은 기출·완성 예시를 검색하거나 읽지 않고 이 스킬의 추출된 원칙으로 수행한다.** 이번 요청이 명시한 원본 재현, 실존 인물/사물 참조, 실자료 조사와 승인된 지도 바탕은 허용한다. 한 성공 예시를 모든 요청의 고정 외피·좌표·장식으로 만들지 않는다.

## 필수 보존

- 표시 원문·수치·소수 자릿수·기호·빈칸·밑줄·관계와 사용자 명시 서식을 보존한다. 지표명·한정어·분모·단위·시점은 적용 범위를 읽을 수 있는 표제/머리글/범례/자료 가까이에 둔다. 공통 단위가 모든 자료에 적용되는지 불명확하면 자료별로 구분한다.
- 빈칸 정답이나 요청 없는 이름·제목·해설·기관·연도·‘가상 자료’ 표기를 추가하지 않는다. 매체의 기본 표기(신문의 ○○신문·기호 날짜)는 해당 recipe를 따른다. 출처/각주는 자료 아래, 제작·검수 기록은 그림 밖에 둔다.
- 새 그림은 별도 문서, 기존 그림은 지정 범위만 수정한다. 문자·말풍선·자료 그래프·도식의 편집성과 자료 연결을 보존한다. 원화는 이동·비례 크기·교체 가능한 포함 이미지여도 된다. 전체 그림을 래스터/윤곽선으로 굳힌 것을 편집 원본이라 하지 않는다.
- 벡터 선·화살촉·선 역할 채움은 **#000000, 유효 불투명도 100%**(상위 그룹 포함)다. 회색 채움/명암, 원화 픽셀, 자연스러운 매체 구조/장식/그림자와 지도 주제·경계를 구분하는 필요한 회색 선은 예외다. 안티앨리어싱과 회색 선 설정을 혼동하지 않는다.
- 원은 1:1, 인물/사물은 자연스러운 비례를 유지한다. 인물 상대 크기는 머리끼리 비교한다. 글·선 규격을 지키며 영역/줄바꿈/간격으로 맞추고 전체 Scale·압축·textLength로 숨기지 않는다. 지도 바탕은 문자·지시선 배치 전에 비례 조절한다.

## 미지정 시 출발값

- 문항 한 단의 가용 폭은 약 **108mm**이며 모든 그림의 기본 제작 폭은 아니다. 미지정 독립 그림은 등록 양식의 기준 폭 또는 글·자료 실측에 필요한 작은 폭으로 시작하고, 보통 108mm보다 작게 완성한다. 많은 내용이나 전체 단 구도가 필요한 경우만 넓힌다. 사용자 지정 폭은 대지가 아니라 제목·라벨까지 포함한 **실제 외곽**이다. 같은 양식도 목표 폭에서 재조판하며 글 크기·선폭을 통째로 축소하거나 대지만 늘리지 않는다. 폭을 높이 상한으로 해석하지 않는다.
- 일반 틀·범례 테두리·인출선은 **0.3pt**, 보조선 **0.2pt**, 축 **0.4pt**에서 시작한다. 대략 0.2–0.4pt 범위에서 밀도·인쇄 크기를 보고 조정한다. 자료선/기간 화살표 등 내용을 전하는 주선은 해당 유형의 더 굵은 값이다. 자료선 > 축·틀 > 보조선의 위계를 읽을 수 있어야 하며 작은 지도 기호·회색 면 경계·원화에 일괄 적용하지 않는다.
- 전체 제목은 전체 내용의 가로 중앙, 소제목은 자기 자료 영역의 중앙이 기본이다. 축 제목·본문 문단은 이 규칙과 구별하고 의미 있는 매체 정렬/사용자 지정은 보존한다.
- 유형별 수치는 사용자 고정·기술 계약 외에는 출발값이다. 최종 내용·글 크기·밀도에 따라 조정하되 원문 의미·자료 관계·편집성을 희생하지 않는다.

## AI가 구도를 고르는 순서

내용의 비교·설명·순서 관계 → 시각적 묶음 → 실제 글/자산 크기 → 배열·정렬선 → 외피·장식을 결정한다. 좌표 미지정은 불완전 의뢰가 아니다. 모든 요소를 같은 상자에 넣거나 남은 칸에 차례로 끼우지 않는다.

한 자료로 읽는 라벨·단위·도형·범례는 가까이, 독립 묶음 사이는 그 내부 간격보다 넉넉하게 둔다. 묶음 내부는 지침의 작은 쪽 간격부터 시작해 획이 닿거나 소속이 흐려질 때 늘린다. 생성기 패딩과 추가 간격의 중복부터 확인한다. **실제 문자 획·표식 외곽**을 기준으로 정렬하며 투명 바탕/글상자 경계만 맞추지 않는다. 읽기 여유·지정 빈칸까지 일괄 줄이지 않는다.

여러 구도가 가능하면 읽는 순서·대응 관계·여백 균형으로 선택한다. 장식은 매체 구조와 남은 공간 안에서 다양하게 만들되 무관한 의미를 더하지 않는다. 인간의 주된 후속 수정은 수치/짧은 문구 편집이므로 AI가 조판까지 끝내고 수동 폭 조절을 떠넘기지 않는다.

## 배경 위 판독성이 필요할 때

선·무늬 위 글자는 작은 흰 받침, 무늬 없는 회색 면 위 글자는 흰 윤곽, 색칠 지도 위 지시선은 가는 흰 테두리로 읽히게 한다. 이런 경우 **`core/readability.md`를 읽고** 최소 여백·0.7pt 문자 윤곽 기준을 적용한다. 정렬된 숫자를 옆으로 밀거나 자료선/중요 경계를 지워 충돌을 숨기지 않는다.
