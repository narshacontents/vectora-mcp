# D2-06_Dot — 점

범주별 하나 이상의 지표를 점 높이로. 두 시점 점 연결 포함

범주별 하나 이상의 정량값을 점 위치로 나타낸다. 같은 범주의 여러 지표는 같은 범주 위치와 서로 다른 표식으로 구별한다. 범주 축을 두 번째 수량 변수처럼 해석하지 않는다. 같은 범주의 두 시점 연결은 비교 방향만 드러내고 다른 범주의 점을 연결하지 않는다. 개별 값/범주 대응과 점의 실제 위치를 검수한다.

두 시점은 `chartStyle:"dumbbell",type:"line"`(정확히 2계열·같은 primary 축) 우선. 단일 값이나 서로 연결하지 않는 여러 지표는 라이브 계약이 지원하는 `bar-scatter`의 `renderRole:"scatter"` 계열을 우선하고, 범주 순서에 대응하는 values와 계열별 표식을 사용한다. 막대가 필요 없으면 모든 계열을 scatter로 둘 수 있는지 확인한다. points 경로를 쓸 때도 범주 라벨을 보완한다. dot이라는 chartStyle을 발명하지 않는다. 임시 범주 좌표는 제작 위치이지 관측 수량이 아니므로 수치로 표시하지 않는다.

## 생성 옵션

- 덤벨 방향: `orientation:"horizontal"|"vertical"`은 dumbbell에서만 사용한다. 세로형도 전체 그림을 회전하지 않고 범주를 가로축, 값을 세로축에 둔다.

- 세로형 두 시점 비교에서 범주명을 위에 둘 때는 연결 앱이 지원하면 `chartOptions.categoryLabelSide:"top"`을 사용한다. 단위·범주명은 겹치지 않으면 같은 상단 띠에 두고, 아래 범례는 자료 영역에 가깝게 둔다. 라벨을 수동 이동한 뒤 아래쪽 예약 여백만 남기지 않는다. 기본 아래 배치나 사용자 지정은 유지한다.
