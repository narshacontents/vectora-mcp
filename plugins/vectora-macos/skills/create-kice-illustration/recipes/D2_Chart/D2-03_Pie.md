# D2-03_Pie — 원·도넛

부채꼴·고리 구성비

구성비 비교 원은 동일 지름·1:1이고 12시부터 같은 계열 순서로 시계 방향, 각도=비율×360°다(명시 순서 우선). 비율 합계 100을 확인하고 오류·반올림 차이를 몰래 정규화하지 않는다. 0%는 조각 없음, 100%는 완전한 원. 면적 자체가 수량이면 반지름은 수량 제곱근에 비례하며 구성비 비교와 구별한다.

제목·라벨·범례 후 지름을 정한다. 원 사이 틈은 지름의 약 1/4–1/2부터, 가운데 범례는 폭+양옆 여백을 추가한다. 중심 높이·제목 기준을 맞춘다. 큰 조각에는 항목명+수치 두 줄을 중심 정렬; 실제 글상자가 안에 들어가지 않는 조각만 외부 인출선으로 옮긴다. 일률 % 기준이나 모든 수치를 범례로 빼는 방식은 쓰지 않는다. 점무늬는 글 주위 점만 비우고 흰 상자로 다른 조각을 가리지 않는다. 도넛은 고리·빈 중심·라벨 공간을 별도 확보하고 가운데는 제공된 총량·시점만 쓴다.

새 16 chartStyle에는 pie/도넛이 없다. 우선 legacy `kind:"graph",type:"pie",series,panels:[{label,values,outside?}],labelMode:"category-percent"|"percent"`(합계100, 같은 지름, outside는 계열 인덱스)을 사용한다. 사선 무늬·relative는 미지원이다. 실제 `vectora_apply`의 pieChart는 합계 대비 비율로 정규화하므로 사전 합계 검증 없이 비율 입력에 사용하지 않는다. 도넛 등 미지원 세부만 생성 후 편집 가능한 고리·라벨로 보충하고 수량·각도를 재검산한다.
