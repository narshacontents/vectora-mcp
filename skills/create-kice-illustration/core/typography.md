# 문자 역할과 편집 구조

## 필수

- 발언·본문·셀·라벨 등 **한 텍스트 덩어리는 하나의 편집 가능한 글상자**다. 자동 줄바꿈·실제 문단·부분 서식을 안에 보존한다. 줄별 글상자, 전체 윤곽선, 전체 이미지로 대신하지 않는다. 제목과 본문·다른 발언/셀처럼 독립된 내용만 나눈다.
- **모든 유형에서 세로쓰기는 실제 세로 글상자로 만든다.** 가로 글상자에 한 글자씩 엔터를 넣거나 가로 글상자를 90° 회전해 세로쓰기를 흉내 내지 않는다. 촘촘한 축 항목·연령 구간도 원문을 그대로 전달하고 세로 방향과 숫자·단위 묶음을 지정한다. 제목과 단위를 두 행으로 나누는 의미 있는 줄바꿈과는 구별한다.
- 원문·기호의 뜻과 요청된 전체/부분 굵게·기울임을 보존한다. 시각적 행 끝을 강제 엔터로 옮기지 않는다. 표시 공백은 아래 조건부 조판을 적용하되, 문자 코드·공백 그대로 보존을 명시한 요청과 URL·코드 구문은 예외다. 전역 Unicode 정규화나 유사 문자 치환을 하지 않는다.
- 실제 설치된 UND v3.1 / UND v3.1 Batang의 Regular·Bold·Italic·BoldItalic을 사용한다. **UND v3.0 Body는 새 제작에서 사용하지 않는다.** 누락 면·글리프는 알리고 임의 서체 교체·합성 굵기/기울임으로 숨기지 않는다. 폰트 바이너리를 그림이나 스킬에 포함하지 않는다.
- 요청된 굵게/기울임은 실제 설치 face와 저장된 style provenance `explicit`을 확인한다. 자동 Regular 기본값으로 덮이지 않았는지 재열기에서 보고, 자동 audit 결과와 명시 서식을 별도로 대조한다.
- 측정·생성·수정에 같은 프로필·부분 서식·실제 pt·장평·자간을 쓴다. 장평은 문자 속성으로 지정하며 그룹 Scale로 대신하지 않는다. 기존 문서의 명시 서식은 요청 없이 바꾸지 않는다. 본문·자료 수치를 공간 부족 때문에 축소하지 않는다.

## 미지정 시 선택

앱 `textProfiles.catalog`의 네 제작 프리셋을 역할에 맞게 선택한다. ID 이름으로 수치를 추정하거나 스킬에 catalog를 복제하지 않는다.

| 역할 | 출발 스타일 |
|---|---|
| 이름·축·범례·짧은 도해 라벨 | 돋움 8pt |
| 독립 상자·카드·말풍선의 줄글 | 돋움 10pt. 도해에 종속된 짧은 설명은 돋움 8pt. recipe의 인용문/제시문 역할이 우선 |
| 바탕 본문·진술 | 바탕 11.5pt |
| 실제 비교표의 셀 | 돋움 10pt 또는 바탕 10.5pt. 셀 역할의 혼용 유지 |
| 제목·비정보성 장식 | 위계에 맞는 명시 크기·굵기. 본문 규격과 구별 |

- 돋움 7·9·9.5·11.5pt 등이 필요하면 돋움 기본 프리셋에서 크기만 변형한다. 작은 측정 차이마다 새 스타일을 만들지 않는다. 긴 본문을 1셀 표로 구현해도 본문 역할이며 표 스타일을 강제하지 않는다.
- **행간은 비율로 저장한다.** 새 글상자·돋움·바탕 10.5pt는 130%, 바탕 11.5pt 프리셋은 150%. 프리셋 변경은 해당 비율을 적용하고 크기만 변경하면 현재 비율을 유지한다. 9pt의 130%는 기준선 간격 11.7pt다. 명시 비율은 보존하며 이전 크기의 pt 행간을 복사하지 않는다.
- 자료 라벨·축·범례·표 수치는 기본 글리프, 돋움의 긴 본문·발언은 **본문용 숫자·기호**, 바탕은 바탕의 기본 글리프를 쓴다. 바탕의 영문만 Body로 교체하지 않는다. 본문 속 도표까지 본문용으로 바꾸지 않는다.

## 입력에 해당하는 지침만 적용

- 모든 표시 문자열의 반칸·콜론·연산자 등은 함께 준비된 **표시 텍스트 조판**을 따른다. 측정 전에 공백을 확정하고 최종 문자열로 서식 인덱스를 다시 계산한다.
- 여러 줄 본문·목록에는 선택된 `core/prose.md`를 적용한다. 짧은 라벨에 산문 조판을 일괄 적용하지 않는다.
- 자료 아래 각주가 있으면 `core/footnotes.md`, 괄호·자료 식별 `(가)`~`(하)`·제목 꺾쇠·특수 기호가 있거나 글리프 틈이 이상하면 `core/symbols.md`의 해당 항목을 읽는다. 이 파일들은 스킬 루트 기준 경로다.
- 원문자 뒤 밑줄은 선택된 `core/underline.md`, 문장 안 박스는 `core/inline-box.md`를 따른다. 폰트의 고유 폭을 공백 삭제·전체 자간 축소로 숨기지 않는다.
