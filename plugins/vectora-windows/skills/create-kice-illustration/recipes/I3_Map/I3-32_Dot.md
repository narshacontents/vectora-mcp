# I3-32_Dot — 점묘도

양적 주제도. 점 하나 = 일정량, 점 개수로 분포

- 단위점은 점 하나의 수량을 범례에 명시하며 도시 위치점과 구별한다. 장식 pattern의 점 수는 수량 보증이 아니다. 자료 해상도보다 정밀한 위치를 주장하지 않는다.
- 지도 안의 모든 단위점과 범례의 점은 같은 물리 지름·농도로 만든다. 범례의 `●` 글리프가 본문 8pt 크기여서 지도 점보다 커지면 같은 지름의 편집 가능한 원을 쓰고 설명 글자는 8pt로 유지한다. 범례 점을 제외한 지역별·전체 점 수를 원자료와 대조한다.
- 분포를 나타내는 합성 점은 중심뿐 아니라 점의 외곽은 허용 영역 안에 두고 밀도에 맞는 공통 지름·단위 수량·겹침 정도로 분포를 읽히게 한다. 폭을 줄인 뒤에도 물리 지름과 해안까지의 간격을 다시 확인한다. 실제 시설·도시의 정확한 위치점은 분포 점처럼 임의 이동하지 않는다.
