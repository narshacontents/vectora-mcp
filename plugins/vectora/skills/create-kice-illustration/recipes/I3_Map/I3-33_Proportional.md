# I3-33_Proportional — 도형 표현도

양적 주제도. 지도 위 제자리의 원·막대·풍향 장미 크기·구성이 값. 지도 둘레에 따로 그린 차트를 지시선으로 이은 것은 D2

- 등급별 기호의 크기/명도/범례를 그대로 대응시킨다. 세 등급 원을 연속 비례 원으로 바꾸지 않는다. 총량 비례 원의 양수 값은 **r=k×sqrt(value)**로 면적을 대응시키고 지도/범례에 같은 k를 쓴다. 최소 기호·0·음수·결측 정책과 크기표를 별도로 확인한다.
- 도법이 미지정이면 비교 대상들이 균형 있게 읽히는 바탕을 선택한다. 고위도 팽창 때문에 주요 지역과 작은 기호가 지나치게 축소되는 구도를 피하되 요청한 지역을 생략하거나 비등방 변형하지 않는다. 경위선 간격도 미지정이면 주요 위경도를 읽는 성긴 간격을 우선한다.
- 밑변을 맞춘 중첩 원 범례는 큰 원부터 뒤에 놓고 각 수치가 어느 원을 뜻하는지 짧은 연결선으로 구분한다. 제목·원·수치를 가까이 묶고 불필요한 빈 띠를 만들지 않는다. 값 편집은 해당 원과 범례를 같은 척도로 갱신하며, 직접 계산한 반지름만 저장한 경우 자동 수치 연동으로 보고하지 않는다.
