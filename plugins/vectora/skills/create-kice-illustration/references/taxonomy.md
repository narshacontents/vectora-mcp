# 분류와 작업 조건 검색

10유형·54개 제작 ID의 분류 정의와 선택 안내다. 분류가 필요할 때 검색하며 매 작업의 필수 읽기 문서가 아니다. 실제 작업 조건에 맞춰 family·recipe·component·execution module을 선택하여 task instructions를 구성한다. ID는 MCP kind나 layout 값이 아니다.


## D1_Table — 표

행·열과 셀 대응을 읽는 격자다. 아래에서 세부 ID 하나를 고른다. 대각선 모서리 하나는 다단 헤더가 아니다. 응답 기호→병합/계층 헤더→모든 셀이 동질인 교차값→한 값 줄/여러 다른 개념 줄 순으로 판정한다.

| 세부유형 | 선택 기준 |
|---|---|
| `D1-01_Flat · 단일헤더 목록표` | 머리 1겹 + 값 한 줄(한 행 또는 전치형 한 열). 이름+값 2열 목록은 항목 행이 여럿이어도 값 열이 하나면 여기 |
| `D1-02_MultiFlat · 다중헤더 목록표` | 단일헤더 목록표 여러 줄이 같은 머리를 공유해 쌓인 표. 값 줄 2개 이상이고 줄마다 다른 개념(항목별 수치표·설명표). 칸이 모두 같은 개념의 교차값이면 Cross(단위만 같다는 뜻이 아님) |
| `D1-03_Cross · 교차표` | 행·열 모두 범주, 셀=교차값(동질). 전치해도 성립. 대각선 모서리 헤더 허용 |
| `D1-04_Nested · 병합헤더표` | 헤더 2겹 이상 또는 병합 셀·섹션 띠. 대각선 모서리 칸만으로는 Nested 아님(R6) |
| `D1-05_Checklist · 응답체크표` | 셀이 ○×·✓·빈칸·점수. 조건 대응용 |
| `D1-06_Others · 기타 격자` | 선택지 띠, 퍼즐 격자, 카드 나열 |



## D2_Chart

유한한 관측값의 범주·시점·구성비를 표현한다. 연속 이론·개념 관계와 경계·영역은 숫자가 없어도 graph다. 비정량 특성 축에 개별 대상의 위치를 배치하면 D4_Diagram/D4-06_Schematic이다. 아래에서 세부 ID 하나를 고른다.

| 세부유형 | 선택 기준 |
|---|---|
| `D2-01_Bar · 막대` | 범주별 독립 막대. 가로·세로·그룹 |
| `D2-02_StackedBar · 누적 막대·띠` | 막대 내부 분할. 절대량 누적·100% 띠 |
| `D2-03_Pie · 원·도넛` | 부채꼴·고리 구성비 |
| `D2-04_Line · 선` | 유한 시점·순서 관측값을 선으로 연결 |
| `D2-05_Scatter · 산점·버블` | 두 정량 지표 좌표점. 버블 포함 |
| `D2-06_Dot · 점` | 범주별 1지표를 점 높이로. 두 시점 점 연결 포함 |
| `D2-07_Radar · 방사형` | 중심 축 배치. 레이더·풍향장미 |
| `D2-08_Others · 기타 차트` | D2 7종에 없는 유한 정량 차트(트리맵·모자이크·면적 비례 격자 등) |


### 작업 조건 선택

- 실제 자료 조사 `real-data`, 기타 차트의 직교 수치 축 `cartesian`, 명시 혼합/이중축 `mixed-axis`, native 기능이 불가한 경우만 `graph-helper`.


## D3_Graph

연속 함수·가능 영역·분포의 이론 관계가 의미다. 유한 관측 연결은 chart다. **2축 개념도는 축에 숫자가 없어도 연속적인 관계·경계·영역 자체가 뜻을 가지면 D3_Graph/D3-04_Others**, 개별 대상들을 비정량 특성의 양끝 사이에 배치하는 구조면 D4_Diagram/D4-06_Schematic이다. 숫자 유무나 그림 모양만으로 다시 분류하지 않는다. 아래에서 세부 ID 하나를 고른다.

| 세부유형 | 선택 기준 |
|---|---|
| `D3-01_Curve · 함수 곡선` | 축 위 연속 함수. 교점·기울기·이동, 거리 연속축 지형 고도 단면 |
| `D3-02_Frontier · 경계선` | 선이 가능 영역을 가름. 안·위·밖이 의미 |
| `D3-03_Distribution · 분포 곡선` | 면적·누적 비율이 의미 (로렌츠·CDF). 자료집 reserved는 제작 금지가 아님 |
| `D3-04_Others · 기타 연속` | 그 밖의 연속 곡선/개념 관계. 정량 관계의 곡면 포함 |


### 작업 조건 선택

- 실제 자료 조사 `real-data`, 명시 혼합/이중축 `mixed-axis`, native 기능이 불가한 경우만 `graph-helper`.



## D4_Diagram

개체·관계·절차·시간 순서·수량 없는 공간 구조를 나타낸다. 정량 관측 축은 chart다. **특성 축 위 개별 대상의 비정량 위치·속성 배치는 D4_Diagram/D4-06_Schematic**, 연속 개념 관계·경계·영역 자체를 읽는 2축 그림은 숫자가 없어도 D3_Graph/D3-04_Others다. 축에 숫자가 없다는 이유만으로 연속 관계를 여기로 보내지 않는다. 아래에서 세부 ID 하나를 고른다.

| 세부유형 | 선택 기준 |
|---|---|
| `D4-01_Tree · 위계도` | 분류 체계·조직도·삼단논법. 무순환 |
| `D4-02_Network · 관계도` | 임의 연결·인과·화살표 관계 |
| `D4-03_Flowchart · 순서도` | 예·아니오 분기, 절차 |
| `D4-04_Venn · 벤다이어그램` | 집합 교집합 |
| `D4-05_Timeline · 연표` | 시간축·순서 배치 |
| `D4-06_Schematic · 모식도` | 단면·공간 구조·특성 좌표 배치·3D 속성 큐브(정량 값 없는 축) |
| `D4-07_Others · 기타 도식` |  |


### 작업 조건 선택

- 노드 관계가 있는 모식도는 `node`를 선택한다.


## I1_Photo — 사진·스캔

실제 사진·스캔·기존 회화·판화·우표·포스터의 복제다. 국기·주화라도 새 선화로 그리면 I2_Illustration이다.

자료 분류에는 하위 코드가 없다. 세부 제작은 `photo-original` 하나를 선택한다.


## I2_Illustration — 새 삽화

자료 분류에는 하위 코드가 없지만 제작 시에는 `illustration-portrait`(독립 얼굴/흉상), `illustration-object`(물체/생물), `illustration-scene`(동작/풍경/복원 장면) 중 하나를 선택한다.

원래 I2 계열의 신규 작화다. 유물·주화·국기·문장의 선화 재작화도 포함한다. 실제 사진/스캔/기존 작품 자체의 복제는 Photo다. 형태·재질·행동을 전달하는 자연 장면은 Illustration, 연결·단면·공간 구조·속성 좌표 등의 관계가 핵심인 모식은 Diagram이다. ‘모식도’라는 명칭이나 정량값 유무만으로 자연 장면을 일괄 분류하지 않는다. 공간 기준 위의 위치·영역·분포·이동은 Map이다.

### 작업 조건 선택

- 인물이 있으면 작업조건에 `people:true`; 생물 구조/부분 확대는 `organic`; 내부까지 순수 벡터를 명시한 경우만 `vectorize`.


## I3_Map — 지도

공간 기준 위 위치·분포·영역·이동을 표현한다. 실제 작업 조건에 맞는 지도 family·recipe·component·execution module을 task instructions로 선택한다. 도구의 실제 스키마·응답, 선택 자산의 manifest와 실제 자료를 확인한다.


## 핵심 정보로 한 하위유형 선택

| 세부유형 | 선택 기준 |
|---|---|
| `I3-11_Locator · 위치 지시도` | 일반도. 칠한 면·그은 경계·점이 정답 후보 자리일 뿐이고 (가)·A~E로 '어디(어느 나라)인가'를 맞추게 함. 면을 칠했든 아니든, 범례가 수도·국경 기호뿐이면 여기 |
| `I3-12_Topographic · 지형도` | 일반도. 지형 등고선·하천·지도 기호의 대축척 지형도, 해발 고도 등고선 모식 |
| `I3-13_OldMap · 고지도·실물 지도` | 일반도. 기존 지도의 사진·스캔(옛 세계 지도, 대동여지도, 점토판). 표현 방식보다 우선 |
| `I3-14_Others · 기타 지도` | 일반도. 평면·배치도, 반구·지구본, 특수 투영 모식, 카토그램 |
| `I3-21_Area · 영역 구분도` | 질적 주제도. 범례·라벨·설명이 면이 무엇의 범위인지(언어권·암석·산업 지역·왕조 영역·빙하·호수 범위) 알려 주고, 그 범위·변화 자체가 정보 |
| `I3-22_Route · 경로·선 기호도` | 질적 주제도. 양 없는 선: 원정로·교역로·이동 경로·산줄기·사건 순서 |
| `I3-23_Symbol · 점 기호도` | 질적 주제도. 범례가 점 기호(●□△)에 범주를 줌 |
| `I3-31_Choropleth · 단계 구분도` | 양적 주제도. 구역·격자별 음영 등급이 값의 구간 |
| `I3-32_Dot · 점묘도` | 양적 주제도. 점 하나 = 일정량, 점 개수로 분포 |
| `I3-33_Proportional · 도형 표현도` | 양적 주제도. 지도 위 제자리의 원·막대·풍향 장미 크기·구성이 값. 지도 둘레에 따로 그린 차트를 지시선으로 이은 것은 D2 |
| `I3-34_Isoline · 등치선도` | 양적 주제도. 기온·강수량 등 통계값의 같은 값을 이은 선. 지형 등고선은 I3-12 |
| `I3-35_Flow · 유선도` | 양적 주제도. 화살표 굵기로 이동 방향과 양 |


### 작업 조건 선택

- `features`: 한국 바탕 korea, 확대/패널 inset, 위치점 points, 면 강조 area, 경로 route, 통계 statistics, 자연층 natural, 판/빙상 tectonic-ice, 역사 historical, 도법/시차 projection, DEM dem. 해당 세부유형에 필수인 조건은 자동 포함되므로 중복 지정할 필요 없다. 고지도 원본은 프리셋을 자동 요구하지 않는다.


## ITA_TypeSwap

활자 교체형. 일반 인물과 글·숫자·표를 담는 판을 사람 수와 배치로 구분한다. 특정 인물·사진·장소·복장이 식별 단서이면 ITC_Fixed를 먼저, 사진·지도·그래프·삽화 자료 칸이 있으면 ITB_ImageSwap을 먼저 판정한다.

| 세부유형 | 선택 기준 |
|---|---|
| `ITA-1_TypeBoard · 활자 보드` | 활자 교체형. 사람 없이 글·숫자·표만 담긴 판(신문·편지·사료·조문·웹·앱 화면·학습지·평가지·채점표) |
| `ITA-2_Solo · 1인 발화` | 활자 교체형. 일반 인물 한 사람 + 말풍선(연단·앵커·일상). 보드·화면 없음 |
| `ITA-3_DialogueH · 가로 대화` | 활자 교체형. 일반 인물 여러 명이 좌우로 나란히, 말풍선도 옆으로(갑·을 대화, 토론, 칸 만화) |
| `ITA-4_DialogueV · 세로 대화` | 활자 교체형. 화자별 줄이 위아래로 쌓임(인물·아이콘·이름표 + 글상자) |
| `ITA-5_SoloBoard · 1인 + 활자 보드` | 활자 교체형. 한 사람 + 활자만 있는 칠판·스크린·모니터·TV(말풍선 없어도 됨) |
| `ITA-6_GroupBoard · 여러 명 + 활자 보드` | 활자 교체형. 여러 사람 + 활자만 있는 보드·화면 |



### 작업 조건 선택

- 보드 세부유형은 `variant`로 newspaper / screen / paper / scroll / board / worksheet 중 실제 매체를 고른다.
- 보드에 실제 보조 발언이 있을 때만 `speech-horizontal`, `speech-vertical`, `speech-solo` 중 하나를 선택한다. 인물 없는 메신저는 ITA-4 + `messenger`이며 `people:true`를 지정하지 않는다.


## ITB_ImageSwap

그림 교체형. 사진·지도·그래프·삽화 자료 칸이 있는 판과 해설자 구성을 사람 수로 구분한다. 실제 특정 인물·장소·복장이 식별 단서인 고정형은 ITC_Fixed를 먼저 판정한다. 신문 속 교체 가능한 보도 사진만으로 ITC-2_RealPhoto로 바꾸지 않는다.

| 세부유형 | 선택 기준 |
|---|---|
| `ITB-1_ImageBoard · 그림 보드` | 그림 교체형. 사람 없이 사진·지도·그래프·삽화 칸이 든 판(신문 사진, 웹 사진, 답사 계획서 지도) |
| `ITB-2_SoloImageBoard · 1인 + 그림 보드` | 그림 교체형. 한 사람 + 그림이 든 보드·화면, 또는 해설자 + 유물 사진 |
| `ITB-3_GroupImageBoard · 여러 명 + 그림 보드` | 그림 교체형. 여러 사람 + 지도·그래프·그림 보드·자료 |



### 작업 조건 선택

- 보드 세부유형은 newspaper / screen / paper / scroll / board / worksheet, 해설자+틀 없는 자료는 plain을 `variant`로 고른다.
- 보드에 실제 보조 발언이 있을 때만 `speech-horizontal`, `speech-vertical`, `speech-solo` 중 하나를 선택한다. 자료 칸이 실제 사진인지 새 작화인지에 따라 공통 조건을 선택한다.


## ITC_Fixed

고정형. 특정 인물·실존 인물 사진·특정 장소/사건·시대 복장이 식별 단서인 경우이며 ITA·ITB보다 먼저 판정한다. 갑·을 같은 화자 기호만으로 특정 인물로 분류하지 않는다.

| 세부유형 | 선택 기준 |
|---|---|
| `ITC-1_Figure · 특정 인물` | 고정형. 얼굴·차림으로 누군지 알아보는 특정 역사 인물·사상가(칸 만화 포함) |
| `ITC-2_RealPhoto · 실존 인물 사진` | 고정형. 실제 인물의 초상·보도 사진이 단서 |
| `ITC-3_Place · 특정 장소·장면` | 고정형. 특정 건축물·광장·유적·사건 현장이 배경이자 단서 |
| `ITC-4_Costume · 시대 복장 인물` | 고정형. 특정인은 아니지만 복장(관복·승복·갑옷 등)으로 시대가 정해진 인물 장면 |



### 작업 조건 선택

- `variant`로 실제 배치 horizontal / vertical / presentation / scene, 또는 매체 newspaper / screen / paper / scroll / board / worksheet를 고른다.
- 보드에 실제 보조 발언이 있을 때만 `speech-horizontal`, `speech-vertical`, `speech-solo` 중 하나를 선택한다. 발언 variant가 있으면 speech 조건을 중복 선택하지 않는다.

## 분류 우선순위

교체형/고정형은 **ITC → ITB → ITA** 순서다. 갑·을은 특정 인물명이 아니다. 자료 분류는 핵심 근거에 따라 하나를 고르며, 세부 `Others`를 공통 회피 경로로 쓰지 않는다. 대표 기출 예시는 분류 경계 이해용이지 제작 참조/의존 파일이 아니다. 분류 ID는 MCP kind나 layout 값이 아니다.
