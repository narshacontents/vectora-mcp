# 여러 요소의 구도

**복합형:** 독립적으로 완결된 자료 단위를 나누고 각 단위를 작업 명세의 units에 넣고 필요한 제작·구성요소 규칙을 조립한다. 공통 규칙과 같은 구성요소 규칙은 한 번만 읽는다. 같은 장면의 교사 발표와 학생 가로 발언처럼 배치 규칙이 다른 발언군은 지침 선택용 unit을 나눌 수 있으나, 같은 외피·인물·발언을 중복 제작하지 않는다. 매체 테두리·교사·짧은 발화처럼 종속된 요소 자체를 별도 완성 그림으로 만들지 않는다. 같은 기호·시점·값을 단위 간 대조하고 하나의 완성 그림으로 저장하되 내부 자료·글·연결은 편집 가능하게 유지한다. 작업 준비 도구가 composition 지침을 함께 포함한다.

## 구도가 미지정인 경우

제작 전에 각 요소를 **주자료·비교 자료·설명/화자·공통 표기**로 묶고 읽는 순서를 정한다. 같은 대상을 비교하면 나란히, 단계·인과이면 순서대로, 설명이 주자료에 종속되면 한 장면 안에 배치한다. 여러 개가 있다는 이유로 전부 같은 카드나 일렬로 만들지 않는다. 먼저 두 가지 정도의 간단한 배치를 내부적으로 비교하고, 실제 글·자료 외곽으로 폭·높이·정렬선·범례 자리를 정한 뒤 제작한다. 사용자에게 좌표를 추가로 요구하지 않는다.

- **동등한 비교 자료:** 두 자료는 비슷한 시각적 비중에서 시작한다. 제목 행과 실제 자료의 상단/바닥/중심 중 하나를 공유하되, 제목·단위·범례를 포함한 빈 컨테이너 중앙만 맞추지 않는다. 세 개 이상은 각각의 최소 판독 폭을 먼저 재고, 좁고 길게 찌그러지면 두 줄 배열이나 세로 배치를 선택한다. 같은 의미의 비교에는 척도·순서·표식 대응도 맞춘다.
- **좌우로 나란한 직교좌표 그래프:** 특별한 이유가 없으면 실제 Y축의 위끝과 아래끝을 모두 같은 높이로 맞춘다. 먼저 같은 `plotHeightMm`를 정하고, 생성된 축의 실제 전역 좌표를 측정해 그래프 묶음을 이동한다. `yMm`·컨테이너 높이가 같아도 제목·단위·자료값·범례 여백 때문에 축 높이는 달라질 수 있다. 제목과 범례는 이 공통 플롯 밖에서 따로 정렬하며, 그래프 전체를 세로 확대·축소하거나 척도·값을 바꾸어 맞추지 않는다.
- **주자료와 보조 자료:** 주자료에 우선 폭을 주고 작은 표·설명·화자는 가까이 묶는다. 나란한 원/방사형 그래프와 짧은 표에서 표를 최소 폭으로 몰아 그래프만 거대하게 만들지 않는다. 표의 자연스러운 행 높이와 그래프의 가용 높이를 함께 보고 폭 배분을 정한다. 자료를 억지로 같은 높이로 만들려고 빈 행·문장을 넣지 않는다.
- **공유 장면:** 칠판·화면·지도와 화자/발언은 한 구도다. 배경의 의미 없는 부분은 인물·말풍선이 가려도 되며 중요한 내용과 연결점만 보호한다. 인물의 가시 높이·손끝·말풍선 끝과 자료판의 관계를 먼저 정해 아래 빈 띠나 고립된 발언이 생기지 않게 한다. 배경과 화자를 각각 완성한 뒤 남은 곳에 끼우는 방식은 피한다.
- **간격의 위계:** 라벨↔자기 표식/축은 짧게, 같은 묶음의 항목 사이는 그보다 넓게, 독립 자료 사이는 더 넓게 한다. 독립 패널은 약3–5mm 틈부터 검토하되 지시선·긴 라벨·전체 크기에 맞춘다. 모든 방향을 같은 숫자로 고정하지 않는다. 서로 가까운 표기와 먼 표기의 소속이 눈에 보여야 한다.

끼워 넣는 자료는 실제 제목·문자·도형의 표시 외곽으로 측정한다. 생성기의 패딩과 외피 여백을 중복하지 않고, 빈 캡션 행이나 투명 이미지 패딩을 정렬 기준으로 삼지 않는다. 원·지도·원화는 비례를 보존하고 표·일반 그래프는 문자 규격과 자료 관계를 유지하며 재조판한다. 한쪽만 절반 높이로 끝나 큰 빈 면이 생기면 폭 배분·배열 방향·범례 위치를 다시 고른다. 무의미한 장식이나 큰 공백으로 108mm를 채우지 않는다.

지도에 연결한 자료창은 판독에 필요하지 않은 지도 바탕 위에 겹쳐 놓을 수 있다. 강조 지역·지명·경계의 판독 부분과 지시선 끝은 보존하되, 모든 자료창을 지도의 사각 외곽 밖으로 밀어 큰 빈 띠를 만들지 않는다. 지도 범위는 요청한 주제를 담도록 정하고 무관한 지역을 포함한 채 배치 여백으로 취급하지 않는다.

자료를 갱신·재생성하면 외곽 크기와 주변 자료의 위치가 달라질 수 있다. 생성기 밖에서 보충한 외피·테두리·공통 범례·주석·지시선도 새 외곽에 맞춰 크기와 위치를 다시 맞추고, 독립된 테두리끼리 붙거나 겹쳐 하나의 구조처럼 보이지 않는지 확인한다. 이전 좌표를 그대로 재사용하지 않는다.

외피를 여러 면으로 보충할 때는 뒤에서부터 바깥 테두리·회색 장식 → 흰 내용 면 → 글·표·그래프 순서로 쌓고, 완성 순서를 유지한 채 그룹화한다. 여러 배경을 각각 맨 뒤로 보내면서 흰 면이 회색 외피 아래로 뒤집히지 않게 한다. 전체 그림뿐 아니라 내용 면이 실제로 흰색을 유지하는지도 확인한다.
