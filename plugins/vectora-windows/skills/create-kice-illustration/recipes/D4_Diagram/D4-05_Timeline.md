# D4-05_Timeline — 연표

시간축·순서 배치

시간 순서 연표와 경과 시간을 재는 축을 구별한다. 순서만 주어지면 범주 간격을 쓸 수 있고 기간 비교면 실제 시점 간격을 쓴다. 사건·구간 수·기호는 유지한다. 사건 핀/구분선과 그 사이 구간 라벨을 구별하고 사건명은 위치 가까이에 줄바꿈한다. 여러 주체의 상태 구간은 시점 경계를 공유하되 행을 나눈다. 미제공 전환·방향·기간을 추가하거나 사건 핀을 진행 화살표처럼 만들지 않는다. 축 0.4pt·인출/구간 보조선 0.3pt를 쓰되 임의 수량 눈금은 넣지 않는다.


현재 연결본의 schematic schema에 `layout:"timeline"`이 있으면 사건 연표는 이를 우선한다. `timeline:{version:1,spacing:"sequence"|"proportional",events:[{id,time,label,timeLabel?}]}`에 원문의 사건을 넣는다. 순서만 나타내면 sequence, 경과 시간 비례이면 한 단위의 증가하는 수치 time과 proportional을 쓴다. 표시에만 필요한 ‘년’·시대명은 timeLabel로 분리하고, 실제 시간을 라벨 배치 때문에 바꾸지 않는다. 사건 추가·수정 시 기존 id를 유지한 전체 events와 필요한 widthMm를 갱신한다. 계획의 사건 좌표·라벨·연결선과 실제 외곽 폭을 확인하고, 핀과 라벨을 독립 도형으로 옮기지 않는다.

이 계약은 개별 사건 연표용이다. 동시 사건·기간 막대·여러 주체의 상태 행 등 라이브 계약이 지원하지 않는 표현에는 필요한 편집 요소를 보충하되, 이미 지원되는 사건·시간축을 통째로 재작성하지 않는다. 좁은 폭에서 실제 시점이 겹치면 연표를 나누거나 폭을 조정하고, 비례 간격을 등간격으로 바꾸어 숨기지 않는다.
