# D4-03_Flowchart — 순서도

작은 별도 범례는 견본과 설명을 하나의 상자 안에 두는 것을 기본으로 한다. 마지막 설명의 실제 잉크까지 포함해 사방에 여백을 확보하고, 도식의 외곽상자만 그린 뒤 범례가 그 밖에 떠 있지 않게 한다. 상자 없이 곡선에 직접 이름을 붙이는 등 명시된 다른 방식에는 강제하지 않는다.

예·아니오 분기, 절차

절차·판정과 질문별 응답 경로를 구별한다. 별도 지정 없으면 예=실선, 아니요=파선이며 각 응답 라벨과 도착 결과를 연결표로 검사한다. 여러 질문이 공유 결과를 가리키는 구조를 순차 질문으로 바꾸지 않는다. 갈라진 병렬 판정·최종 결과는 각각 같은 높이에 두고 경로 누락·잘못된 합류·출구 없는 순환을 확인한다.

단순한 가로 단계열은 지원되는 네이티브 `layout:"sequential"`의 측정 배치부터 사용하고, 특별한 위치 관계가 없으면 노드별 `xMm/yMm`을 고정하지 않는다. 문구 변경 뒤에도 자동 중심 정렬이 유지되는지 확인한다. 목표 외곽 폭은 노드의 실제 폭·연결 간격·선 끝까지 합쳐 배분하며, 논리 `widthMm`만 늘려 자연폭 노드가 함께 늘어났다고 간주하지 않는다. plan의 `boundsMm`와 실제 출력 외곽을 대조하고 문자를 통째로 확대해 맞추지 않는다. 가로 질문열은 실제 줄 수와 상자 높이를 먼저 구한 뒤 좌우 연결점의 높이를 맞춘다. 한 줄 질문과 여러 줄 질문의 위쪽 좌표를 같게 고정해 수평 연결선이 비스듬해지게 하지 않는다. 상자 없는 결과는 보이지 않는 글 프레임의 중심 대신 실제 글 획의 중심을 연결 축에 맞춘다. 아래 결과가 한 줄로 나열되면 결과와 반복 응답의 기준선을 함께 맞추고, 응답 문구가 선 위에 있어야 할 때는 공통 규칙의 작은 흰 받침을 첫 조판에 포함한다.

설명 상자를 차례로 잇는 **단계 전환 표지**는 복잡한 분기 연결선과 구별한다. 큰 자료 상자 사이에서는 짧고 선명한 채움 화살표부터 검토하고, 촉만 겨우 보이는 가는 바늘 모양을 피한다. 중심선과 상하 틈을 맞추되 모든 관계도·분기선에 굵은 화살표를 강제하지 않는다. 시기 열이 있는 단계 상자는 각 설명의 실제 높이로 조판하고 열 경계·시기명·연결표시도 같은 행을 따라가게 한다.

질문별 응답으로 대상을 구분하는 도식은 질문을 직사각형으로, 짧은 결과를 원·타원 등으로 구별한다. 절차의 판단 지점을 마름모로 표현하는 요청에는 마름모를 쓰며, 물음표가 있다는 이유만으로 모든 질문을 마름모로 바꾸지 않는다. 원본 또는 요청의 명시 모양이 우선한다. live schematic의 `diamond`·`document`가 지원되면 해당 원본 모양을 저장하며 사각형을 만든 뒤 겉 경로만 바꾸지 않는다. 한 글자 판단 기호의 마름모는 실제 글 여백을 확보한 가로로 긴 형태부터 잡고, 긴 질문용 높이를 그대로 쓰지 않는다. 시작·판정 문장이 길면 자연스러운 어절 줄바꿈의 두 줄 폭도 비교한다. 마름모 질문을 한 줄에 넣으려고 가로로 벌리지 말고, 실측 문자 영역과 비스듬한 변의 여유로 폭·높이를 함께 정한다. 분기 사이 빈 면적을 줄일 때는 노드 간격뿐 아니라 반환 통로와 마지막 결과의 위치도 함께 조판한다. 배치가 지정되지 않았다면 긴 수직 단계열과 가로 전개를 비교해, 연결 의미를 유지하면서 한쪽 빈 면적이 과도하지 않은 구도를 고른다. 범례에는 의미 설명이 필요한 기호만 넣고 본문의 실제 선·화살촉·노드 모양과 일치시킨다. 화살촉은 가는 연결선·문자 크기에 맞추며 관계 강조 요청 없이 크게 확대하지 않는다. 분기 라벨은 실제 연결선 가까이에 두고 범례나 이웃 경계에 걸치지 않게 한다.

범례가 있는 순서도는 범례까지 포함한 전체 외곽을 요청 폭으로 잡는다. 범례의 실제 폭·위치와 본 도식의 질문·결과·통로를 함께 배분한다. 범례는 마지막 설명 줄까지, 각 통로는 꺾임·화살촉·응답 라벨까지 포함한 점유영역으로 검사한다. 노드가 없는 곳도 연결 라벨이 지나가면 빈 공간이 아니므로 별도 범례를 놓지 않는다. 본 도식만 요청 폭 전체로 먼저 벌린 뒤 범례를 끼워 넣지 않는다. 같은 결과들을 판정하는 두 질문은 대응하는 한 묶음으로 보고, 짧은 결과의 자연폭·촉에 필요한 통로를 뺀 나머지 폭을 질문에 배분한다. 전체 폭을 채우려고 연결선만 길게 늘이거나 짧은 시작 상자를 긴 띠로 만들지 않는다. 질문 폭과 실측 줄바꿈·높이를 함께 검토해 균형을 맞추고, 빈 질문 `(가)`만 지나치게 납작한 띠로 축소하지 않는다. 연결 통로에 넓은 빈 공간이 있는데 질문의 어절이 갈라지면 먼저 폭 배분을 고친다. 공유 결과는 두 질문 사이의 시각적 중심에 두며, 반복 결과의 간격은 짧은 상자 높이에 맞춘다. 연결선은 도착 윤곽에 화살촉이 자연스럽게 진입하는 방향인지, 응답 문구는 자기 선·꺾임·노드와 떨어져 읽히는지 확인한다. 좌표를 지정하는 도식은 모든 노드의 실제 문구·폭으로 높이를 먼저 측정한 뒤 이웃 노드·범례·통로를 배치한다. 문구 변경으로 높이가 늘면 이웃 위치도 함께 다시 정하며, 화살표 끝의 자동 추종을 주변 배치의 자동 조정으로 간주하지 않는다. 원문을 바꾼 뒤에는 상자뿐 아니라 모든 경로와 각 응답의 연결도 다시 검수한다.
