# 사람의 추가 편집 없이 사용하는 완성 기준

검수를 위해 원문을 임의로 늘리는 시험은 하지 않는다. 실제 내용 수정 의뢰에서는 재조판과 연결 관계를 확인한다.

기본 스타일 검수는 2028학년도 평가원 예시문항에서 정리한 해당 구성의 형식을 먼저 적용한다. 그 시험지에 없는 구성만 기존 기출 기준으로 판단한다. 원문 재현 검증에서는 내용 일치, 조판 일치, 글꼴 고유 모양의 차이를 분리해서 기록한다. 문자열이 같다는 사실만으로 줄바꿈·간격까지 같다고 판정하지 않는다.

사용자가 원본 대조를 요청한 검증에서는 **동일한 실제 글자 크기에서 원본과 생성본을 겹쳐** 자폭·자간·기준선 간격·문장부호·기호를 따로 비교한다. 원본 PDF의 물리 크기 또는 대표 글자의 크기로 균일하게 축척을 맞추고, 가로·세로를 따로 늘려 차이를 숨기지 않는다. 반복 확인된 조판 차이는 기본값 후보, 특정 문자의 윤곽 차이는 글리프 대치 후보로 구분한다. 윤곽이 같아도 글리프 폭·좌우 여백은 다를 수 있으며, PDF에서 추출한 문자 코드는 원래 입력 코드의 증거로 단정하지 않는다. 개별 일러스트의 폭·강조 예외를 전체 기본값으로 일반화하지 않으며 일반 신규 제작에 원본 예시 열람을 추가하지 않는다.

- 최종 fit/audit는 실제 표시되는 glyph ink·획·clip 결과와 사용자가 명시한 유효 예약 bounds를 기준으로 한다. composition child `reserve`, text root `reserve`, 지원되는 text-frame `blocks` 예약만 빈 공간으로 보존한다. 빈 프레임, 숨긴 임시 문자, 가짜 placeholder를 예약으로 만들지 않는다. 내용·자료 좌표·선택한 문자 규격과 명시 치수는 유지하고, clip 밖 편집 기하는 최종 보이는 폭에 산입하지 않는다.

1. **1차 완성본을 반드시 이미지로 직접 보고**, 최종 사용 크기와 확대에서 원문·글리프·단위·자료 대응, 글/선 규격·편집성, 명백히 어색한 겹침·잘림·너무 큰 틈·불필요 여백·원화 화풍·꼬리/인출선의 실제 대상을 확인한다. 선택 세부 원칙에 있는 배치·간격 검사도 함께 수행한다. 별도로 실제 개체 ID와 문자 서식을 검사해 텍스트 덩어리당 글상자 하나, 같은 글상자의 단일/이중 밑줄 서식, 줄별 분리 글상자·별도 밑줄 선 없음도 확인한다. 저장·재열기 뒤에도 이 편집 구조가 유지되어야 한다. 수치 audit나 렌더 성공만으로 통과시키지 않는다. 의도된 본문 빈칸·원화 내부 장면 공간은 외부 대지 여백과 구별한다.

2. **사람의 후속 편집 없이 바로 쓸 수 있는 상태**를 완료 기준으로 삼는다. 개별 요소를 읽기 전에 전체를 보고 제목의 중심, 나란한 자료의 시각적 크기, 공통 정렬선, 한 묶음 내부와 독립 묶음 사이의 간격 차이를 확인한다. 다음으로 대지 외부, 틀 내부, 요소 사이, 글자 주변을 나누어 본다. 의미 없는 빈 띠·한쪽으로 쏠린 틈·라벨의 고립·지나친 밀착·배경 회피 때문에 벌어진 배치는 불통과다. 내용이 맞거나 충돌이 없다는 이유로 이런 결함을 통과시키지 않는다. 필요한 숨쉴 틈과 지정 빈칸까지 없애지는 않는다. 결함은 배치/원화를 수정한 뒤 전체를 다시 이미지로 검수한다. 최초 결과와 수정 후 결과를 구분하고, 수정 예산과 중단 판단은 SKILL의 검수 절차를 따르며 미충족·도구 한계는 보고한다. 축소·흐림·클리핑·진단 면제로 숨기지 않는다.

범례처럼 문자와 도형이 짝을 이루면 실제 문자 획의 중심과 표식/선의 중심을 가로·세로 각각 대조한다. 글상자 중앙 정렬만으로 합격시키지 않으며 여러 줄 라벨은 전체 표시 획의 묶음을 본다. 수치·문구 수정 후에도 단위/라벨의 소속과 이 정렬이 유지되는지 확인한다.

목록은 내용의 상하 관계와 들여쓰기 단계가 일치하는지 확인한다. 같은 단계의 표지·본문 시작선과 이어지는 줄의 본문 열을 비교하며, 분수식·딸린 표도 해당 단계 안에 있어야 한다. 모든 왼쪽 끝을 일치시킨 것을 정렬 합격으로 보지 않는다. 독립 제목·자료의 가운데 정렬은 목록의 들여쓰기와 구별한다.

대지 외곽을 실제 내용에 맞춘 결과 글 획이 이미지 가장자리에 가깝다는 이유만으로 바깥 여백을 다시 추가하지 않는다. 획의 실제 잘림과 내부 요소끼리의 과도한 밀착을 별도로 확인한다. 요청 치수와 출력의 작은 픽셀 반올림 차이도 내용 폭 자체가 줄어든 문제와 구별한다.
