**N줄 지정:** 들어갈 내용의 역할에 맞는 문자 프로필로 정확히 N줄인 텍스트 프레임을 측정한다. 명시한 글자 크기·너비·기준선 간격을 우선하고, 미지정 값은 선택한 프로필에서 받는다. 부분 서체·굵게·기울임이 있으면 실제 혼합 서식으로 측정한다. 본문이 없으면 짧은 한글 문구를 명시 줄바꿈 N줄로 만들어 자동 줄바꿈이 늘지 않는지 확인한다. 빈 문자열/개행만 또는 N×글자 크기로 높이를 추정하지 않는다. 본문이 있으면 그 문장으로 측정하고 줄 수 충돌을 숨기지 않는다. measurementAvailable=true, font.verified=true, 누락 글리프 없음, lines.length===N을 확인한 frameBounds.heightMm를 예약한다(inkBounds/기준선 거리 아님). 예약 API가 선택한 프로필을 지원하지 않으면 이 실측 높이를 heightMm로 전달한다. 도구가 없으면 실제 선택한 UND 계열 Editor 임시 프레임 배율 1로 mm 높이를 측정한다. 임시/숨긴 측정 문자는 저장 전 제거하고 줄 수·너비·프로필·행간·높이를 기록한다. 프로필이나 행간을 바꾸면 재측정한다.
