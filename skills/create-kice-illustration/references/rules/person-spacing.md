## 인물·말풍선·이름의 실제 간격

꼬리 끝↔자기 화자 머리의 실제 빈틈 **1–2mm** 출발. 가로 배치는 끝 높이↔정수리 세로, 옆 꼬리는 머리 윤곽과 가로 거리로 잰다. 옆 이름 글 획↔같은 높이 인물 윤곽 **0.8–1.5mm**, 아래 이름↔인물 하단도 **0.8–1.5mm** 출발. 이미지 사각/투명 여백은 제외한다. 멀리 떨어진 화자까지 꼬리를 늘이거나 몸통 확대와 함께 꼬리를 확대하지 않는다. 끝은 자기 얼굴/입을 향하고 닿지 않는다. 예약→승인 원화의 실제 경계 재계산→최종 합성에서 형태와 간격을 각각 검사하고 실제 mm를 기록한다. 흰 이미지 배경이 끝을 가리면 배치/바깥 면부터 고친다. 이름은 받은 것만 별도 문자, 반복 위치는 일관되게 유지한다. 생성기 기본 대칭 꼬리는 직접 경로 수정한다.
