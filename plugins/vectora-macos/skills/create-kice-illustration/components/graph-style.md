## 차트·연속 그래프의 축·개형 표현 — chart/graph에만

정량 chart와 축/개형을 가진 graph에 적용한다. 수량 눈금은 **실제 수량 척도가 있는 경우만**; 정성 이론 그래프에 새 숫자 눈금·전면 격자를 자동 추가하지 않는다. **수치를 생략하더라도 요청된 시점·범주명과 자료의 대응은 표시한다.** 숫자 눈금 숨김 설정이 의미 있는 축 라벨까지 없애지 않는지 계획과 실제 출력에서 확인한다. 눈금 비교용 보조선 적용 조건은 해당 유형에서 정한다.

- 축 **0.4pt**, 독립된 자료 선·개형 **0.6/0.7/0.8pt** 중 하나, 보조선·인출선·범례 테두리 **0.3pt**. **누적면적·구성비 영역처럼 회색 면 자체가 자료인 경우 면 경계는 0.3pt**를 기본으로 하며, 독립 곡선의 굵기를 그대로 적용하지 않는다. 명시된 강조선은 별도로 구별한다. 채운 화살촉에 외곽선을 덧대지 않는다.
- 보조 파선 선/간격 **1.5/1pt**. 개형 파선은 0.6·0.7pt에서 **2/1pt**, 0.8pt에서 **3/1.5pt**. 일점쇄선은 각각 **5/1/1/1pt**, **6/1.5/1.5/1.5pt**. 엔진의 0.8pt 일점쇄선이 6/1/1/1이면 실제 개체를 교정한다.
- Y지표명은 정량 차트에서는 축 왼쪽 직립 세로쓰기를 출발점으로 하며, 긴 제목은 의미 단위 **2–3열**, 짧은 단위는 따로 둔다. 정성 이론 그래프의 짧은 제목(물가·Y재(개) 등)은 **Y축 상단 왼쪽의 가로쓰기**를 기본으로 한다. 짧은 단어와 단위를 여러 세로열로 쪼개지 않으며 사용자 지정 방향을 우선한다. X제목은 눈금 아래 별도 줄/축 끝 바깥. 단위는 수량을 나타내는 축에 붙인다. 가로 막대·100% 띠의 단위는 가로 값 축 끝 부근에 두며, 범주축 위 왼쪽에 홀로 띄우지 않는다.
- 제목·눈금·단위·범례·외부 라벨 공간을 먼저 제외하여 자료 영역 계산. 긴 범주명은 의미 단위 줄바꿈과 실제 폭 측정, 한 음절 고립·이웃 라벨 접촉 금지. 비수량 범주 간격만 라벨 폭에 맞춰 변경할 수 있다.
- 두 축이 같은 원점을 공유하면 `0`은 한 번만 표시한다. 투영·기간 보조선이 개형을 가로지르는 것은 의미상 필요한 교차일 수 있으므로 무조건 피하지 않는다. 기간 화살촉·글자가 개형에 붙어 한 기호처럼 보이는 충돌은 피하되, 이를 위해 자료 좌표나 기간 끝점을 바꾸지 않는다.
- 점·곡선의 이름과 수치 라벨은 보조선에 획이 관통하지 않게 둔다. 자료 좌표는 유지하고 라벨의 가로·세로 오프셋을 함께 검토하며, 같은 역할의 간격을 맞춘다. 위치 조정으로 해결할 수 없을 때만 최소한의 흰 뒷면을 사용한다. 선을 문자 뒤로 보냈다는 사실이나 글자 외곽에 가는 흰 선을 두른 것만으로 충돌이 해결됐다고 판단하지 않는다.
- 축 제목은 바로 인접한 눈금 글자 또는 축 끝의 **실제 획에서 약 1–2mm** 떨어진 위치부터 배치한다. 수치 눈금이 없는 개형에 눈금용 빈 줄을 남겨 제목이 축에서 고립되지 않게 한다. 기울어진 선 옆 라벨도 글상자 사각형이 아닌 글 획↔선의 빈틈을 검사하고, 교점·자료 위치는 유지한다.
- 수량 축은 일정 간격의 읽기 쉬운 눈금이며 관측값을 불규칙 눈금으로 대신하지 않는다. 생략 뒤에도 척도/눈금 간격 유지. 같은 의미의 비교 패널은 척도·크기 공유, 패널 사이 틈은 내부 틈보다 크게.
