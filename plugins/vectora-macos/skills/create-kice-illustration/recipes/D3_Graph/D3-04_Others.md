# D3-04_Others — 기타 연속

2축 개념도, 3D 곡면

연속 수량 의미의 2축 개념 관계·3D 곡면 등을 다룬다. 축·단위·정의역·투영/깊이와 수량 매핑을 먼저 정한다. 개별 대상의 높음/낮음 특성 배치는 D4_Diagram/D4-06_Schematic이다. 연속 개념 관계·영역 자체가 의미인 그림은 숫자가 없어도 이 유형이며 임의 수치 눈금 없이 그 관계를 표현한다. 곡면은 투영 때문에 생긴 가림과 실제 불연속을 구별하고 제공되지 않은 등고값·숫자·관계를 추가하지 않는다. 지원되지 않는 곡면은 실제 관계로 편집 가능한 경로·면을 구성한다.

곡면의 축 이름은 각각 X/Y/Z 대응축을 따라 읽히고 서로 구별되어야 한다. 축과 이름의 시각적 연결, 글자·축선·다른 이름 사이의 실제 간격을 확인한다. live 계약의 측정 여백을 지키되, 전체 projected hull 바깥이라는 이유만으로 축 이름을 더 멀리 밀지 않는다. 식·계수·정의역·투영이 바뀌면 곡면과 가림, 윤곽, 축, 이름 배치를 모두 다시 만든다.
