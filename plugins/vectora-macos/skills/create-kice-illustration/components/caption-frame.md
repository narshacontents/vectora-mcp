## 작은 설명·범례·예시 상자

전체 매체 외피가 아닌 독립된 작은 내용 묶음이다. `component-caption.v1`·`component-legend.v1`·`component-example.v1`의 `composition.legendFrame`으로 제목과 본문을 연결한다. 제목은 닫힌 테두리 위쪽 중앙, 작은 흰 받침은 제목 잉크와 최소 여백만 덮는다. 실제 그래프 자료에 딸린 범례는 그래프 소유 범례를 우선하며 이 독립 상자로 연결을 끊지 않는다.

폭은 지정 최대 폭 안에서 내용에 맞춰 줄이고, 길어진 글은 자연 줄바꿈과 함께 높이를 늘린다. 내용이 줄면 상자도 줄인다. 모서리·획·제목 여백·본문 문자 크기는 전체 확대율에 종속시키지 않는다. 위아래 상자를 한 묶음으로 비교하면 같은 폭과 내부 가운데 정렬을 사용한다. 내용 수정 후 제목 받침, 내부 여백, 주변 자료와의 간격을 실제 이미지로 확인한다.
