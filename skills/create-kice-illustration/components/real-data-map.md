- **검색 → 지리 자료 추출 → 같은 도법으로 배치 → 위치 대조** 순서로 진행한다. 공공기관·시설 운영기관·학술 지도·박물관/역사 자료를 우선하고, 출처 URL·자료 시점·대상/의미·좌표계·변환 방법을 그림 밖 제작 기록에 남긴다. 지점의 좌표를 확인한 것만으로 두 지점 사이의 실제 경로나 영역 경계를 검증했다고 보지 않는다.
- GeoJSON/좌표표/지리 래스터가 있으면 우선 사용한다. 지도 이미지밖에 없으면 경위선 또는 분산된 식별점으로 원도법·범위를 맞춘 뒤 필요한 자료만 지리 좌표로 옮긴다. 맞춤에 쓰지 않은 지점에서도 오차를 확인한다. 원본과 투영이 다른 지도에 이미지 x/y를 비례 복사하거나 경계 꼭짓점을 감으로 찍지 않는다. 해상도/고증이 허용하지 않는 정밀도를 주장하지 않는다.
- 도시·시설·경유지는 출처와 연결된 geographic anchor로, 경로는 검증된 경유 좌표로 만든다. 문화권/역사 영역은 채택한 분류·시점의 경계를 따른다. 보편적으로 고정된 국경처럼 취급하거나 현재 국가 면의 합으로 자동 대체하지 않는다. 자유 영역은 검증된 지리 도형으로 등록할 수 있는 경로를 우선하며, 문서 path 보완만 가능하면 원 좌표를 보존하고 도법/crop 변경 시 함께 재생성한다. 등록되지 않은 보완 면의 자동 연동을 약속하지 않는다.

- 지도는 실제 위치를 확인하여 승인 바탕의 투영/등록에 맞게 환산; 파일 x/y를 위경도로 보지 않는다. 국가 경로에 소지역 통계를 붙이거나 가짜 경계/경계 시점 왜곡을 만들지 않는다. 비율·밀도는 경계값/범례/결측을 가진 소수 채움 단계, 총량은 기호 **면적** 비례를 검토한다. 위치 확인과 통계 검증은 별개다.

- 등온선·강수량 등 실제 연속 분포는 출처의 지표·단위·기간·해상도·좌표계와 결측값을 확인한다. 관측점, 관측 기반 보간 격자, 기후 평년값을 구별하며 매끈한 가상 곡선의 생성 성공을 실제 자료 검증으로 보고하지 않는다.
- 래스터를 등치선용 격자로 옮길 때 픽셀 중심/모서리, 위경도 순서, 남북 행 방향을 명시적으로 변환하고 원본·변환 근거를 보존한다. 원자료 몇 지점의 값/위치와 최종 등치선의 수치·교차 위치를 대조한다. 검증되지 않은 평활화·결측 메움·곡선 이동으로 모양을 꾸미지 않는다.

- 원자료 해상도를 유지하도록 먼저 필요한 지역만 잘라 계산한다. 용량 제한을 피하려고 행·열을 임의 건너뛴 격자를 원본 해상도라고 부르지 않는다. 불가피하게 줄이면 방법·유효 해상도·단서 손실을 제작 기록에 남기고 목적에 맞는지 판단한다. **연속 분포의 채색도에서 격자와 해안의 불일치·작은 결측 때문에 육지에 흰 틈이 남으면, 주변 유효 구간색을 연장하는 표시 전용 채움으로 마무리한다.** 원 격자의 값·null과 등치선·숫자 계산은 보존하고, 보완 면을 관측값이나 최저 등급으로 바꾸지 않는다. 바다·호수는 칠하지 않으며 보완 영역·근거는 그림 밖에 기록한다. 실제 미관측 여부 자체가 문제 단서이거나 넓은 자료 부재를 숨기게 되는 경우에는 이를 적용하지 않는다. 그림 안에 결측 보완·단순화 안내를 자동 추가하지 않는다.
- **자료가 자세할수록 좋은 그림인 것은 아니다.** 광역 기온·강수의 경향을 읽는 작은 지도에서 국지적 굴곡과 작은 폐곡선이 주분포를 가리면 표시용 일반화를 검토한다. 실제 값은 별도 보존하고, 필요하면 범위·강도를 명시한 이웃 평균 격자로 선과 면을 함께 다시 계산한다. 원자료의 노드 간격을 유지해도 유효 상세도는 바뀌므로 변환 근거와 값의 변화량은 제작 기록·인계 자료에 남긴다. 그림 안에 ‘단순화함/일반화함’ 문구는 자동 추가하지 않는다. 특정 지점의 정확한 수치·국지 극값·산지 효과가 문제 단서이면 이 방식을 쓰지 않는다. 눈대중으로 곡선을 새로 그리거나 등치선마다 따로 움직이지 않는다.
- 등치선 숫자는 선의 실제 값에 연결하고 판독 가능한 구간에 배치한다. 작은 폐곡선·짧은 조각에는 무리하게 숫자를 끼워 넣지 말고 인출 표기 또는 범례로 해석이 가능한지 판단한다. 앱이 등치값에 연결된 인출 라벨을 지원하면 이를 우선하고, 제작자는 라벨 위치와 연결할 가시 조각을 고른다. 자료 변경 후 연결점 재계산과 실제 겹침을 검수한다. 해당 값의 선이 사라졌을 때 예전 숫자·지시선이 남으면 안 된다. 미지원 앱에서만 계산된 선분상의 지리 좌표를 앵커로 보충하고 값·선분·좌표 근거를 보존한다. 이 지리 앵커는 격자·등치값 변경 뒤 새 선분에 수동으로 다시 연결해야 한다. 자동 배치 실패를 정상 표기 완료로 간주하지 않는다.
