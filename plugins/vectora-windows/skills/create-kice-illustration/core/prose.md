# 산문과 문단 시작점

- 본문은 실제 문단과 강조를 보존한 한 글상자로 조판한다. 영어를 별도 Body 면으로 바꾸는 전처리는 사용하지 않는다. 일반 줄바꿈·자간·반칸·문자 코드 원칙은 함께 준비된 typography 원칙을 따른다.
- 서체·크기는 typography 원칙에 따라 앱 catalog에서 영역별로 선택한다. 돋움 기본 프리셋에서 역할에 맞는 크기를 변형하며, 말풍선이라는 이유만으로 모두 같은 크기로 만들지 않는다. 발언·진술·카드 본문과 이름·짧은 표기의 역할 및 원본의 크기 차이를 보존하고, 측정과 제작에 같은 프로필을 전달한다. 사용자 명시값과 기존 문서의 서식은 우선한다.
- 새 UND v3.1 Main Regular 연속 본문의 숫자는 지원 앱의 **평가원 본문 숫자·기호** 서식을 사용한다. ASCII 원문은 보존하며 숫자를 전각 문자로 입력하지 않는다. 표·축·범례·자료 라벨의 숫자와 ABC는 기본 표시를 유지한다. 바탕·Bold·Italic에는 이 Main Regular 전용 역할을 적용하지 않는다. 원본 표본이 없는 숫자까지 모두 동일함을 검증했다고 표현하지 않는다.
- 2028 예시문항의 연속 산문은 기본적으로 양끝 정렬, 마지막 줄 왼쪽 정렬(`justify-left`)로 조판한다. 제목·짧은 라벨·표셀에는 일괄 적용하지 않는다. 사용자가 다른 정렬을 지정하면 그 지시를 따른다. 폭을 맞추려고 공백·수동 줄바꿈을 삽입하지 않고 마지막 줄의 자연스러운 오른쪽 여백을 허용한다.
- 행간은 선택한 프로필의 **실제 기준선 간격**으로 확인한다. 새 제작의 기본 비율은 함께 준비된 typography 원칙을 따른다. 원본이 촘촘하다는 이유만으로 임의의 행간을 새 기본값으로 선택하지 않는다. 표의 행 높이나 줄에 들어간 큰 기호의 높이를 본문 기본 행간으로 오인하지 않는다. 돋움·혼합 서체·문단 박스가 있는 행에 바탕의 간격을 일괄 적용하지 않는다. 부분 문자 스타일을 바꿔도 다른 범위가 속한 문단의 행간을 함께 바꾸지 않는다. 문단 사이 간격은 실제 마지막·첫 기준선으로 확인한다. 본문 행간과 다른 간격이 필요하면 한 글상자의 네이티브 문단 뒤 간격을 사용하고, 빈 줄·글상자 분리로 흉내 내지 않는다. 요청이나 구성상 근거가 없으면 추가 간격은 0이며, 마지막 문단 아래에 여백을 더하지 않는다.
- 문단 시작점은 의도에 맞는 네이티브 속성으로 정한다. 원본이나 요청에 있는 **첫 줄만 들여쓰기**는 첫 표시 줄에만 적용한다. 목록 기호·발언자처럼 **짧은 접두부 뒤의 본문 열을 반복해 맞출 때**는 고정 본문 열을 사용해 접두부와 뒤 공백이 양끝 정렬로 늘어나지 않게 한다. 같은 역할의 항목은 실제 본문 시작 열을 맞추되 모든 문단에 들여쓰기를 강제하지 않는다.
- 사용자가 현재 커서 위치를 기준으로 다음 줄을 정렬하라고 한 경우 **커서까지 항목 고정(Ctrl+Shift+Tab)**을 사용한다. 버튼과 단축키는 같은 기능이다. 커서 위치의 실제 x를 같은 문단의 다음 표시 줄 시작점으로 삼고 첫 줄의 문자 위치와 다른 문단은 유지한다. 수치로 지정하는 고정 본문 열과 구별하며, 일반 산문 전체에 일괄 적용하지 않는다.
- 이 기능은 한 텍스트 객체의 네이티브 문단 속성으로 유지해야 한다. 공백 반복·강제 엔터·줄별 객체로 흉내 내지 않는다. 연결 앱의 실제 공개 명령/스키마 지원을 확인하고 사용하며, 미지원이면 요청된 들여쓰기를 완성했다고 보고하지 않는다. 본문 추가·삭제와 저장·재열기 뒤 문단 범위와 시작점을 확인한다.
- 본문을 감싼 단순 사각 상자는 내용과 테두리 높이를 함께 관리하는 네이티브 컨테이너를 우선한다. 본문 추가·삭제가 가능한데 독립 사각형의 높이는 매번 따로 고쳐야 하는 구조를 기본으로 삼지 않는다. 원하는 외피를 이 방식으로 만들 수 없으면 AI가 본문 실측에 맞춰 외피까지 재조판한다.
