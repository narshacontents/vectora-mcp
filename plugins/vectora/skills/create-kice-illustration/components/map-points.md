## 위치·점·라벨이 있을 때

- 같은 크기의 원/사각/삼각/기호는 위치·범주이며 수량 비례로 추정하지 않는다. 작은 장소의 타원/국지 영역 표시는 국가 전체 채움·자연 경계와 구별한다.
- 등록 좌표 또는 바탕에서 확인한 위치에 기호 **중심**을 맞춘다. 고정 anchor를 이동해 겹침을 해결하지 않는다. 부가 수치는 의미·단위를 명시한다.
- 설명 상자는 먼저 `지점–기호–원문` 대응을 확정한다. 문장 속 출발지·비교 대상 지명을 표시 지점으로 오인하지 않으며, 상자를 옮겨도 연결 대상과 원문은 유지한다. 설명 상자가 여럿인 지도는 **상자를 대상과 가까운 쪽 틀의 좌우 경계에 걸쳐** 둔다. 상자의 절반 이상이 틀 밖으로 나가도 되며, 지도 틀은 남은 가운데 폭(전체의 약 3/5–4/5)을 쓴다. 이렇게 해야 전체 높이가 폭보다 크게 늘지 않는다(전체 높이는 폭의 약 0.7–1배에서 시작). 틀 위·아래로 상자를 빼지 않는다. 상자는 대상 점과 가까운 쪽에 나눠 둔다(내륙 지점은 서쪽 빈 땅, 해안 지점은 바다 쪽). 모든 상자를 한쪽 바깥 열에 몰아 세우지 않는다. 상자 자리가 모자라면 상자를 밖으로 빼기 전에 지도 범위의 바깥 여유(빈 내륙·바다)를 조금 넓힌다. 상자를 틀 위·아래 바깥으로 빼서 지도와 떨어뜨리지 않는다. 지시선은 점에서 상자 가장자리까지 꺾지 않은 직선 하나로 잇고, 상자 폭은 문장이 2–3줄로 감기는 정도다. 지도 창은 의뢰에 이름이 나온 지역(예: 랴오둥반도·한반도 서부)을 모두 포함하도록 먼저 정하고, 그 범위의 자연 종횡비로 틀을 만든다. 상자를 넣으려고 범위를 잘라 내거나 틀을 세로로 길게 늘이지 않는다. 기호 범례(● 도시 등)는 틀 모서리에 붙은 테두리 칸에 넣는다.
- 라벨의 실제 잉크 상자와 점 외곽 사이 약 **0.7–1.5mm**를 시작 간격으로 쓴다(보편 강제값 아님).
- 첫 배치부터 위·아래·좌·우의 빈 면 후보를 실제 글 폭과 대조해 고른다. 모든 점에 같은 offset을 적용하거나 halo만 넣으면 지리선 충돌이 해결됐다고 가정하지 않는다. 해안·국경·경로가 글 획을 통과하면 라벨만 옮기고, 가까운 빈 면이 없을 때 짧은 인출선을 해당 점에 연결한다. 라벨 자체가 다른 지역·섬 위에 놓여 지시 대상을 오인하게 하지 않는다. 점의 지리 anchor는 고정하고, 흰 배경/halo로 중요한 해협·섬·경계를 크게 덮지 않는다.
- 한 지점의 이름·수치·작은 수치 상자는 **하나의 주석 묶음**으로 먼저 측정한다. 묶음 전체가 들어갈 가까운 빈 면을 고르고, 지시선은 점에서 묶음 바깥쪽까지 연결해 자기 상자나 다른 문자를 관통하지 않게 한다. 이름만 자동 배치한 뒤 수치 상자를 덧붙이거나, 충돌할 때 이름 하나만 멀리 옮기지 않는다. 필요한 지형 판독을 보존하며 별 의미 없는 빈 바다를 찾으려고 인출선을 과도하게 늘이지 않는다.
- 문자·인출선·기호를 분리하고 필요한 기호 범례만 둔다. 화살촉 없는 기본 관계/비교 연결에 이동 방향을 부여하지 않는다.
- 일반 add의 ellipse/polygon/path와 독립 text는 자동 위경도 변환이 아니다. 문서 anchor와 등록 좌표를 구별하고 바탕 배율 변경 후 기호 중심/크기·인출선의 대응을 확인한다.

문구·값을 바꾼 뒤에는 지리 앵커·자료 대응과 주석 묶음의 배치를 보존했는지 확인한다. 글 폭이 달라져 문자 가장자리의 인출선 종단이 조금 재계산되는 것은 정상 재조판이다. 지점 자체 이동·다른 대상 연결·자기 상자 관통과 구별한다.
