**N줄 지정:** 실제 UND 계열 8pt와 선택한 역할의 장평·자간으로 정확히 N줄인 텍스트 프레임을 측정한다. 지정 너비·행간을 우선하며 미지정 기본 행간은 **lineHeight:1.24**(공식 규정 아님). 부분 서체·굵게·기울임이 있으면 실제 혼합 서식으로 측정한다. 본문 없으면 짧은 한글 문구를 명시 줄바꿈 N줄로 만들어 자동 줄바꿈이 늘지 않는지 확인한다. 빈 문자열/개행만 또는 N×8pt로 추정하지 않는다. 본문이 있으면 그 문장으로 측정하고 줄 수 충돌을 숨기지 않는다. measurementAvailable=true, font.verified=true, 누락 글리프 없음, lines.length===N을 확인한 frameBounds.heightMm를 예약한다(inkBounds/기준선 거리 아님). 도구가 없으면 실제 선택한 UND 계열 Editor 임시 프레임 배율 1로 mm 높이를 측정한다. 임시/숨긴 측정 문자는 저장 전 제거; 줄 수·너비·폰트·행간·높이를 기록하고 행간을 바꾸면 재측정한다.
