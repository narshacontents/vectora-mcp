# 선·회색 바탕 위 글자와 지시선

해당 배경이 있을 때만 적용한다. 실행 속성은 `execution/text-effects.md`를 읽는다.


- 점선·눈금 보조선·상자 윗선 위에 글자를 놓아야 하면 **문자 뒤에 작은 불투명 흰 배경**을 둔다. 정렬·자료 대응 위치는 유지하고 실제 글 획 전체와 글자 사이 공간을 덮되, 여백은 약0.15–0.3mm부터 최소한으로 정한다. 빈 글상자 전체를 흰색으로 채우지 않는다. 가는 글자 윤곽만으로 글자 사이를 지나는 선까지 가려졌다고 판단하지 않는다.
- 회색 면 위 글자는 바탕을 크게 지우는 사각형 대신 **읽히는 두께의 흰 윤곽선**을 사용한다. 미지정이면 #AAAAAA 정도 이상으로 어두운 회색에서 적용하고, 더 연한 면도 무늬·선 때문에 획이 묻히면 적용한다. 보이는 바깥 테두리 **0.7pt**를 기본으로 실제 인쇄 크기로 확인하며 글자를 두껍게 만들거나 내부를 흰색으로 바꾸지 않는다. 이 농도·두께는 판단의 출발값이다.
- 색칠된 지도 위 지시선에는 **같은 경로를 따라 양옆에 얇은 흰 테두리**를 두고 그 위에 검정 본선을 유지한다. 지리 anchor·연결 끝점·선 굵기는 바꾸지 않고, 흰 띠는 약0.2–0.3pt씩부터 검토한다.
- 위 처리로 자료점·자료선·중요한 경계·다른 글을 가리지 않는다. **흰 받침은 뒤의 보조선을 가리는 수단이지 관측값을 이은 자료선을 지우는 수단이 아니다.** 실제 글 획뿐 아니라 흰 받침 외곽도 자료선과 대조한다. 문자·선에 연결된 효과를 우선하고, 별도 배경을 보충했다면 글/경로 수정·이동·저장 재열기 뒤 크기와 위치도 따라 맞춘다. 배경을 피하려고 정렬된 숫자 하나만 옆으로 밀거나 자료 좌표를 바꾸지 않는다.
